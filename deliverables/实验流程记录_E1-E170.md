# ICCAD 2026 Problem C 实验综述

2026 年 11 月 26 日结题。2026 年 11 月 27 日按实验编号整理。研究从公开题目生成草稿，再用几何优化修复硬约束和软约束。最终保留 **E169 Ref080 best33 + 强化后处理 + FP32 CUDA Graph**。原 no-MIB dev2000 的硬合法为 **2,000/2,000**，加权 Q **1.005851**、混合 Q **1.006563**，完整单例均时 **217.6 ms**。 [最终评价](../experiments/E169_s2_progressive_unfreeze/evaluation/gpu_graph_dev2000_v1/results.json)

## 实验执行与评价口径

先冻结数据成员、训练目标、初始化和预算，再在固定监测集上选检查点。完成的候选按登记预算求解，分别记录草稿 Loss、最终硬合法、软违规、质量分和完整耗时。原始数据、MIB 平均面积派生任务和后期 no-MIB 设定各有独立记录。各行 Q 沿用原面板与聚合方式，历史 Flash、完整后处理、固定深度以及不同时限的结果各自有效。 [历史执行约定](../experiments/_archive/20261126_research_closeout/docs/protocol.md)

## 改变研究路线的实验

### E6–E8 · 确定神经草稿与几何修复的分工

E6 跑完五组训练与评估，冻结草稿后做意图感知修复，在 dev100 达到 100/100 硬合法、加权 Q 1.262626。E7 的 occupancy 监督改善了草稿的重叠和留白，最终 Q 基本持平。这组对照后来用来区分两个问题：草稿是否更好修，以及修完后是否真的更好。

E8 固定 E7 草稿，改进几何后处理。在两组各 100 例的开发面板，新方案均保持全硬合法，推理加后处理分别加速 8.66 倍、10.14 倍，平均 Q 与最大 Q 同时下降。第二组参与过策略修订，因此两组结果是开发期验证。此后整条路线以模型给初稿、几何求解器保证可行并修质量为主。 [E6](../experiments/E6_intent_aware_repair/README.md) · [E7](../experiments/E7_repair_friendly_draft/README.md) · [E8](../experiments/E8_fast_robust_postprocess/README.md)

### E25、E42 · 把质量与时延固定在可复用基线上

E25 冻结 E17 best51 和 steady 后处理组合，dev500 上 500/500 硬合法，加权 Q 1.039578、均时 259.5 ms。它提供了明确的对照入口，后续试验能固定模型只改求解器，也能固定求解器只改草稿。

E42 的矩形网络联合正则化 best51 在登记的本地 1,000 例全部硬合法，加权 Q 1.028385、均时 222.5 ms。后续 Flash 和其他几何分支共享它的草稿。两组数字分别来自各自的面板与口径。 [E25](../experiments/E25_integrated_baseline/README.md) · [E42](../experiments/E42_joint_regularization/README.md)

### E97、E101 · 建立 GPU/CPU 混合流程和首个交付基准

E97 把 GPU 神经网络前向与 CPU 几何求解接到同一入口。原 C5 在 dev500 的加权 Q 为 1.012686，均时 204.5 ms，500/500 硬合法。E101 冻结原 C5 交付身份，并把 64k 暖启动和后续链路重放分别记账。登记的原 test2000 加权 Q 为 1.018809。E101 代表当时的交付版本，也给后面的架构实验留下了可追溯的历史参照。 [E97](../experiments/E97_gpu_hybrid_solver/README.md) · [E101](../experiments/E101_final_c5_solver/README.md)

### E108 · 建立原面积 no-MIB 的数据与评测基线

E108 冻结独立随机的 40,000 例原始 reference，按 36,000/2,000/2,000 划分，并登记固定 train500 和 dev500 监测成员。保留原面积与公开约束，把自由布局及已存指标与求解输入分开。MIB 平均面积路线与 no-MIB 路线由此有了各自可追溯的数据口径，后段结果才能沿固定成员比较。 [E108](../experiments/E108_random_reference40k/README.md)

### E119、E134 · 初始全局交互与中间层监督

E119 用两层全局交互生成初始布局，best55 在原 dev500 的混合 Q 为 1.021568，全部硬合法。E134 对比架构和监督间隔，在 E119 分支每三层监督的 best63 上得到混合 Q 1.018624，并保留逐层损失和拓扑诊断。这些实验把观察对象从末层草稿扩展到真实的分层读出，给后续共享单元及出口监督提供了对照。 [E119](../experiments/E119_global_initial_generator/README.md) · [E134](../experiments/E134_supervision_interval/README.md)

### E142、E145–E148 · 把几何反馈与隐藏传递做成可复用双层单元

早期反馈对照分别检查了成对关系值、逐层隐藏传递、监督出口处的隐藏重置。E148 把它们收束为两个子块组成的功能单元。公开题目编码一次，调用时用静态条件启动隐藏状态。A 到 B 同时传布局与隐藏状态，跨单元只接续布局。当前布局重新计算重叠、分组、边界等几何特征，另外加入 16 维等面积形变探测。

best46 的混合 Q 为 1.012608。这个实验同时改变了共享方式、几何反馈和监督，记录支持整套方案的结果。后来的 E169 沿用三个双层单元、各重复两次的骨架。 [E148](../experiments/E148_shared_functional_shape/README.md) · [E148 结构与比较](../experiments/E148_shared_functional_shape/DESIGN.md)

### E149、E151、E165 · 训练可独立使用的结构化初稿

E149 单独训练从公开角色和端口信息生成布局的 RoleInitial 初稿，best52 的固定 dev500 Loss 为 0.382389。E151 冻结这份初稿、重新训练后段，在原 dev2000 得到混合 Q 1.008980、2,000/2,000 硬合法。

E165 从头训练三层带静态关系消息的 L0，冻结 20 轮训练后段，第 21 轮低学习率解冻联合微调。原 dev2000 混合 Q 为 1.008717，仍全硬合法。E165 同时留下独立 L0 检查点和后段联合结果，后来可以固定初稿、逐段判定 S0 或 S1 改动的收益。 [E149](../experiments/E149_role_initial/README.md) · [E151](../experiments/E151_frozen_role_initial/README.md) · [E165](../experiments/E165_joint_l0/README.md)

### E167–E169 · 分段训练与最终软约束修复

E167 在 S0 的四步更新屏蔽重叠相关反馈，固定 dev500 的 L4 出口 Loss 为 0.246721，相对 E165 的同层有 418/500 例改善。E168 保留前级并渐进解冻 S1，L8 Loss 从 E165 的 0.294049 降到 0.255944，450/500 例改善。这里的两组数字衡量指定层的草稿，最终质量仍以完整求解结果为准。 [E167](../experiments/E167_s0_no_overlap_feedback/README.md) · [E168](../experiments/E168_s1_progressive_unfreeze/README.md)

E169 延续 E168 前缀，训练 S2 后解冻前级，采用末层 Reference 系数 0.80 的 best33。冻结模型后，CPU 后处理加强分组和贴边修复，GPU 使用 FP32 CUDA Graph 复用推理。原 no-MIB dev2000 最终 2,000/2,000 硬合法，混合 Q 1.006563、加权 Q 1.005851，平均服务时间 217.6 ms。与强化后处理的 CPU 前向对照相比，平均服务时间由 539.7 ms 降至 217.6 ms。CPU 与 CUDA 草稿存在数值差异，因此两臂分别留有逐题布局与分数。此组合成为最终求解器。 [E169](../experiments/E169_s2_progressive_unfreeze/README.md) · [最终评测](../experiments/E169_s2_progressive_unfreeze/evaluation/gpu_graph_dev2000_v1/results.json) · [CPU/GPU 对照](../experiments/E169_s2_progressive_unfreeze/evaluation/gpu_graph_dev2000_v1/comparison.json)

### E170 · 五阶段改造的停止点

E170 测试五阶段、每阶段三块的新结构，并在后续版本改用永久冻结前缀的逐段训练。S1 best31 的 dev Loss 为 0.271979，S2 于 11,428 步安全停止，后续阶段和全网联合训练未启动。记录保留训练曲线、配置和停止证据，当前交付沿用 E169。 [E170](../experiments/E170_three_block_stages/README.md)
