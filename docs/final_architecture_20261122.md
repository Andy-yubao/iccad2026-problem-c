## 1. 架构接口

| 阶段 | 核心网络 | 布局读出 | 训练边界 |
|---|---|---|---|
| L0 | 三个attention/FFN块，width128、四头、每头32、FFN384 | 末端一次 | 独立训练，冻结own-Loss-best |
| S0 | 两个attention/FFN块，建议同样width128/四头 | 末端一次 | 冻结L0，只训练S0 |
| S1 | 两个attention/FFN块，建议同样width128/四头 | 末端一次 | 冻结L0/S0，只训练S1 |
| S2 | 两个attention/FFN块，建议同样width128/四头 | 末端一次 | 冻结L0/S0/S1，只训练S2 |

推理顺序为L0→S0→S1→S2→一次原硬合法后处理。四阶段权重不共享；S0/S1/S2各调用一次，不沿用旧方案的共享单元调用两次。两块内只传隐藏状态，没有第一个块的坐标头、辅助几何Loss或几何反馈重算。

设P是公开题目信息，Y是上一阶段末端的布局状态：

    H0 = PublicProjection_k(P) + LayoutProjection_k(Y_in)
    H1 = AttentionFFN_k,1(H0, public_relations, ports)
    H2 = AttentionFFN_k,2(H1, public_relations, ports)
    Y_out = Y_in + ResidualHead_k(H2)

LayoutProjection只编码归一化中心和log长宽比；不运行碰撞、四方向脱离、空白、形变探针、接触走廊或动态pair提取。每阶段独立从公开原始静态信息重建输入，不传上一阶段的动态隐藏状态。第二个块继续使用静态pair bias、端口key/value和静态关系消息，这不是重新注入一套几何反馈。

不再在每个后段前面放一个额外两层RoleInitial题目编码器，否则“后段双层”实际仍有四层。静态原始字段、最短路和归一化图可以缓存；各阶段自己的可训练投影仍属于该阶段。L0没有Y_in，按现有初稿接口解码一次。

中心残差按自身sqrt(area)缩放、形状用logratio残差，全部模块包括F/P均预测。公开固定规格保留在输入和Loss中，最后由原硬检查判定，不能用reference覆盖预测。

每阶段新建优化器，冻结前缀eval/no-grad，固定成员与缓存保持。该阶段的反传、固定dev监测、best、LR和早停采用同一个预登记Loss。每阶段唯一监督出口就是其末端布局，不保留旧L2/L4、L6/L8、L10/L12的双出口加权。

这属于新结构，不能把E157原权重截断后称为已经训练完成的本架构。width128的后段和以下新增Loss尚无训练结果。

## 2. grouping：只增加针对A-X-A的阻挡项

### 2.1 保留原接触目标和原MST

保留现有contact_cost和minimum_group_tree。原接触代价C已经同时计算相向面距离及切向接触长度不足，不能简化为中心距离。原最低有效共边长度为对应较短边的1%；角点接触不算有效贴边。

在当前阶段**出口**预测布局上，用原C为每组建立MST，树与接触方向选择detach；选中边的几何量保留梯度。首个候选不同时改树权、不加瓶颈项、不强迫全组两两相接，也不使用reference树。

这样新增项确实回答“原来希望贴边的MST边是否被挡”，而不是让模型仅靠重新定义期望边来降低新增Loss。各前向仍可根据布局自然更新MST；固定坏边的修复另作统计。

### 2.2 接触走廊和遮挡率

以i在j左侧为例，两者相向面之间法向区间为(x_i_right,x_j_left)，切向共同投影为：

    [u,v] = [max(y_i_bottom,y_j_bottom), min(y_i_top,y_j_top)]
    T = v-u
    s_ij = (sqrt(area_i)+sqrt(area_j))/2

法向间隙及T均为正时，二者形成接触走廊。选择所有法向投影穿过该走廊、且切向与[u,v]相交的异组模块X；无组模块也算异组，同组第三个模块允许成为连接中介，不作为挡块。其他三个方向同理。

把各挡块切向区间裁剪到[u,v]后取并集U，报告：

    rho_ij = length(U)/T

这里用**切向长度**，不乘挡块法向厚度。长条X把通道遮住90%时，rho就是0.9；X厚度缩小十倍不会让遮挡率缩小十倍。多挡块重叠区间只计一次。

无共同切向投影时不虚构走廊，先由原C引导对齐；已经无间隙贴边时无需通路监督。模块穿入彼此时仍由原重叠项负责，不能把走廊失效当作修复成功。

### 2.3 只对真正不足以形成共边的阻隔施压

“遮住一部分”不一定妨碍有效贴边。设F_ij为[u,v]去掉U后最长的连续空段，最低共边长度：

    ell_ij = 0.01 * min(height_i,height_j)
    eta_ij = clip((ell_ij-F_ij)/ell_ij, 0, 1)

只有T>=ell_ij时启用该阻挡项；T本来不足时先由原C负责。空段已经足够长则eta=0，避免为了清空整条走廊而过度搬动其他模块；完全堵住时eta=1。rho用于报告严重度，eta用于聚焦本轮要解决的A-X-A。

F和区间排序/并集只用于当前前向的离散事件与权重，不反传。它们依赖预测布局和公开组关系，不读取reference。

### 2.4 饱和时仍有梯度的让路距离

直接对rho求导的问题是：X完全遮住共同投影时，rho=1，局部移动可能仍是1，梯度为零。因此新增监督还需让路距离。

对有效挡块X，设其完整切向投影为[l_X,h_X]，定义：

    r_minus = h_X-u+epsilon
    r_plus  = v-l_X+epsilon
    r_X = min(r_minus,r_plus)
    rho_X = length([l_X,h_X] intersect [u,v])/T
    b_X = stopgrad(rho_X) * SmoothL1_beta=0.1(r_X/s_ij)
    B_ij = stopgrad(eta_ij) * max_X b_X

epsilon=1e-6*s_ij，仅作尺度相关的接触余量。min采用detach后的确定性活动分支；精确等距选一个方向，不把两个相反梯度平均抵消。max只把当前最严重挡块作为活动约束，下一前向重新判断，避免挡块越多就按数量放大Loss。无有效挡块时B_ij=0。

r_X在完全遮挡时仍随X切向坐标变化，能够给挡块让路的梯度；同时u/v来自端点，因此两端也可以移动以建立新的接触位置。它是局部优化信号，不是对交换成功的保证。为了得到一小段足够的共边，通常不需要真的把X完全移出；eta在空段足够时就会关闭。

F只固定形状，允许移动。P有公开固定位置，新增阻挡项中将P模块的中心坐标视作常量，梯度交给可移动端点/挡块；这仅限辅助项的求导边界，不mask或覆盖网络的P预测，其原公开位置Loss保持。F/P的锁定WH同样不通过该辅助项改动。MIB同形关系继续由原MIB监督和后处理维护。

### 2.5 归一化与加入方式

令E为原MST森林边集合，n_g为原有效分组数，n_b为原有贴边要求模块数。按原树边容量归一：

    G_block = sum_(ij in E) B_ij / max(|E|,1)
    DeltaLoss = 2*B * n_g/max(n_b+n_g,1) * lambda_block * G_block
    B = 0.3336832108335229
    lambda_block = 0.25  # 建议的首个固定值，未经实验验证

加到原Loss上；其余grouping/boundary权重和聚合保持，不按当前坏边数或活动挡块数改分母，不叠加旧瓶颈项。训练、best、LR、早停全部包含同一DeltaLoss，并分开保存原接触与新增阻挡贡献。

收尾优先复用已经完成的E160作为冻结L0，在S0加入本项；S1/S2保留相同系数以避免重新夹挡。这样无需为本项先重训L0。若决定让L0也学该项，应登记新L0并重训全部后段，不能改写E160的Loss身份。各阶段reference/重叠/移动项的最终系数仍需在实现登记时明确，本稿不把旧提案自动作为已定配置。

阻挡监督只在训练/登记的Loss评价中读取出口布局；正式推理没有这段计算。已选MST最多N-1条边，每边遍历N个模块，新增检查量为O(N^2)，不构造N^3完整三元组张量。

### 2.6 如何判断解决了A-X-A

在冻结阶段入口上记录受阻边/三元组身份，出口分别报告：原边达到合法共边并解除阻隔、经同组其他成员形成合法替代路径、仍受阻。修复成功需相关矩形无重叠、P/F满足；仅MST换边、遮挡率降低、走廊消失或Loss下降均不单独算成功。完整分组满足率最终按独立几何检查计算。

不增加边界通路Loss、显式交换头、三方反馈token或新的几何反馈网络。本轮只处理用户提出的grouping夹挡。
