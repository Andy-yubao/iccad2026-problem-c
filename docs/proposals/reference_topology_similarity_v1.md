# 参考关系图相似度：指标候选 v1

状态：2026-11-15 设计候选，已实现独立原型和合成例检查；尚未登记为正式训练目标，没有训练、推理现有权重或读取数据载荷。用户优先要求设计指标。本轮不扩展为新的架构方案。

用户的新方向一：聚焦初始头的拓扑关系表达；初始化阶段最多一次中间布局和一次初始层输出，两次之间允许多层隐状态计算，后者应相对前者有明显拓扑改善。早期允许重叠/间距较差，首先学习问题的关系组织。单层 Transformer 的旧失败结果保留。

另一路用户提出单组 grouping/boundary 系数×4；保留为独立后续实验范围，不加反馈消融、不扩展参数网格，本次尚未准备或启动。

## 1. 要测的对象

定义 **参考关系图相似度 T_ref**：同一模块身份下，布局与reference的相对方向及近邻组织一致到什么程度。范围[0,1]，1表示登记关系全部匹配。

节点为模块，属性不包括预测宽高；由布局中心构图。边同时带有：

1. reference明确的左右/上下关系；
2. reference中是否属于该模块的局部近邻。

所有模块对提供全局组织信息，局部近邻单独获得一半权重，避免远距离容易关系淹没局部错误。一个关系必须同时方向正确、近邻身份兼容才能得分。direction_match和neighborhood_match仅用于解释，不作为另外两个主指标。

矩形几何中心相同而宽高变化时，T_ref完全不变；允许重叠程度不同。整体平移与中心坐标的正统一缩放也不改变主分数；旋转、镜像或交换模块身份可能改变方向，按reference相似任务计错。

这是布局相对组织的操作性定义，不是数学意义上的完整接触拓扑不变量。T_ref=1不保证无重叠、面积/固定规格/分组/贴边满足，也不唯一确定一套坐标；整体压缩中心但保持关系也可能满分。这是该早期目标对几何间距保持宽容的明确边界，最终几何与约束检查另行保留。

## 2. 从reference生成关系标签

模块中心为c_i=(x_i+w_i/2,y_i+h_i/2)。使用公开原面积a_i，定义s_ij=(sqrt(a_i)+sqrt(a_j))/2。

对每个查询模块i，候选集J_i包括其他模块；为避免公开固定位置之间的关系抬高得分，P-P对不计入，包含P与非P的关系仍计入。这仅是评价/监督关系的筛选，不mask任何模块的预测渠道，不覆盖F/P输出。若没有可用关系，指标报告不可用。

距离定义为d_ij=||c_j-c_i||_2/s_ij。分别在reference和预测布局上取有向K近邻，初版K=6；节点不足时取全部候选。同一模块身份不做重匹配。

reference近邻集合N_i包含第K距离处所有数值并列项，防止按模块编号任意选一部分；并列组跨过第K名时，这些边的近邻类别视为不确定，不强迫它们全都出现在预测前K名。它们仍接受明确方向监督。预测近邻同样保留第K距离处并列项，错误额外近邻由reference明确的远邻边检测。

对于reference中心差Δc^R_ij，保留以下明确方向轴：

    A_ij = {a in {x,y}: |Δc^R_ij,a| >= α * max(|Δx^R_ij|, |Δy^R_ij|)}

初版α=.1。相对主要位移过小的轴忽略，避免把几乎同列/同行的微小抖动当作必须复制的关系。每个非重合reference模块对至少保留主轴；reference中心完全重合时方向没有定义，原型明确报错，不编造标签。这个阈值取决于reference相对方向，不取决于预测重叠程度。

预测在每个有效轴上均与reference同号时，方向匹配。预测中心在有效轴上完全相同，属于未确定，计错；不能把所有模块塌到同一点获得高分。

## 3. 主指标的精确定义

设D_ij表示上述方向全部匹配，H_ij表示近邻类别与reference兼容；reference第K名歧义边的H_ij直接视为兼容。

    q_ij = D_ij * H_ij

每个模块对近邻和其余模块分别平均，再等权聚合：

    T_i = 1/2 * mean(q_ij, j in N_i)
        + 1/2 * mean(q_ij, j in J_i \ N_i)
    T_ref = mean_i(T_i)

空类别跳过，只对该节点剩余类别平均；没有候选的节点跳过。每题节点等权，跨题等权，不因N大的题产生更多模块对而获得更高统计权重。分数输出0–1，展示可乘100%。

这是以reference为固定标签的相似度，不要求交换预测与reference后数值相同，也不宣称满足数学距离的公理。

这同时覆盖两个反例：

- 只看方向排序，可能漏掉“方向都对，但邻居位置插错”；近邻类别会扣分。
- 只看K近邻，可能漏掉“整片区域互换而内部邻居不变”；远邻方向会扣分。

初版常数：K=6、α=.1、距离并列相对容差1e-6。它们是可审查的初始设计，未根据E134/E139结果调参，不声称最优。正式实验前需要固定版本和参数。

## 4. 训练时使用可微替代目标

精确排序和正确率的导数几乎处处为零，不能直接把1−T_ref反传。原型采用同一批reference关系的最大间隔排序目标，预测头可以输出中心，或者在后续架构中直接输出关系；两种路径最终都必须以实际输出布局重新计算T_ref，不能仅凭关系头准确便宣布布局成功。

记r_i(X)=sqrt(mean_j(d_ij(X)^2))，对预测r_i取不小于reference r_i的5%，在平方根前实施下限，避免中心塌缩时的除零和无穷梯度。该下限仅在监督目标内部使用，不提供reference模型输入。定义：

    u_ij,a(X) = (c_j,a-c_i,a) / (s_ij * r_i(X))
    dbar_ij(X) = ||u_ij(X)||_2

方向项：

    e_order_ij = mean_a [γ*|u^R_ij,a| - sign(Δc^R_ij,a)*u^P_ij,a]_+
    L_order = 按主指标相同的每节点近/远等权方式聚合e_order

近邻排序项：对reference类别明确的近邻j、远邻k，要求j保持比k更近：

    e_neighbor_ijk = [γ*(dbar^R_ik-dbar^R_ij)
                       + dbar^P_ij-dbar^P_ik]_+
    L_neighbor = 先按每节点的有效三元组平均，再按节点平均
    L_topology = .5*L_order + .5*L_neighbor

初版γ=.1；reference截止并列歧义项不进入此近/远三元组监督。没有有效三元组的节点不参与该项；全题没有三元组时该项为0。

两项均无量纲，reference自身为零损失。方向只要求保留reference一小部分明确间隔，近邻只要求保持排序及小间隔，不追逐完整参考距离。查询归一化防止单纯扩大全部中心坐标持续降低损失；预测压缩到reference尺度5%以下时稳定下限会破坏严格缩放不变性，用于避免塌缩。

这是T_ref的可微替代，不与硬分数数值等价，也不是将其所有最优解精确重写为可微函数。原型未优化批处理或GPU性能。是否产生有效学习、是否需要调整梯度聚合，尚未经过模型实验验证。正式训练须同时登记T_ref和L_topology，反传/监测/选模使用同一注册目标，不能按dev Q重选版本。

## 5. 两次布局输出的改善如何看

同一套reference标签分别计算T_mid与T_initial；报告最终绝对分数、逐题提高/持平/下降数，以及剩余关系错误的消除比例：

    error_reduction = (T_initial-T_mid) / (1-T_mid)

例如.80→.90代表消除一半已有关系错误。T_mid=1时无剩余错误，比例记不可用，单报最终是否维持1。

不单独最大化两次输出的差，否则模型可能通过做差中间布局获得大改善。最终布局的绝对拓扑分数是主目标；两次输出的改善是阶段功能核验。此处不预设新的Transformer深度、坐标头结构或强制改善阈值。
