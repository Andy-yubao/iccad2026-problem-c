## 4. 评价与证据

分别报告草稿Loss/几何/硬合法、最终硬合法/Q、完整耗时。成对交面积、重复覆盖、并集覆盖与N10定义不可混用；B/A≥1不是可装性证明。更少重叠、更多方向正确或较高预测相关性都不自动意味着最终Q更好。

冻结唯一own-Loss best及身份后做登记的终末评价，不看Q再选checkpoint。Q用官方评分，硬合法独立检查；加权Q、平均Q、混合Q=(前两者)/2明确标注。历史有的研究仅以加权Q为目标，不事后替换。中性时间本地Q、公开MIB派生任务不称正式比赛成绩。

固定后处理、成员、数值路径和预算后才讨论网络差异。E101历史完整后处理与E98.depth_budget.v1固定计算深度是两个口径；时间预算会引入运行环境/分支差异。单seed、开发自适应、历史对照、额外训练量和多因素变化均需说明，不能用描述性区间消除这些限制。

完整逐例时间包含公开规格复制/遮罩/面积变换、特征、传输、网络、内部几何、全部后处理/回退及必要硬检查/同步。报告均值/P95/最大值及250ms超限数；磁盘、加载/捕获/预热、评分/绘图单列。批量吞吐和微基准不替代逐例延迟；保留全部坏例、慢例和低质量合法回退。

2026-11-07用户更新：当前默认展示固定同5例的逐层输出，取代100例reference/L/F/最终三相或多相图；模型与层间统一模块ID/颜色和坐标尺度，注明实际checkpoint及监督差异。可以同时比较原模型和新模型，分阶段checkpoint与最终模型前缀必须区分。既有100例图集保留历史证据，不作为当前默认入口；E102仍仅reference/生成图片。无评分控件、不自动打开界面。人类观察保留原话和版本，再转成可验证假设。
