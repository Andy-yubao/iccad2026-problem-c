# E42 → E74 → C5 F 完整重训与评价

用户于2026-11-03明确授权后台运行完整链路，E42与E74均训练到正常早停，不考虑历史复现预算。为完成整个求解器，随后训练原C5修正器，冻结唯一模型，依次进行dev500和已登记2000例测试的重复评价。此运行独立于先前64k重训；不覆盖旧权重、源码或证据。

## 固定设计

| 阶段 | 数据/初始化 | Loss与选择 | 停止方式 |
|---|---|---|---|
| E42 | 原v5 train16k，随机96×12 | 历史八项G，前2个分数轮渐增几何项；best/LR/早停沿用历史G+occupancy代理 | 原四档LR、15轮保护、3次停滞、最低档至少2轮；无时间或轮数上限 |
| E74 | v6嵌套train32k；新E42唯一best精确96→192加宽，冻结graph-local | 原固定G+0.5C；反传/监测/选择一致 | 原调度与数值门禁，正常早停；无时间或轮数上限 |
| C5 F | 原train16k；与历史C5相同的原C3 F暖启动，新E74 L冻结 | 原C5按模块数加权的教师/clearance/公开boundary+MST目标，系数不变 | 原四档LR与正常早停；无时间或轮数上限 |

batch32、FP32、seed0不变。E42/E74使用原CPU4、原eager/guarded CUDA graph路径，F使用原guarded graph backward＋AdamW。阶段内best/latest分开，保存优化器、RNG、顺序/游标、调度与累计费用。阶段之间仅载入登记的权重，优化器重新初始化。

E42反传与选择Loss不同、前2轮渐增属于已核实的历史复现例外，明确保留，不能表述成全程共用一个固定总Loss。原E42正常早停54轮、best51；原E74在42轮因7200秒预算停止，best42，已到最后LR档。本次移除预算，不预设best轮数，不保证逐位重现或必然提高Q。

F目标直接复用原E85公开求解器教师张量及usable标志，逐分块SHA和逐成员核验；只用新L重新生成base。标签不作为网络输入，不重新用C5后处理器生成目标。原模型表示及教师面积表达限制均保留。修正器沿用历史暖启动，因此本次不是所有ML参数从随机初始化重训。

## 完整自动流程

`run.py`依次执行E42 → E74 → 新L草稿/原E85标签桥接 → C5 F → 唯一Loss-best组合冻结 → dev500 → registered test2000 → 汇总报告。任何异常停止后续阶段，不无限重试。原完整E85单线程后处理设置不变，同100例reference/L/F/最终图随dev评价生成，不自动打开页面。

测试2000例此前已在E101旧运行曝光，本次是用户授权的重复评价，不称全新未见测试。全部训练在测试前完成，权重与源码冻结后才读取测试载荷；不按dev Q或测试结果重选权重、改系数、改后处理或追加训练。完整逐例时间、硬合法、Q与回退分开报告，冷启动、磁盘、评分和绘图单列。

状态入口为`state.json`，当前阶段日志为`E42.log`/`E74.log`/`F.log`等，完成后生成`results.json`和`report.md`。最终新权重在`sf/experiments/E101_final_c5_solver/delivery/model.pt`，旧交付不覆盖。所有原始split和冻结索引保留。

根目录创建`STOP`可在当前阶段安全边界保存并阻止后续阶段。仅在用户明确恢复后移除STOP，再以原环境执行`run.py --resume`；不专门预测恢复，不清零累计状态。没有自动唤醒。

`s42`/`s74`取自历史运行的完整冻结源码ZIP并逐文件核验；`sf`为独立C5交付实现。数据、缓存和受保护权重通过文件硬链接只读共享，原路径校验保持，运行输出独立。开始执行后禁止重新运行`prepare.py`/`build_f.py`覆盖运行源码。具体身份和来源见`plan.json`、`frozen_source_manifest.json`、`adaptations.json`及各阶段快照。
