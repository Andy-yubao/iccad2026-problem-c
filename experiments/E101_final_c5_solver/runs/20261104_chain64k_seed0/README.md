三个训练视图均为原v6同一64k成员，train/dev固定500监测及原dev2k/test2k成员保持。面积变换仍为公开MIB平均面积，端口仍逐模块总权重/加权中心完全压缩。监督与标签不进入网络。F保留历史C3暖启动，因此并非所有ML参数从随机初始化训练。
