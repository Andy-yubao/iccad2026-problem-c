# E102重新设计：模块身份图片与迭代掩码生成

日期：2026-11-06。用户已要求重新设计模型和Loss，允许采用diffusion。此次实施新模型／Loss及针对已发生失败的有界单训练图拟合检查；旧16k运行仍暂停，STOP保留。本文件不授权正式长训练。

## 问题与目标

原RGB回归器在第2轮主要画出了灰色外形和背景。它没有达到“图片像reference、内部边界分明”的目标。不能靠参数数量或能输出512像素来证明学习能力，也不能把这次失败等同于所有图像生成模型不可行。

目标不变：原始面积／原始reference，公开输入到图片，不读取测试，不做MIB同形、矩形／矩阵提取、几何修复或Q。继续使用v5冻结成员、公开画布canvas_v2与逐模块端口总权重／加权中心。reference自由位置只生成监督图片；不存在旧模型暖启动。

## 1. 图片表示

每个像素预测背景0或模块i+1；用固定模块ID颜色直接显示整张图。不回归连续RGB，不把颜色平均化当作模块正确，不从输出识别矩形或恢复坐标。

训练标签由原reference矩形在512画布上直接按像素中心栅格化，不从旧RGB图反推身份。没有人为放大小模块、缩小空白、根据reference外框重缩放或投影成矩形。小于一个像素的模块可能无法表达，此问题仍属分辨率限制，不能静默修改原数据；正式缓存应记录未覆盖任何像素的模块。

## 2. 模型

- 6层192维关系Transformer编码模块公开属性、模块身份与连接／分组／MIB关系。它不强制同MIB形状相同。
- 残差U-Net保留512／256／128／64／32空间特征与skip connections，通道48／64／128／192／256。
- 在128、64、32及解码128、64层做图像到模块cross-attention。512层像素描述符直接与每个模块的条件key匹配，得到模块类别logits；不会只在低分辨率注入条件再用全局池化控制细节。
- 约1281万参数，从头初始化。增大容量是组合设计的一部分，不据此声称容量已充分，也不把多因素改动归因为单一结构收益。

## 3. 从空白开始的生成与去噪

采用MaskGIT式迭代掩码生成，属于离散图片去噪路线；没有实现DDPM高斯噪声过程或完整D3PM变分下界，不将它们混称。

训练有两个状态：全像素MASK，以及随机掩掉部分像素的reference标签图。后者是去噪生成模型的训练变量，绝不是公开条件里的reference；采样函数只接收公开条件，从全MASK开始，完全不接收reference参数。

每次更新对同一题同时计算两个视图的Loss，并各以0.5权重累计梯度后做一次Adam更新。随机遮罩比例用余弦分布，另保留25%全遮罩。每步明确包含全空白生成任务，避免只学会利用已知像素补图而从空白生成仍然失败。

采样固定16轮：预测模块类别，按置信度和余弦日程保留／重掩码，并允许纠正先前生成的像素。随机提案温度逐步降到0，最终argmax。固定seed0；不用reference从多个种子中挑最好的一张。所有操作均在图片像素空间内，没有几何后处理。

## 4. 固定Loss

设单状态损失为J，则每题总Loss固定为：

`L = 0.5 J(全MASK) + 0.5 J(随机MASK)`

`J = L_ID + L_Dice + 0.2 L_boundary`

- `L_ID`：只对被破坏像素计算类别交叉熵；先分别在每个前景模块内平均，再在模块间平均，另加0.25倍背景平均。小模块不会按像素数量被大模块和白底淹没。
- `L_Dice`：每个可见前景模块独立计算soft Dice，再在模块间平均，要求预测像素区域与该reference模块重合。
- `L_boundary`：由相邻像素类别概率直接计算类别不同的概率`1-sum_k p_k(u)p_k(v)`，与reference相邻像素是否异类做边界／非边界平衡BCE。它的梯度直接进入模块概率图，没有一个可以与实际模块预测脱节的独立边界头。

反传、正式train/dev监测、best、LR和早停必须使用同一双视图总Loss。监测随机遮罩使用成员派生的固定种子，不随轮数重新抽样；正式方案仍固定train/dev各500。RGB误差、模块像素IoU和图片仅辅助解释，不另选checkpoint。未对dev扫权重。

## 5. 已实施的必要验证及范围

先在同一冻结train_monitor成员上进行512像素、有步数／时间上限的拟合，目标是验证能不能学出模块图片，而非再次只验证一次参数更新。

初版v2的250更新检查未通过：全遮罩模块平均IoU0.551，16轮生成0.377。原记录完整保留于`runs/20261106_semantic_v2_fit1`。据此登记v2.1：每步增加成对全遮罩监督、把边界损失直接接入模块概率，并允许采样修正旧像素。没有增加训练成员或用dev选择这些修改，也没有重复无限训练直到成功。

修订检查固定250次更新或180秒先到为止，仍只用原来这一张21模块训练图；最终指标为唯一检查终点，不按中途最好值交付。全遮罩模块平均IoU>=0.75只是一个必要拟合条件，仍需人工看边界与采样图；即使通过也不能宣称未见实例有效。此处未进行任何正式16k长训练。

## 6. 正式训练前仍缺什么

修订检查已完成：250更新、约116秒，单训练图全MASK Loss5.2704→0.4591，模块平均IoU0.0018→0.8245，前景像素准确率0.0847→0.9178。模块分色已恢复，但边界仍弯曲。相同最终权重的16轮采样IoU只有0.5777，比全MASK单次输出差，因此当前默认直接输出，不把迭代分支强行作为正式生成路径。这是训练侧拟合证据，不证明未见实例有效；也不支持对diffusion整体作否定判断。

必须先依据本轮拟合结果判断生成是否确实可用，不能只看训练Loss下降。下一次如明确授权正式训练，应登记独立新run、完整固定监测、唯一best和同100例固定seed图片。新模型与RGB旧权重不能混称同一运行；旧STOP不移除，不自动追加候选。

输入可能不唯一决定某一张reference；迭代生成改善清晰度也未必改善与指定reference的匹配。单图拟合只证明基本可拟合性。数据泛化、背景面积影响、成员历史筛选及新像素目标与旧RGB目标的差别仍需披露。

## 阅读依据

- [MaskGIT: Masked Generative Image Transformer](https://arxiv.org/abs/2202.04200)：训练预测被遮罩token，推理从全空白开始迭代生成。本实现直接用模块ID像素，不使用其学习式VQ tokenizer，不声称复现原架构。
- [Masked-attention Mask Transformer for Universal Image Segmentation](https://arxiv.org/abs/2112.01527)：借鉴模块query与像素特征匹配、在多尺度上注入条件；不声称直接套用Mask2Former即可解决本题。
- [Structured Denoising Diffusion Models in Discrete State-Spaces](https://arxiv.org/abs/2107.03006)：离散状态与吸收MASK的生成建模依据；这里只借鉴离散去噪思路，没有报告D3PM似然或完整变分训练。
