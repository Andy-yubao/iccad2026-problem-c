# 固定后处理器下的训练目标研究建议

日期：2026-11-05。本文是供后续决策的研究设计，未登记或启动任何新训练、搜索或评价任务。

建议优先研究**根据真实后处理反馈学习局部下降方向的可微Loss**，同时用**真实Q的黑盒梯度估计**作为小规模对照。若希望最终仍得到现有十项的固定系数，再研究**按训练效果学习Loss的双层优化**。第一步应检查后处理对草稿的可利用敏感性，而不是立即进行又一轮完整训练。

## 1. 现有证据支持什么

同一原dev500、同一E98固定计算深度后处理，Q越低越好：

|冻结模型|加权Q|平均Q|混合Q|最终硬合法|
|---|---:|---:|---:|---:|
|E98增强best71|1.043560018|1.050714113|1.047137066|500/500|
|第一轮拟合Loss续训best29|1.040796990|1.052651602|1.046724296|500/500|
|位置/形状系数各乘0.75，best8|1.039699828|1.053338179|1.046519004|500/500|

最后一轮训练11轮正常早停、best8；新验证Loss从0.312567943降至0.309232669。混合Q比父模型低0.000618062，平均Q高0.002624065，最坏5%平均Q从1.402098166升至1.418987865。单次单seed的微小混合收益不能证明稳定改进，也不能据此声称完全没有效果。两个候选均比冻结父模型多训练，缺少等训练量原Loss控制，无法分离系数改变与额外训练的影响。

跨题全局统计的600检查样本中，原Loss/全局拟合Loss的Pearson分别为0.2530/0.2585，Spearman为0.3250/0.4563；新全局系数尚未进入训练。这表明值关联有所改变，不能据此推断训练梯度更好。

旧40题局部诊断中，第一版Loss在0.002步长下40/40例Loss下降、混合Q平均变化-0.001042820；在0.01下39/40例Loss下降，混合Q反而变化+0.000195193。原Loss两种步长的混合Q变化均为正。这是针对这一组草稿/方向的证据，不证明所有Loss或所有步长都失败，但足以说明**Loss值下降与最终Q改善之间尚缺少可靠的方向联系**。

历史E97也已试过教师接触关系、动态MST、释放教师指定轴及更完整教师几何监督；效果并不单调。其后处理配置和指标与本次不同，不能直接横比Q，也不能把“再蒸馏一次完整解”视为未经尝试的新机制。

## 2. 准确定义要优化的量

设公开问题为x_i，网络原始输出为z_i=f_theta(x_i)，原解码为D_i，固定后处理为P_i，逐题中性时间官方成本为q_i。真正目标是：

    F_i(z) = q_i(P_i(D_i(z)))
    J(theta) = sum_i a_i F_i(f_theta(x_i))
    a_i = 0.5/N + 0.5*exp(n_i/12)/sum_j exp(n_j/12)

这里混合Q是整个面板的聚合，不存在独立于面板权重的“逐题混合Q”。训练面板及评价面板分别计算各自的固定归一化权重。若训练均匀抽题，可将逐题Loss乘N*a_i再做batch平均；不应每个minibatch重新归一化exp权重，否则期望目标会改变。若改变抽样分布，须使用对应的重要性修正。

Q标签可按原评分器使用训练题reference和分母，网络与下述代理网络的输入只读公开规格、允许草稿；reference和评分分母不进入它们的输入。P_i使用E98.depth_budget.v1的冻结源码、计算预算、数值路径和硬检查。时钟仅计时，不参与质量标签；批量并行吞吐与单例完整延迟分开。

现有标量Loss值缺少几个层面的信息：

1. 题目难度及约束数量可以同时推高Loss和Q，形成跨题关联，却不给同一模型的更新提供改善机制。
2. 十个标量无法完整描述位置排列、分组连通、锁定模块、邻接与后处理路径；相同分项值可能对应不同最终Q。
3. 固定后处理包含离散选择、条件分支和保留最佳解，F_i可能出现平台、跳变与不同吸引区域。普通反传穿过几何代理，并不等于穿过P_i。
4. 即使单个草稿的坐标下降方向有用，共享网络参数的一次Adam更新也可能使其他题变差；必须再验证实际网络更新。

原先“多样草稿+数学统计”的想法仍有价值。需要把数学目标从拟合静态数值，推进到学习**改变输出和训练模型后，真实Q如何变化**。下面的同题正负扰动是控制问题差异的敏感性测量；总体目标仍是跨题加权平均Q，不恢复旧的同题排序选模目标。

## 3. 共用的第一步：先测草稿是否还有可利用的改善方向

建议未来执行时新冻结100道训练题，覆盖N和公开约束类型；不动原split和旧冻结面板，不用dev/test选择方向。它们对E98源网络不是未见训练数据。实施短检仍最多5题，正式100题面板另行登记。

从E98增强best71的每题草稿出发，对自由中心与自由log长宽比进行扰动。固定形状只锁形状通道，仍允许其公开自由位置变化；预放置锁整模块，padding不参与。通过原D_i保持面积和精确锁定值。所有坐标按公开尺度归一化；XY交换必须同步变换固定位置、固定形状、mask、边界位及端口。

建议每题8个预登记方向、3个半径、正负两侧及中心，共49次后处理，100题最多4900次。方向包括独立随机扰动与整组移动、近邻分离、边界滑移、形状等结构扰动。结构方向用于机制检查；只有符合指定高斯采样分布的方向才用于后述无偏平滑梯度公式，不能混为一谈。半径可从公开归一化空间的0.002/0.01/0.03起，属于待登记起点，不是已证明最优值。

保存每次原state、解码几何、最终几何、q及其分解、合法性、solver路径和计算次数。回答：

- 不同半径下，最终Q完全相同的比例与跳变尾部有多大？
- 哪些结构扰动更常产生改善？是线长、面积、边界、分组还是MIB改变？
- 有限候选中最好草稿能改善多少？这是离线选优的乐观参考，不是部署成绩、模型可学习性证明或全局最优界。
- 现有十项梯度能否解释这些变化？方向对步长是否敏感？

若只有很少方向有效，先调整扰动表示或尺度，检查后处理是否抹除了大部分草稿差异。不能因一次随机探测失败就宣布没有可学信号；同样，也不应在没有方向证据时投入多轮完整神经训练。

## 4. 方案A：学习能够指导优化的后处理感知Loss（推荐主线）

训练一个可微条件函数h_phi(x,z)，预测固定后处理后的成本或其平滑版本。输入包含公开问题图和当前完整草稿：模块面积与锁定标记、位置/长宽、相对间隙、连接、分组、MIB和边界要求。现有十项可作为辅助特征，但不构成全部输入；不使用模型来源ID、题目ID或reference作捷径。

关键不是把全局线性回归简单换成大网络。代理必须接触当前草稿附近的反事实变化，并接受下降方向检查。

**数据与拟合。** 第一轮建议新1000训练题，每题以增强best71为中心，8个方向、2个固定半径、正负扰动加中心，共33,000条标签。按题目隔离600拟合/200设计调参/200终末内部检查，所有邻近草稿与增强归同一题；不复用已曝光旧检查集充当新检查集。这个规模只是建议预算，不承诺足以训练出可靠代理。先以100题检查确定可用尺度，再冻结一次正式设计。

在标量成本拟合之外，加入局部差分约束，例如：

    dF = [F_i(z+sigma*u)-F_i(z-sigma*u)]/(2*sigma)
    dh = [h_phi(x_i,z+sigma*u)-h_phi(x_i,z-sigma*u)]/(2*sigma)
    L_fit = value_error + beta * mean((dh-dF)^2)

较小尺度下这约束代理的方向导数；有限尺度下它约束实际区间变化，不能当作不连续F_i的精确导数。对高斯平滑版本可进一步使用方案B的梯度估计监督代理梯度。beta、尺度和归一化只在训练侧设计区确定，不使用dev扫描。初期可选小型图网络；模型复杂度应由留出方向效果决定，而不是由训练R²决定。

**使用。** 冻结h_phi，定义该训练阶段固定Loss为sum_i a_i h_phi(x_i,f_theta(x_i))。若需要原监督作稳定项，必须在阶段开始前登记固定系数，并在反传、监测和调度中完整包含它；不能训练时加一套、选模时省略。保留原解码与更新门禁。h_phi只用于训练，不进入最终部署求解链路。

**防止走出拟合范围。** 先在事先规定的小邻域内做短续训，记录输出偏移和代理误差。若模型已经离开覆盖范围，结束该阶段，采集新的训练侧真实标签，冻结新版代理再另登记下一阶段。不能在同一Loss身份中悄悄在线改代理权重，也不能因预测Q低就接受没有真实评价的新分布草稿。

**进入长训练的依据。** 未参与拟合的题目上，按代理梯度走两个预先固定步长，实际混合Q均下降，并优于同尺度原Loss方向和随机方向；再验证实际Adam更新。报告幅度、置信区间和高尾，不能只报符号准确率。终末还要通过冻结模型的dev500；代理下降本身不代表成功。

这条路线与LODL、ZeroGrads的思想相近，本文提出的是适配本项目的方案，尚未复现其算法，也没有这些论文在本问题上的效果保证：

- [LODL，NeurIPS 2022](https://papers.neurips.cc/paper_files/paper/2022/hash/0904c7edde20d7134a77fc7f9cd86ea2-Abstract-Conference.html)：通过黑盒优化反馈学习决策相关Loss。
- [ZeroGrads，作者项目页](https://mfischer-ucl.github.io/zerograds/)：用局部平滑的黑盒目标学习可微代理；原方法在线更新，若借鉴，须按本项目固定阶段边界适配。

## 5. 方案B：直接用真实Q估计梯度（小规模必要对照，也可独立发展）

这条路线直接优化后处理结果，不要求先找到能预测Q的静态公式。令z为自由通道的公开归一化坐标，高斯扰动u~N(0,I)只作用于这些通道，D_i包含所有约束还原和截断：

    F_i,sigma(z) = E_u[F_i(z+sigma*u)]
    g_hat = (1/K) sum_k {
        [F_i(z+sigma*u_k)-F_i(z-sigma*u_k)] * u_k / (2*sigma)
    }

在相应可积条件下，这是高斯平滑目标关于z的梯度估计，不需要对P_i求导。将g_hat作为外部输出梯度，经过网络Jacobian反传到theta；无需对百万维网络参数逐一扰动。若使用其他方向分布、低维结构子空间或改变缩放，梯度公式必须对应修改，不能仍声称估计同一个全空间高斯平滑目标。

实现可用局部线性反传载体sum(stop_gradient(g_hat)*z)，但其数值不是可比较的训练Loss。真正定义、train/dev监测、best/LR/早停必须使用预登记的加权F_sigma估计，不能用该线性载体值调度。固定验证噪声种子以减少监测噪声；这是一个需单独登记的真实Q平滑Loss阶段，不是终末评价后偷偷按Q重选checkpoint。

优点是更新直接接受真实后处理反馈，可检验方案A有没有学到错误方向。缺点是每个样本需要2K次真实求解，高维估计方差可能很大。正负配对减少部分波动，不能消除方差或保证下降；四路并行也不会减少总调用数。

更关键的是，优化F_sigma不等于优化部署时无扰动的F_i(z)。固定sigma的初轮必须同时检查未扰动草稿，防止只改善“加噪声平均表现”。sigma太小会落在Q平台，太大会改变布局结构；选择尺度需要训练侧方向证据。若后续改变sigma，要重新登记阶段。

建议先给独立的小调用预算，验证输出梯度与实际网络更新是否可用，不直接铺开train16k。以K=4算，完整16k一轮就要128,000次后处理，按已有约0.2秒/例仅作量级推算约7.1 CPU小时，四路理想约1.8小时，尚未含初始化、通信和尾部；实际样本与运行路径可能不同。这个量级说明它适合作为可靠信号来源和方法对照，能否成为主训练取决于样本效率。

方法依据：[Evolution Strategies](https://arxiv.org/abs/1703.03864)、[Differentiable Perturbed Optimizers](https://arxiv.org/abs/2002.08676)。前者说明黑盒反馈可以用于优化，后者说明扰动可用于连接不可微决策与学习；本项目的具体估计器及固定后处理适配仍需自行验证。后者的结构化优化理论条件不能直接移植给任意启发式P_i。

## 6. 方案C：按实际训练效果学习Loss（若仍希望输出一套系数）

用eta表示Loss参数，可先限为现有十项的正系数，固定总体尺度，避免把整体放大Loss误认作学习率或权重改进。内层用候选Loss真实更新模型若干步，外层评价更新后的模型：

    theta_T(eta) = T步固定训练更新(theta_0, L_eta, 内层训练题)
    M(eta) = sum_{i in 外层训练题} a_i F_i(f_theta_T(eta)(x_i))
    eta* = argmin_eta M(eta)

这才直接对应“用该Loss训练后是否更好”。它与E98整支训练试验的差别是：每次比较来自相同theta_0/Adam状态/数据顺序的短、受控训练，尽量估计外层改进方向并累计统计，不为每个系数组合付出一次完整早停费用。

训练侧内外题分离；外层不是封存test，也不拿反复使用的dev500扫eta。相同状态出发的正负Loss扰动必须各自隔离保存。先用方案B的g_hat或已通过方向门槛的代理，把外层信息传过T步更新；若直接有限差分eta，则仍要付出多次短训练成本。真实Adam、动量、梯度裁剪与相对步长保护都可能改变方向，不能把普通SGD的解析结果当作当前训练器结果。

还可先做一个更便宜的表达能力诊断：把十项Loss在相同网络状态和batch上的参数梯度组成G，查看非负组合G*w是否能对齐真实Q估计梯度。若即使允许逐batch选择最有利系数也很难对齐，固定全局系数更受限，应优先增加目标表示。该诊断受估计噪声与当前状态限制，不是十项Loss永远无效的证明。

短T带来短视偏差。必须在不同训练起点、题目组和至少两个预登记训练长度上检查外层方向；不能因几十步有效就承诺收敛后有效。最终冻结eta，按同一Loss正常训练、监测、选best和早停，再做一次真实dev500。若外层长期需要更大容量的eta，可能不如直接采用方案A。

这条路线概念上最贴合“寻找训练目标”，但工程复杂、成本较高，而且若仍限于十项系数，无法摆脱该特征族的表达局限。建议在A/B给出可靠的外层信号后再投入。[Meta-Learning via Learned Loss](https://arxiv.org/abs/1906.05374)提供了按模型训练效果学习Loss的相关思路；本文的不可微P_i需另行处理。

## 7. 教师蒸馏可以作为备选，但需换一个可检验机制

若训练题上已经搜到可使P_i获得较低Q的输入草稿z_i*，可以用这些**后处理前的草稿**作训练目标，再检验模型能否保留收益。这能把昂贵搜索摊销成便宜监督。

不应直接认定P_i(z)就是最理想的网络目标：P_i未证明幂等，P_i(P_i(z))可能变化；不同好布局的坐标均值也未必好。历史E97完整教师几何监督并未稳定改善结果。因此若研究，应先确认z_i*的真实输入收益、约束可表达性及多解问题，再比较蒸馏后Q，不能仅报告坐标误差变小。这条路线可与A的数据生成共用，但不是当前首选。

同样，直接把现有后处理全部“展开成可微网络”不是低成本捷径。现有P_i包含启发式分支、离散关系和不同数值求解；只微分其中一个固定关系投影并不等于微分完整P_i。[Blackbox Combinatorial Solvers](https://arxiv.org/abs/1912.02175)所述线性目标求解器条件也不能自动满足。可微重写若改变前向结果，就需要新的研究边界，无法继续称同一固定P_i。

## 8. 建议的推进顺序和判据

|阶段|要回答的问题|建议投入|进入下一步的依据|
|---|---|---|---|
|0：当前证据复核|改善是否真实、幅度多大|只读已有结果，本次已完成|明确微小混合收益、平均Q退化、无训练量控制等限制|
|1：局部响应面|草稿附近有可利用的Q改善吗|新100训练题，最多4900次求解，CPU四路|有效方向与尺度可复现，量级值得继续；不是只看候选最好值|
|2：方向学习|代理能否建议正确更新|A的训练侧数据与B的小对照；题目隔离|未拟合题真实下降、两种步长检查、实际网络更新方向通过|
|3：单路线训练验证|能否把方向转成模型泛化收益|固定一套目标、E98增强同起点，正常早停|冻结own-Loss best，一次同dev500真实评价|

阶段3应从同一E98增强best71起步以减少变量；先不把从头训练、扩容和新Loss捆绑。若方向和续训收益稳定，再另登记随机初始化验证Loss是否依赖父模型。每个阶段事先固定数据、Loss、LR、min_delta、预算与停止规则；长任务授权后才启动，不因本文建议自动扩展候选。

主要指标始终是混合Q，三Q全部报告。平均Q与加权Q可以产生取舍，只要混合Q定义固定，单项变差不自动否定目标改善，但必须如实说明。硬合法、回退、P95/最坏5%/最大Q、按N及约束类型的变化、草稿重叠/外框/空白和完整时间用于解释与风险判断，不偷偷变成另一套选模分数。

建议预先设置实际收益门槛，例如混合Q超额部分(Q-1)至少下降5%；相对当前基线约需下降0.00236。这只是避免追逐极小波动的实用建议，不是已计算的显著性阈值。配对题目区间、配对seed和自适应曝光限制分别报告。dev500已多次使用，不能称全新未见面板；原test继续封存。

训练量控制与冻结父模型用途不同：父模型回答“是否比现有模型好”；等更新量原Loss续训控制回答“收益是否来自新的目标”。所有控制也必须事先固定自己的Loss-best规则，不能从历史多份结果中事后挑最有利对照。报告实际更新、GPU时间、后处理调用与总墙钟，比较单位计算的真实Q改善；四路吞吐不冒充单例延迟。
