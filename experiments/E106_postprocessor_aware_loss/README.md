# E106：后处理感知的可微Loss

**2026-11-05完成状态：25000份标签、单个代理训练、check1000与只读诊断均已结束。** [结果检查](runs/20261105_bank25000_seed0/result_review/report.md) · [完整自动流程状态](runs/20261105_bank25000_seed0/autostart_state.json)。check方向准确率47.06%，不支持直接接回布局训练；没有布局训练或待自动执行阶段。下文准备/授权/入口记录历史身份，不重复运行。

用户授权独立实施方案一，最新规模为**5000题×每题5份，共25000份草稿**，网络约200万参数。用户随后明确授权数据生成完成后自动启动一个代理训练；布局模型训练仍不启动。原16000份/大网络准备稿保留在revisions，仅现行v2有效；原实验与运行不修改。

这是一个预测固定后处理成本、并提供局部下降方向的图网络。输入为公开问题图、端口压缩摘要与当前完整草稿，不读reference、目标坐标、评分分母或模型来源ID。模型按逐模块总权重/加权中心读取端口；标签仍由完整公开连接的官方评分计算。输出为Q及辅助物理指标，输入几何可反传；部署布局器未来可以把冻结后的Q预测作为Loss。当前代理已完成26轮训练、best7；数值拟合有限改善，局部方向未优于基准，尚无改善真实Q的效果结论。

## 网络

- 宽128、8层、4注意力头、SwiGLU隐藏320、读出宽256。
- 完整草稿几何进入节点及成对偏置；wire/MIB/group分支分别pre-norm与门控，无未归一化消息残差。
- 2个可学习池化查询加mean/max读出，兼顾整体和局部尾部。
- FFN Dropout=.10、残差Dropout=.05；同题5份草稿共享mask，避免局部差分被独立Dropout噪声淹没。
- 具体参数量由preflight.json的实际实例统计给出，不能仅按宽度估算。

## 草稿和分片

从原train16k中，排除E103旧1000和全局统计2000题后，固定seed抽5000道不同题。每题来自3个成熟模型的3份原稿：E98增强best71、新Loss best29、reference075 best8；再绕其中一个原稿做正负扰动。扰动中心在三模型间轮换，一半高斯方向、一半分组/边界/邻近簇/形状方向，半径.005/.010/.020/.030按固定规则均衡分配。总计15000原稿+10000扰动。来源权重均已正常结束训练，属于相关模型的成熟分布差异，不宣称三个独立随机seed。

固定形状模块仅锁形状，预放置模块锁整个位置与形状；原解码保持面积与公开规格。XY交换不复用原Q，因为固定启发式后处理未证明XY等价。

按题目分成3000拟合/1000内部验证/1000最终检查，对应15000/5000/5000份草稿。同题全部关联稿始终在同一片。这些题都在来源网络的训练历史内，检查集只对代理拟合未见，不是布局网络的未见验证或封存test。原dev/test不参与数据建立。

每份草稿经独立冻结副本E98.depth_budget.v1得到真实Q；不复用旧草稿/Q，不改后处理，不把墙钟纳入标签。四个单线程CPU任务处理数据。五例短检的25份正式标签直接计入25000，不重复求解。

## 固定拟合目标

Q数值平方误差＋一对局部对称差分斜率误差＋0.1×辅助指标误差。辅助项为有符号HPWLgap、area gap和soft违规率。所有尺度仅由fit3000拟合一次并保存，不截除高Q或Q=1平台。按一半样本等权、一半exp(N/12)权重聚合；分片归一化常数固定于整片，不按minibatch重新归一化。

未来反传、监测、best、LR与早停共用这一完整拟合Loss。内部验证1000负责选唯一best；不按Q重新选checkpoint。正常结束可只读检查1000已存标签，输出结果后停止，不自动训练布局器或追加真实求解。代理拟合好不等于其梯度能够改善真实Q，后续另需方向与真实网络更新验证。

- 停止数据：实验目录STOP或本run/STOP；当前求解返回后保存已完成标签，后续求解停止。失败保留数据并阻止后续任务，不自动重试。

独立复制数值源码与打包推理权重的来源/哈希见copy_provenance.json、model_manifest.json。运行不跨实验导入私有算法。所有阶段身份、面板与计划保存；本实验没有恢复旧E98搜索。
