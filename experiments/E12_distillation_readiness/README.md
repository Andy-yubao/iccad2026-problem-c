# E12：教师—学生表示—轻量投影的蒸馏准备

2026-10-18。用户要求继续研究，直到有充分依据开始蒸馏；同时关注重叠和留白的真实作用。E10维持冻结，E11历史不改写。本实验独立维护算法，复制来源见[provenance.json](provenance.json)，仅复用datasets/scoring/visualization。不恢复已停止的occupancy/rectangle训练。

## 预先固定的问题与成熟标准

1. 以固定宽高、固定分离关系的小型LP代替迭代锥优化，主要修复位置和数值接触；比较旧规范化与带完整分离约束的规范化，检验新重叠来源。
2. 对照目标面积、允许面积下界、可学习合法面积三个尺寸表示，区分表示失配和模型误差。当前E10多数自由块接近面积下界，但公开固定/MIB规格仍须独立满足；不凭经验统计强行改变官方面积规则。
3. 在主dev100筛机制，冻结后用既有另一组dev100检验，不读local_test。两组都参与过开发，不能称独立测试。默认先用最多5例机制检查，未见信号不扩大。
4. 理想输入准备门槛：两组均100%硬合法；平均Q不高于各自冻结教师+0.002，P95不高于教师+0.01，最大Q不高于教师+0.05；平均修复/通信≤0.35秒，另为未来学生网络预留0.10秒，时间P95完整报告。不是正式比赛分数。
5. 检查有限误差容忍度：中心按局部块尺度、log长宽比注入固定seed0的0.5%/2%/5%噪声；关系由噪声几何推导与直接提供教师关系分开。至少2%档须保持100%硬合法、平均Q≤教师+0.005、最大Q≤教师+0.15，失败/回退≤1%。受控噪声不能替代真实学生误差，达到门槛只意味着值得开始训练。
6. 只在上述信号成立后准备训练集教师标签的小规模生成和可恢复全量命令；标签/梯度只来自冻结train工作集，dev仅计分，不读取测试。预计超过20分钟的完整教师库/训练仍只交用户命令，不自主启动。

## 研究与预算

先实现近草图投影、约束感知数值接触与输出表示；记录原始草图重叠面积/模块面积、bbox内部留白、接触结构、修改幅度、最终Q与实际耗时，不能用“少重叠”代替质量/速度改善。规则、噪声和面板在查看对应结果前固定；只做必要归因，不按胜负删样例。

本轮累计训练/推理计算保护1100秒，包含各阶段与预热、评分，不通过新目录重置预算；不够完成时保留部分证据及命令。新算法功能检查最多5例；扩展评价是用户明确授权的蒸馏准备研究。所有输出归runs，新运行拒绝覆盖，源码快照/命令/版本/种子/数据路径/冻结哈希随运行保存。

## 实际教师结构证书（扩展扫描前固定）

第一轮dev100暴露出近邻接触树和MIB尺寸选择的失配，因此新增certified对照：从冻结教师提取实际相接的分组接触生成森林、已满足边界的标记、MIB形状类别。学生将来需要预测这些信息；本诊断直接提供正确标签，不能算学生表现。联合投影对这些实际接触及边界施加约束，MIB按类别协调；不再把几何近邻误当作教师接触。geo组仍从扰动草图推导全体分离方向，teacher组另提供教师分离方向；两组都获得上述结构证书。形状类别按8位小数提取以避免把近似相同形状强制合并。

certified五例机制检查已完成；随后保持九组接口、噪声、预算和成熟门槛不变扩大dev100。所有旧运行保留，新增元数据fixed_shape与joint实际值一致，旧快照不改写。

certified扫描中，下界面积零噪声dev100平均Q=1.211558，全部硬合法且无行排回退；但噪声组出现数值接纳失败。五例反例审计发现微负坐标、面积下界微小越界以及精确浮点接触失连。新增一次局部LP精修：宽高仅允许相对1e-5调整，以倒数割线内近似保证面积下界；接触法向采用2e-7物理重叠，全分离允许4e-7，均处于原1e-6硬检查容差内部，原硬守卫不变。它修正几何而不修改计分。SOCP的较粗解仅能作为LP输入，不能绕过最终严格检查。

该机制在固定五个实际反例（worker1/2/3/4/7）的零噪声、2%几何/教师分离三组中无回退。下一阶段固定下界面积，对dev100验证0/0.5%/2%/5%几何噪声及2%教师分离五组；成熟门槛不变。此前否定的精确面积/教师面积表示仍保留全部结果，不重复扩大。

## 固定形状门槛检查后的机制修订

初始5例中，将教师合法面积下界从约0.990001提高到0.990002使固定宽高LP不可行；原教师自身能通过同一LP，排除基础模型完全不可用。第二次将float64解码下界改为0.9900002后，下界表示5例均不保留行排，但精确面积仍全回退，部分软接触损失仍存在。原记录不改写。

因此新增一次局部SOCP投影[joint.py](joint.py)：在近草图位置/形状的信赖域内允许宽高小幅修复，以精确凸面积下界和保守上界保证官方面积区间；无HPWL目标、无迭代搜索或拓扑更新。形状L1改变量权重大于坐标，公开MIB兼容尺寸继续协调。对照固定形状LP，检验“形状微调确实必要”而非继续精调惩罚。

新数值接触投影若失败，旧规范化作为独立候选仍须通过全部原硬守卫才可使用；不因为新算法名称而丢弃有效参照。累计预算另保守计入10秒单例LP排错费用，各阶段不重置1100秒上限。

局部SOCP在同5例中消除了精确面积固定形状LP的不可行性，下界面积接口没有行排回退。开始dev100前固定：低面积表示使用float64的0.9900002A；公开MIB若存在多个合法刚性尺寸，按预测长宽比选择最接近者，不任意取第一项。单例数值排错累计预留费用上调为20秒，覆盖已执行的两次单例检查。

dev100扫描固定9组（精确/下界/教师面积的零误差、下界面积提供教师关系、下界几何0.5%/2%/5%噪声、下界2%噪声提供教师关系、教师面积2%噪声），均使用一次局部SOCP＋合法候选池。不在中途按结果修改参数；失败照常计入。当前阶段不运行训练。
