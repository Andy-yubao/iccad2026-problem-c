# 准备诊断，不是正式实验结果

- `e119_stride2/`、`e120_stride2/`：只用原五个缓存训练成员的可丢弃短跑，验证连续3步与2步→SIGINT暂停→恢复第3步的模型、Adam、RNG、调度、排列/游标及投影逐位一致。诊断中的train/dev监测均来自这五个训练成员，不是正式dev面板。
- 四组各一次可丢弃受保护更新另记录在父目录`preflight.json`；共16次诊断更新，正式更新0。
- `queue_signal/`：真实控制器流程＋模拟工作进程；验证SIGINT阻断后续、显式恢复继续阶段。
- `evaluation_signal/`：真实评价控制流程＋完全合成的输入/模型/修复/评分替身；验证第1例提交后SIGINT暂停，恢复复用该文件并完成剩余提交。这里的500例、Q=1和合法标志均为控制流测试数据，绝不是模型质量评价；实际后处理/Q调用0、dev/test载荷读取0。
- `queue_signal_failure1/`、`queue_signal_failure2/`及`preflight_failure1.json`保留首次模拟器常量缺失和随后发现的恢复时间字段重复写入问题。修复后只重查受影响的控制器/评价流程，模型训练证明经源码哈希核对后复用，没有重复正式训练。

正式运行尚未创建；唯一正式入口为父目录README所列前台`run_queue --start`，后续用`--resume`。
