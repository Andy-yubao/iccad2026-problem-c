# E134每三层基线：阶段分工与拓扑形成

固定E119每三层best63（权重SHA256 `1f69a681713255a7adfca09357d70065ad7dff4d62f1a6294a7c233e30ad1df1`），同一dev500、299个源分片。补采既有S0及真实S1–S12、隐状态和实际注意力，不更改网络、权重、数据或后处理。所有末层与原评价逐位一致，已有15例的全部12层也逐位一致。原模型没有更新；线性探针只是按分片交叉验证的诊断拟合。

完整数据：[统计表](report.md)、[逐题逐层CSV](per_case_layers.csv)、[量化方案](plan.json)、[验证](verification.json)。

## 主要判断

结果支持明确的阶段分工：前两个全局块形成可读的位置关系表征，S1–S3把大部分宏观相对关系转成实际布局，S4–S12主要减少几何冲突并确定细分离方向。当前证据不能证明拓扑在学习上必然比几何修复困难，也不能直接证明前端欠缺拟合容量。

尤其需要区分“宏观关系基本成形”与“细拓扑完全定型”：前者主要发生在S1–S3，后者明显更晚。不能据此删除后九层。

## 1. 单独看监督层

S3/S6/S9/S12的完整原训练域Loss依次为 **.540194/.442186/.383794/.334363**，Reference项为 **.294003/.265442/.248095/.239745**，碰撞项为 **.161476/.098647/.067784/.030265**。它们呈连续改善。

S3→S12总Loss下降 .205831，其中碰撞下降 .131211，占 **63.75%**；Reference下降 .054258，占 **26.36%**；其他项合计约9.89%。因此后段的主要可见收益是削减冲突，仍有参考位置/形状改善与约束修正。

真实重复覆盖率 S3→S6→S9→S12 为 **16.087%→11.099%→8.397%→5.018%**。逐题最坏模块覆盖率的均值从 **95.961%** 降到 **33.042%**，不能仅按全局重叠率认为剩余冲突都轻微。组接触瓶颈从26.681%降到12.962%，Boundary要求边距从4.969%降到1.115%。HPWL/reference则从.970669升到.987929；各项并非同步单调变好。

组接触树直线候选受阻比例从S3的36.844%到S12的36.148%，参考布局约.495%；这个结构代理没有随全局重叠同步大幅改善。它只枚举既定三个直线移动分摊，不是所有路径搜索，不能把受阻率解释为不可修复比例。但它提醒我们：宏观方向/邻居已成形，不代表分组穿插等任务结构也已充分解决。

## 2. 把所有层一起看

S0到S12的平均Loss为：

`4.938188 → 1.570059 → .893110 → .540194 → .584229 → .543634 → .442186 → .520601 → .508240 → .383794 → .452651 → .372036 → .334363`

S4、S7、S10反弹分别为 **+.044035、+.078415、+.068857**；按299个源分片做2000次配对bootstrap，并对12步变化给同时95%区间，三次反弹区间分别为 **[+.039752,+.048318]、[+.072250,+.084580]、[+.064806,+.072908]**。这是面板上的系统性现象，不能简单视作均值噪声。

但Loss反弹不等于宏观拓扑重新崩坏：

- S6→S7：局部方向正确率下降 .234个百分点，K6邻居召回变化仅 +.020个百分点；真实重叠率还从11.099%下降到10.839%。Boundary项增加 .037650，是该步总Loss增量的约48%；F/P尺寸与P位置项也升高。
- S9→S10：局部方向正确率下降 .117个百分点，K6召回提高 .153个百分点；F/P尺寸项增加 .032089，约占总Loss反弹的47%。该步log形状改变量均值为 .2078，晚段中较大。
- 隐状态线性探针的方向准确率在这些位置没有同样的明显下降。例如S3/S4为90.209%/90.489%，S9/S10为91.214%/91.277%。这与“内部计算仍在推进、未监督读出临时变差”相容，但不是训练有意执行某条优化路径的证明。

前两层作用很大：S0→S1的Loss下降3.368129，S1→S2再下降.676949；前两层承担了本基线主要的布局生成工作。

## 3. 拓扑如何量化

在计算前固定了以下互补指标，避免把重叠率或精确接触直接等同拓扑：

1. **局部相对方向**：先用reference按模块面积归一的中心距离构造K6邻居对，再比较x/y相对顺序。参考近平局轴排除；预测方向不明确计为未正确。P-P对排除，防止只靠公开预放置位置抬高分数。邻居对在所有层固定。
2. **邻居结构**：预测中心KNN与reference KNN的逐节点召回。主口径K6，同时报告K4/K8，允许平移和统一缩放，不要求矩形已经接触或合法。
3. **分离意图**：按四方向有符号间隙推断当前最明确的分离方向；reference对角分离可允许多个方向，避免硬塞成唯一标签。模糊方向不从分母删除。
4. **终态稳定性**：在S12明确的邻居对上，检查当前分离方向与S12一致率何时首次达到阈值，且以后每层都不再低于阈值。它衡量“定型”，不保证S12本身优质。
5. **不依赖reference的任务结构**：组外框中的异组占据、接触树扫掠受阻、Boundary外侧模块比例等，防止把另一个合法优质排列误称为拓扑错误。

## 5. 隐状态与读出分开看

对非P模块，按源分片五折留出，拟合固定正则的线性映射恢复相对中心；每题等权、训练折独立标准化、不用Q或层号择优调参。

|S0指标|原始头中心，未做非负clamp|实际解码布局|隐状态线性探针，留出预测|
|---|---:|---:|---:|
|非P局部方向正确且明确|72.080%|74.703%|86.307%|
|非P K6召回|48.550%|46.967%|66.670%|

探针比S0实际布局的方向高 **11.60个百分点**（配对95%CI **11.03–12.18**），K6高 **19.70个百分点**（**18.91–20.46**）。原始头中心同样明显低于探针，所以不能仅归因于非负坐标clamp。S0训练标签乱序控制的方向/K6为40.438%/20.140%，远低于真实标签探针。

表征积累已经在全局前端发生：公开原始特征、编码后、全局块1之后、全局块2之后的非P方向探针分别为72.578%、73.898%、83.348%、86.307%。这支持S0前已有可恢复的关系信息。S1实际解码方向已达88.689%；S2之后原有非线性共享头在该指标上超过这个小规模线性探针。

这说明S0的可视布局差不能直接当作前端没有学会关系的证据。它尚不证明共享头容量不足；S0本身未被当作完整草稿监督，线性探针只是信息可恢复性的下界。

## 6. 其他参数与资源分配

- **参数**：输入＋两个全局块＋前三个几何块共252804参数，占全模型约35.49%；后九个几何块共454860参数，占63.86%。共享头与state embedding为其余部分。参数比例不等于计算量或任务难度。
- **隐藏尺度**：S0/S3/S6/S9/S12的隐藏RMS均值为2.285/2.722/2.843/2.763/2.963；对应逐题最大值约2.799/3.092/3.201/3.085/3.240，本次冻结前向没有显示数值爆炸。
- **隐藏参与比有效维数**：S0约3.70，S3约4.15，S12约3.32。该量只描述节点间方差集中度，不是64维表示的全部表达能力；不能据此判定容量用尽或表征崩塌。
- **注意力**：归一熵从全局块2的.945到S12的.561，但中间非单调。S7/S8较集中，S9/S10又变分散；熵不能单独作为拓扑质量指标。
- **局部梯度**：best63完整dev500均值Loss的前端参数梯度范数，乘登记权重后，L3/L6/L9/L12为 **.05686/.05986/.06587/.65931**。L12的范数约为其他三项范数之和的3.61倍。未监督S0不等于前端没有收到训练信号。该结果是eval局部导数，不是整个训练轨迹或Adam更新分配。
- **监督目标一致性**：共享头的四目标梯度余弦约.81–.94；前端中L6与L12余弦仅.116，但仍为正。这次局部诊断没有显示基线四个监督目标在共享头上直接相互对抗；不据此解释ABCD失败的具体原因。

## 7. 对下一步研究的建议

保留当前S3/S6/S9/S12监督和现有Loss作为控制，优先检验**固定总参数预算下，把后端部分容量转给初始全局块及前1–3层**。这样能检验资源分配假设，同时不把容量变化与新增S0监督混在一起。也应把粗结构读出与后续修正的功能适配列为待验证因素；S0探针结果使“已有信息如何有效转成布局”成为独立问题。

当前不宜把reference-KNN或方向保真直接升级为唯一Loss或选模规则。它们与既有最终Q有关联，但在控制模块数、重叠率和Reference项后，S12方向/K6的部分秩相关仅约+.054/+.084，未显示很强的独立解释力。它们适合定位阶段，不是最终质量充分代理。要证实“拓扑更难、增加前端资源会提高最终Q”，仍需后续受控实验；本次未启动任何新布局训练或后处理。

对已登记任务结构代理的次级检查中，S12组接触瓶颈与最终Q的Spearman约.397、部分秩相关约.335，同面板尾部50题AUC约.821；K6的对应尾部AUC约.721。它比单纯reference邻居保真更贴近本轮最终质量，但自身含几何距离并与评分Grouping约束有关，不能当作纯拓扑因果证据。它从S3到S12仍持续改善，因此面向任务的可拼合结构并未在前三层完全解决。后续“优秀拓扑”定义应同时保留宏观相对关系与分组/锚点兼容性。
