# 共同 dev500：Reference／S12草稿／原后处理逐题统计

只提供描述统计与数值表，不判断模型、后处理器或尾部问题的原因。

范围：E134 E119 每三层基线，E135 A/B/C，E136 D；各取原先冻结的 own-Loss-best，严格配对同一500题。已有每两层监督、E120和历史best55不纳入本轮。

- `summary.md`：全体适用题目的均值表，Reference在最左侧数值列。
- `index.md`：500题索引及原已存后处理Q；点击题号进入各题完整表。
- `tables/dev_0000.md` 等：每题的Reference、五组草稿和五组原后处理Loss拆项、几何与约束表。
- `all_cases.csv`：完整精度的5500个阶段记录，含逐题成员、模型、阶段和全部数值。
- `summary.json`：所有指标的有效题数n、均值、中位数、P95与最大值。
- `manifest.json`、`verification.json`：冻结来源、权重/记录哈希及核验；`losses/`、`geometry/` 保留中间统计证据。

## Loss口径

同时保留两套明确分开的口径。两者均使用 `public-priority-v1` 的同一组项和系数，不乘监督层权重，也不使用各组不同的训练聚合目标。总Loss拆成11个叶项：参考中心位置、参考形状(.25)、穿透深度、平均模块重叠负担、最大超10%负担、线长、紧凑、Grouping、Boundary、F/P尺寸、P位置。叶项之和须与总值一致。

主表为**布局域诊断Loss**：直接在实际Reference／已存S12草稿／已存后处理XYWH上计算同项同系数，公开面积、规格、参考监督和端口不变，不再对给定布局做decode或形状/位置clamp。任务项复用冻结函数的全部原运算，仅以不修改原模块的独立函数副本接入恒等解码器，已检查与原任务运算逐位等价；F/P尺寸项直接比较给定布局的log宽、高。该口径用于坐标层面的配对统计，不替换任何训练目标。数据在 `coordinate_losses/`。

另表保留**原训练域Loss**：S12草稿读取实际原始共享头状态，按原评价同一路径推理并逐例核对解码末层与原已存草稿逐位一致；reference使用缓存的参考目标状态；后处理则由已存XYWH重编码后代入原公式（包含原decoder限制，不能当作实际重叠率）。原始S12逐例Loss均值交叉核对原冻结权重的dev监测记录。数据在 `losses/`；两种口径均在CSV中以 `loss.*` / `training_loss.*` 区分。

## 几何口径

始终直接读取实际Reference、原草稿与原后处理坐标。沿用 `scoring/draft_geometry.py` 的既有实现，开启完整details，不修改输入面积/形状、不使用MIB。

- A=保存矩形面积之和，S=原公开面积之和，B=外框面积，U=精确矩形并集。重复覆盖为(A−U)/A；留白为(B−U)/B；同时报告A/S、U/S、B/S、B/Bref，避免只看重叠掩盖面积或留白变化。
- 逐模块覆盖率用该模块与“其他模块并集”的相交面积除以自身面积；另列成对交面积比例。该指标与训练Loss中累加成对交面积的负担不同。
- F/P尺寸误差为每模块宽、高相对误差的最大值，再在适用模块取均值/最大值。P位置保留原先左下角偏移/√规格面积口径，另列中心偏移。
- 组接触距离、MST瓶颈、异组占据、扫掠负担和受阻比例，以及边界距离/外侧模块/扫掠阻挡，全部沿用既有定义。接触代理要求共享边达到对应较短边的1%；路径只枚举固定形状的三个直线移动分摊，不冒称联合修复可行性。
- 后处理中心位移除以√原总面积，形状改变为绝对log宽高比差；Reference无后处理位移，记缺失。

各指标先在题内按原定义归一，再在有适用对象的题之间取算术均值；无对象留空，不补0。题内模块P95与最大值再取题均值，不同于把全部模块混池。CSV保留所有原始精度，展示表按单位格式化。

模型草稿/后处理Q、硬/软约束计数和完整耗时复用原记录。Reference按同一原面积/无MIB评分口径另算一次，未强设其Loss、约束、Q或几何为理想值。新统计耗时不混入原完整求解耗时。
