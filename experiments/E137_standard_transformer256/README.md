## 研究问题与结构

检验：在完整公开信息编码和可学习输入网络的支持下，一个宽而浅的标准 Transformer，能否直接生成有用的布局草稿，减少对逐层几何偏置、显式图聚合和中间几何反馈的依赖。

流程：公开题目 -> 确定性字段编码 + 可学习端口集合编码 -> 输入MLP -> N×256 -> 一个pre-norm Transformer block -> 最终LayerNorm和Linear(256,3) -> 全部模块中心位置及log宽高比。

Transformer：4头，每头64维；标准QK/sqrt(64)、softmax和V聚合；FFN为256→1024→GELU→256。attention和FFN各有正常残差与pre-LayerNorm。FFN激活后dropout=.10，两条残差分支dropout=.05；attention权重不额外dropout。最后输出层只调用一次，没有中间读出或全局均值拼接。

主体只接收h和valid。除padding mask外，没有外加attention bias；没有连接/分组矩阵乘隐藏特征的旁路，没有草稿几何、碰撞、gap、penetration、逐层解码或反馈。端口集合聚合仅编码公开端口输入，不聚合其他模块的学习隐藏状态。

所有模块包括F/P均预测，不覆写规格，不使用MIB。位置以公开总面积平方根归一化；最终用现有面积保持的三通道解码及独立后处理。

## 一次性公开输入编码

设N为有效模块数，A=sum(area)，L=sqrt(A)。128个地址槽足够覆盖当前登记N≤120的任务；超出上限报错，不能截断。N上限和字段范围在启动准备时核验。

W使用现有缓存wire_b2b的对称、每个原无向边贡献分半的约定，贯穿关系编码及统计；不另建不明缩放的权重定义。group只表示非零G标签相等，不把任意G编号大小作为连续特征。F/P信息严格按公开可用性mask，普通模块自由reference坐标和形状不进入任何分支。

### 1. 模块自身：20维

按以下顺序固定：

| 通道 | 字段 |
|---|---|
| 1 | area_i/A |
| 2 | log(N*area_i/A) |
| 3–4 | F、P两个标志 |
| 5–8 | L/R/T/B四个公开边界要求位 |
| 9–10 | F或P的公开w/L、h/L；其他为0 |
| 11–12 | P的公开中心x/L、y/L；其他为0 |
| 13 | F或P的公开log(w/h)；其他为0 |
| 14 | log1p(sum_j W_ij) |
| 15 | 正权重连接对象数/max(N-1,1)，不计自己 |
| 16 | 同组其他模块数/max(N-1,1) |
| 17 | log1p(本模块端口连接权重和) |
| 18 | log1p(本模块正权重连接的端口数) |
| 19–20 | 是否有正权重模块连接、是否有正权重端口连接 |

缺失字段靠公开标志区分，而非依赖特殊巨大数或参考几何填补。

### 2. 对象对应的关系：640维

模块地址one-hot128、有效地址槽mask128、连接行128（按行归一化）、连接行128（log1p原W）、同组关系行128，共640维。

关系行每列指向明确模块地址；one-hot身份与目的列采用同一双射。保留相对连接分配和绝对权重强度；无连接行归一化后为0。同组关系排除自己，空地址不视为有效无边模块。这里只编码公开事实，不把这些字段直接加进attention scores。

训练时，每个member、每个epoch用独立确定性RNG从128槽生成随机不重复地址，与dropout、样本排列和轴交换RNG分开。监测/正式评价使用登记的规范地址0..N-1。地址不是布局坐标，也不读取reference排序。

这种固定槽输入不保证对地址重新命名严格等变。增加一个预先登记的固定随机重命名dev500 Loss诊断，放在选定权重后进行，只报告敏感性，不做测试时集成、不按诊断重命名选模型。固定地址随节点一起移动时，单纯节点行重排应保持输出等变，实施短检须核验。

### 3. 端口分布：学习得到128维

复用全部有效pin_coordinates、pin_weights、pin_valid，而非只保留端口重心。每条正权重模块—端口关系输入(x/L,y/L,log1p(weight))，共享MLP：3→64→GELU→64。

对每个模块分别取权重归一化mean64和masked max64，拼为128维；空集合两者均为0。已连接端口逐个经过MLP，不截断、不仅取top-k。相同端口的重复连接按已有缓存规则先合并权重。mean/max是有限维压缩，不能宣称完整无损；它比单一重心保留更丰富的可学习分布信息。

### 4. 全题背景：8维

N/128、log(N)、log(A)、log1p(sum_ij W_ij)、正权重无向连接对象对数/max(N*(N-1)/2,1)、log1p(全题端口连接权重和)、F模块比例、P模块比例。

无向连接对象对数按i<j计，不将重复边当多个不同邻居；sum W沿缓存约定包含已汇总权重。以上背景向量重复附加到各模块，不增设全局attention token。

### 5. 输入网络

拼接20+640+128+8=796维，使用796→512→GELU→256→LayerNorm。输入MLP、端口MLP、Transformer和输出层均可训练。

按带bias的Linear和正常LayerNorm估算，总参数约1,335,363（约134万）；这是设计计算，实施后须以实际模型计数核对。可学习编码属于总模型，不称作免费embedding，其成本纳入训练及逐例推理时间。

## 为什么第一轮联合训练

全部网络从同一scratch seed0初始化，直接用最终布局Loss联合更新，不冻结输入编码，不额外预训练。

数值、类别、关系和集合输入都可以通过最终Loss学习表示，无需先获得外部语言embedding。当前也没有验证过的独立embedding目标。先做字段重构可能偏向地址和数值复原，先拟合reference坐标又相当于额外训练一个布局器，都不能自动保证更好的下游表示。

若后续有必要研究独立预训练，应单列可复现目标、预算及等总训练量对照，并在接入Transformer后联合微调；本轮不自动追加。仅凭本模型结果也不能将好坏全部归因于attention：输入编码、容量、深度和训练策略都与历史模型不同。

## 建议训练配置

| 项目 | 计划 |
|---|---|
| 组数/初始化 | 1组，scratch seed0，所有分支随机初始化，无历史权重/Adam |
| batch/精度 | 32，FP32 deterministic，TF32关闭 |
| 优化器 | AdamW，betas=(.9,.999)，eps=1e-8，weight_decay=.0003；所有可训练参数统一LR/decay |
| LR | 第一完整epoch按接受步由3e-5线性warmup到3e-4；后续3e-4→1e-4→3e-5→1e-5 |
| 调度 | 前14完整epoch不触发平台降LR/早停；每epoch固定dev500；有意义改善=max(1e-5,abs(previous_meaningful_best)*1e-4)；连续6轮无此改善降一档并重置该档等待计数 |
| best | 以同一有意义改善阈值记录唯一dev-Loss-best；首次有限监测结果建立best，不按Q重选 |
| 最低LR停止 | 最低LR至少完成8整轮，且连续8轮无上述改善后正常早停 |
| 预算 | 单组4小时训练阶段累计墙钟或200完整epoch，先到为止；包含训练监测/检查点；数据准备及终末评价分列计时 |
| 增强 | 原P=.5的x/y互换；公开几何、端口、边界要求、标签同步变换；地址重命名独立随机源 |
| 梯度/更新 | 原全局clip1与每模块联合参数位移相对上限.005；记录输入/端口/QKV/FFN/输出梯度和触及位移保护的比例 |
| 数值门禁 | Adam前检查所有相关非有限量、任一题/批Loss≥1000、原始梯度范数≥10000；触发保存失败现场并退出，不跳批、不自动重试或调参 |
| 保存/恢复 | best与完整latest；恢复模型、Adam、RNG、顺序/游标、LR/早停、更新保护及累计预算；STOP阻断后续评价 |

首轮不开展LR扫描；这些是新模型的提议值，不声称继承E136的相同优化路径。输入网络和主干同一LR，无阶段切换目标。权重初始化固定PyTorch各层默认初始化、LayerNorm默认参数和seed0；实施时冻结模块创建顺序及源码hash。

先保留清楚可验证的执行路径，再依据分项计时决定是否进行CUDA graph等工程优化。准备期允许在无参数更新、RNG恢复的条件下验证capture支持；采用哪条执行路径必须在正式训练前登记并通过数值短检。正式训练不得因错误静默切路径重试。性能结论用完整epoch、样本/秒和完整单例耗时，不能只看显存/利用率。
