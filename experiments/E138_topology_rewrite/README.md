# E138：从坏拓扑重新规划，同时保留几何修复

2026-11-15用户授权恰好三个新训练实验，准备完成后后台启动，并逐组自动运行原dev500后处理。对照复用E134 E119每三层best63，不新增对照训练，不恢复任何历史STOP任务。

## 假设与架构

当前模型的局部修复有用，但大幅强关系换位很少。这里检验“把重规划从逐步几何修复中分开，再明确训练其恢复坏关系”的机制，不预先认定这就是旧Loss平台的唯一原因。

三组采用同一架构、同一scratch seed0、与E134逐张量相同的初始值，参数仍为712275。S1–S3保留原矩形修复；S4/S5、S7/S8、S10/S11变为不使用当前空间偏置的隐空间规划块，各段开始从公开问题的全局表示＋上一草稿编码重新建立隐状态，不绕过干净的旧几何隐状态。规划块之间不反馈中间坐标；S5/S8/S11共享头绝对预测新草稿，再由原S6/S9/S12矩形层修复。中间诊断仍可读出真实S0–S12，但不把诊断读出冒充被反馈的布局。

|实验|训练目标|检验|
|---|---|---|
|A，`e119_A`|原完整Loss：0.8L12＋0.2/3×(L3＋L6＋L9)|仅改变架构，隐空间重规划是否改善天然坏关系|
|B，`e119_B`|0.8×A的正常目标＋0.2×受扰轨迹末层完整Loss|明确教模型从错误强关系恢复是否有用|
|C，`e119_C`|0.8×[0.8L12＋0.2/3×(F3＋F6＋F9)]＋0.2×受扰末层完整Loss|放松中间几何要求并加入强关系监督，是否比B更容易重构|

B/C每题在S3/S6/S9中的一个位置，交换约25%非P模块的中心，保留每个模块自身形状；交换按模块对进行，不用reference决定受扰输入。受扰状态停止梯度，之后的规划段从公开全局表示重建，不保留干净几何隐状态作为答案捷径。训练扰动随机，监测扰动由公开特征/节点数固定；RNG随checkpoint保存。恢复分支仅在末层施完整Loss，允许途中产生强重叠。

C的F固定为：中心容差项（0.25典型边长）＋0.05自由形状项＋F/P尺寸项＋P位置项＋0.25强方向项。强方向项只在reference明确分离的轴上监督正确中心方向，按每个模块-轴的最坏违反关系聚合，避免大量容易的远距离模块对稀释信号。F不含中间碰撞、线长或外框惩罚。末层始终使用原完整Loss，保留弱关系优化任务；这是需要验证的能力，不预先承诺保住性能。

## 数据、预算与选模

为了复用同轮对照，延续固定36k训练、原train500/dev500及兼容CPU缓存，例外于新任务默认16k；不重建静态缓存、不读test。每组累计训练上限4小时或200轮，保留原FP32/batch32、增强、AdamW、LR、早停与数值门禁。B/C增加一次恢复前向，同时间预算下可能接受更少更新；同时报告轮数、步数和实际耗时。

每组自己的固定目标统一用于反传、监测、best、LR与早停；不同own-Loss不直接排名。共同评价正常推理末层完整Loss及分项、重叠/外框/分组/贴边、最终Q尾部与完整耗时。强关系诊断同时统计固定旧基线S3错误关系的末层修复与各自S3错误的后续修复；reference关系只是定位工具，不是唯一好拓扑定义。

训练成功后冻结唯一own-Loss-best，逐组自动运行原500例、原E98.depth_budget.v1后处理、原面积/无MIB本地Q和独立硬检查，再保存真实逐层输出及结构诊断。Q不参与选模，不扫描后处理预算，不挑选有利步数。错误或用户暂停阻断后续；只运行A/B/C三个训练臂。
