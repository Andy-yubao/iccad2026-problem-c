## 启动前固定的实验

* 两个同预算配置：geometry仅学习教师中心/log长宽比；structure在相同几何监督上增加边界、组内接触方向及MIB同形状监督。均从冻结E10 attention权重初始化，96宽、4层，不恢复退役架构。
* 首次蒸馏用教师目标权重1，原reference位置监督和新增赛题代理损失权重0。原模型初始化已经带有reference预训练。这是验证此前方案的对照，不在本轮同时引入多阶段权重调度。
* train20,000、固定train_monitor500/dev_monitor500；教师库不完整、pilot冒充全量、错误标签或成员不符时拒绝正式训练。开发标签只做评价，无反向传播。
* float32、batch16、AdamW学习率1e-4、weight_decay1e-4、梯度范数裁剪1。中心误差除以sqrt(公开块面积)，形状误差按log长宽比；结构三项各权重0.1，正负样本分开平均。
* 每轮完整监测两组500例。两配置均按开发几何MSE之和选择best、调度和早停，结构指标另报，避免改变checkpoint选择标准。绝对min_delta=1e-5；连续4轮无改善学习率减半，最低1e-6；连续12轮无改善早停。最多200轮、每配置累计4小时，时间上限不是收敛结论。
* best/latest保存模型、优化器、scheduler、随机数、当前轮的排列/游标、监测日志位置、已见训练成员和累计预算。STOP文件在当前batch后保存停止，恢复不重置预算。训练源码、标签成员/哈希和预算不符时拒绝恢复。
* 训练结束的完整dev2500官方reference预测误差作为兼容性诊断单独记录；主教师误差使用固定dev_monitor500。随后固定dev_quality100评价真实学生+E12同款0.35秒投影。最终Q、合法性、回退与含预测/解码/通信的时间分开报告；不存在教师信息的正常推理才是学生成绩。

学生结构解码使用固定0.5置信阈值、公开面积/刚性规格兼容性检查和最大置信接触森林。不使用teacher类别编号；几何对照从几何推导结构。正式推理中的接触/边界预测可能不一致，所有失败计入，不把oracle成绩当学生成绩。可另做真实几何+教师结构、教师几何+真实结构的诊断。

## 数据集更新的含义

任务输入和split不变；E12教师库是新监督答案层，不是修改官方原件。教师偏好标签不保证每例都优于reference，训练准备时会用相同中性时间官方计分同时审计两者，保存改善/退化/硬合法标记。首次蒸馏仍使用全部教师目标，保留既定对照；以后若制作“择优答案库”，应按固定质量标准逐例选完整布局，另开标签版本，不能平均两种拓扑的位置。
