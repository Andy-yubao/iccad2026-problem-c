# 新增路径阻隔 Loss v1

仅使用公开面积、组关系、边界要求、有效位和当前预测XYWH；不使用reference位置、评分分母或后处理结果。原 grouping 接触平方项和 boundary Smooth L1 完整保留；不将其升至四次方。新项只在实验一、三各自所有监督层使用，包含去掉直接overlap的层。

## 单轴移动通道

矩形沿单轴平移时，取相对起始矩形新增扫过的条带。向右时为 `[x+w,x+w+dx]×[y,y+h]`，其他方向同理。对允许的阻挡模块k累加条带与k的交叠面积，除以 `((sqrt(A_i)+sqrt(A_k))/2)^2`。不再平方面积或聚合项。该惩罚随阻挡的纵深和横向占用增加，不因布局中无关模块数量增加而被均值稀释；起始模块的已有重叠不计入本条带。对已有重叠和全局穿透仍由原项在完整监督层负责。

分支、接触朝向和MST选择离散且停止梯度；条带坐标、平移距离、阻挡模块坐标/尺寸均保留分段梯度。允许目标模块与阻挡模块共同移动，F/P仍由原公开规格Loss及后处理约束。

## boundary

按当前布局外框和公开L/R/T/B要求，计算模块到对应边界的轴向平移，累计通道阻挡。排除自身和padding，其余模块均可为阻挡（包括同组）。同模块多边要求先均分，再按有boundary要求的模块累计；已经贴边时路径长度为零。

## grouping

复用原接触代价选出的最小生成森林，不改变原树和原接触平方损失。每条树边两端计算达到侧边接触所需的最小平移：朝向使用原接触代价较小的x/y选项；切向至少满足原项1%接触长度。检查“先横后纵”和“先纵后横”两条局部路径，取阻挡较小值；正反两端移动的代价取均值，避免Prim根和边方向偏置。

只把异组和无组模块视为grouping阻挡；同组模块可作为连通中继，不能因为位于两端之间而受罚。无组、单模块组、无树边均贡献零。对每条边累计所有阻挡模块，不增加全体模块数的归一因子。

令ng为原组树边数，nb为有boundary要求的模块数，新增贡献为 `2B*(group_path_sum+boundary_path_sum)/max(1,ng+nb)`，B沿用0.3336832108335229，附加乘数固定1。逐层记录两项原始值、已计系数贡献及共同原Loss。

## 限制与检验

这是两种正交平移路径的可微近似，不保证找到绕远路径、尺寸变化路径或多模块协同方案。MST根据原接触代价选择，未按新阻隔项重选；局部条带完全覆盖阻挡时某些平移梯度可能平坦。它仍可能通过改变相对拓扑、移动障碍或调整形状降低损失，需以最终硬合法和软违规验证效果。

准备门禁覆盖：阻挡为正/清空为零、四边方向、已接触、起始重叠排除、同组中继排除、正反方向、平移/缩放/换轴不变性、有限差分、原分项逐值一致、监督层直接梯度、五个既定训练例的batch64图捕获和受保护更新、末32成员路径及保存恢复等价。训练失败不跳批、不降门禁、不自动重试。
