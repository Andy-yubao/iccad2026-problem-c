# E148 冻结定义

## 单元接口与梯度

L_out=F_s(P,L_in)。F_s含两个不同的CoordinatedBlock；跨两次同名调用共享参数。单元每次调用h=E_problem(P)，第一层需求编码输入[原49,形变16,静态16]共81维。第一层输出h1及布局L1，第二层需求编码只输入[原49,形变16]共65维，使用h1+state_embed(L1)，没有静态条件二次注入。pair18 bias/接收者相关关系value及连接/分组局部聚合沿用原计算。第二层仍用公开面积/分组等计算几何，并非禁止读取构建几何和图关系所需的公开字段。

纯题目编码器与初稿生成器是独立参数和运算路径；纯题目编码不依赖初稿/历史隐藏/布局，仅缓存当前前向的公共条件。布局不detach，端到端梯度沿布局和pair/state_embed传播，动态49+16摘要保持no_grad。共享编码参数收到所有单元的联合梯度不构成动态隐藏传递。

原输入条件保留16维公开面积、已知规格、F/P标记、边界要求、同组数量、连接强度和端口权重/重心，并用两次全局attention及连接/分组消息恢复题目上下文；没有新增reference信息或原始pin细节。第二层不再次读取16维向量。

## 形变定义

r=log(w/h)，r'=clamp(r+delta,-5,5)，delta顺序+.2,-.2,+.8,-.8。w'=sqrt(A exp(r'))，h'=sqrt(A/exp(r'))。以当前decode后矩形真实中心c为锚，lo'=max(c-wh'/2,0)，与真实decode使用同一非负原点规则；靠原点时实际中心可能随截断变化，明确不是全域严格中心不变。其余模块固定，每个i的试探独立，不能把所有模块同时改变。

每种试探返回asinh(phi_i(trial)-phi_i(current))四维，字段顺序如下：

1. log1p(sum_j intersection_area(i,j)/A_i)，保留重复覆盖负载，无上限。
2. 对所有同组有效j!=i，取原contact_cost(i,j)的最小值；无同伴为0。contact_cost含1%正交接触长度要求，角点不当作有效接触；不计算或替换Loss中的组MST。
3. i的已要求边到该试探完整布局外框的平均距离，除sqrt(A_i)；无贴边要求为0。
4. 该试探完整布局外框面积/公开有效总面积。使用排除i的其他矩形极值，再与i的试探矩形合并；不使用reference外框。

padding/self排除；允许所有F/P参与试探，禁止规格覆盖。只有形变试探读出使用ratio数值保护；实际布局仍由学习的残差头输出。
