## 事前方案与验收

先定位单行底解、数值拒绝、拓扑不相容和质量代理不对齐，再比较三种不同机制：可行拓扑投影、公开约束引导的多种构造种子、模型草稿的局部重构。先用至多五例（含既有失败反例）检查；有机制信号才扩大。优先保留正常路径，选择候选只能使用公开输入的面积、线长、软违反和硬检查。自由块参考和参考分母不进入求解器。允许按证据联调或训练；无必要则不重训。

开发100例使用已有平均面积100例成员；另500例与其不重叠，按预先固定的公开兼容规则和顺序选取，不按Q筛选。两者均来自原dev分片；500例只在候选冻结后运行。若据500例调整，原500明确转为开发证据，冻结新版后另取不重叠500复核，不将重复适配声称独立测试。local_test本轮保持封存。

验收：100例及另500例全部硬合法，Q>2为零，Q>1.8不超过1%；同一派生输入下算术和模块数加权Q均低于E10。正常例逐例列出Q升幅>1%，以零例为保护目标；若发生不得用平均收益掩盖。Q是沿用原HPWL/bbox分母的中性时间诊断，不是正式比赛分数；任务面积改变后旧reference不是新任务的可行答案。报告HPWL、bbox、边界/分组/MIB、P95/最大值、回退率、实际耗时和预算。600例无严重尾部不能证明分布上永不失败。

默认seed=0、CPU两线程。E10普通路径1.3秒/总目标5秒；E14普通路径沿用，必要的额外救援预算单列，不把增算力收益当同预算收益。机制消融与运行证据在runs，实际命令和完整源码快照随运行记录。E14算法从E10独立复制；教师标签编码从E12独立复制，权重只引用唯一原件。

## 固定数据规范

新任务标准为16,000 train、2,000 dev、2,000 local_test，总目标20,000兼容任务；**不从原train划出验证/测试**。三组严格属于split_v1对应的完整分片池。保留split_v1/workset_v2原件；扩展候选池是本次明确新方案，不冒充旧工作集。局部兼容率低，故需要在各自原分片池按固定顺序补足，不把不同集合互相补齐。

规则：MIB组内面积统一为算术平均，保留总面积、固定/预放置规格；锁定形状冲突或与平均面积不兼容则拒绝。仅使用公开输入筛选，保存拒绝原因和修改记录。新任务由原成员+版本化面积修改唯一确定。先按worker均衡配额，再按固定顺序补齐无兼容worker的缺额，披露实际覆盖。开发100先纳入dev，其余dev成员由固定哈希顺序决定；另500是dev中排除100后的固定成员。训练不消费任何dev/local_test标签。测试候选顺序事前固定，实际兼容成员须在未来获得封存读取授权后才物化；本轮不为凑满数字读取测试。

`prepare.py`生成版本化成员和筛选审计；`data.py`定义规则及读取。正式登记见[derived_workset_v3.json](../../protocol/derived_workset_v3.json)，本机已物化train16,000/dev2,000，测试保持封存。局部MIB兼容不保证所有边界/分组条件可同时满足。后续如训练：固定train/dev监测各500、学习率下降和早停、best/latest及累计预算，完整训练配置须在启动前另存，不能用测试选权重。
