## 继续生成

仓库根目录 PowerShell：

```powershell
.\experiments\E14_stable_teacher\generate_selected.ps1
```

自动恢复新库 `runs/teacher_q104_stratified_v1/`，不使用旧 `generate.ps1 -Resume`。默认新增生成累计预算48小时、60000次求解，任一触顶即停；每层配额全部满足后提前完成。不启动训练或其他阶段。按目前约60%接受率粗估尚需约2.4万次尝试、约13小时，扩充兼容率和尾部耗时可能使时间上升；配额不足不会伪报完成。可明确扩大累计预算：

```powershell
.\experiments\E14_stable_teacher\generate_selected.ps1 -MaxSeconds 345600 -MaxSolves 120000
```

停止：在新库创建空文件 `STOP`，当前候选结束后退出。也可Ctrl+C。继续：删除STOP后重新执行同一命令。SQLite事务决定已完成成员；标签先原子落盘，事务后导出清单，崩溃可能重做最后未提交一例，不会重复纳入。禁止同时启动两个生成器，入口持有独占锁。质量超标（含Q>2）正常淘汰并继续；数据/求解/硬检查错误停止，查看 `last_error.json` 调查后再恢复，出错成员保持pending。

`progress.json`含每层进度、已用时间、状态；`accepted.json`是后续训练唯一教师成员清单（可少于16000，只有completed才达到配额）。运行中每25次新求解导出一次，停止时再导出；`bank.sqlite3`为断点权威状态，也记录淘汰结果。保留银行数据库及labels，不能只保留导出清单。恢复时逐个验证已接受标签哈希，并验证模型/求解/评分/协议源码指纹；无关绘图脚本不影响恢复。
