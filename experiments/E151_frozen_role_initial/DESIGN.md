# E151 冻结定义

从 E149 冻结 best52 载入初稿生成器的 107739 个参数。L0 在训练和评价中始终使用 eval 前向，关闭 dropout 和梯度，参数从 AdamW 与逐模块位移投影中排除。启动、恢复和结束前检查 L0 参数与父权重逐位一致。训练时沿用公开题目轴交换，冻结初稿读取交换后的公开字段。

后段是 E150 的 101184 参数题目编码器和 E148 风格的三个共享双层单元，共 573402 个可训练参数。后段 seed0 从头初始化，AdamW 从空状态开始。单元按 S0/S0/S1/S1/S2/S2 调用，各段边界是 L4/L8/L12。跨单元传真实布局，保留后段端到端布局梯度。F/P 全通道维持预测，忽略 MIB。

联合目标为 `0.1 * F_no_overlap(L4) + 0.1 * F_full(L8) + 0.8 * F_full(L12)`，与 E148 的阶段权重和分项一致。固定目标用于反传、固定监测、选模、学习率和早停。L0 只在终末审计中记录诊断 Loss。

沿用 E148/E150 原 36k、固定 train500/dev500、batch64/尾批32、FP32、AdamW 及原调度和数值门禁，整个训练候选上限 4 小时或 200 轮。复用原 CPU 张量和 E149 完整公开角色缓存。训练完成后冻结唯一 own-Loss-best，再核对同一 dev500 的 L0 Loss 与 E149 原始记录、联合 Loss 与 E151 监测记录。

终末逐题审计报告 L4、L8、L12 完整 Loss，重点统计 L8 减 L4 的重叠、分组、贴边、F/P 尺寸和 P 位置误差。与归档 E148/E150 逐题对齐，分别核对 L4 相对优势能否维持到 L8、L8 重叠水平与 S1 段降幅。数据和比较对象的身份在 `plan.json` 固定。
