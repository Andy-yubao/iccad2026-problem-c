# E152 冻结定义

两组载入同一 E151 best45。L0、S0、S1、公开题目编码器始终 eval 并冻结，S2 从原权重开始，优化器为空。S2 含 157406 参数，双层单元调用两次。每次训练以变换后公开题目的实际 eval 前段生成 L8，后段接相同的公开条件。两组使用相同成员顺序、增强和 seed0。

L12 Loss 为 E151 原系数的公开任务项加 0.2 倍改动项。A 另加原 reference 项，B 的目标和反传与 reference 无关。改动项以停止梯度的 L8 为锚，中心位移除以模块面积平方根，容差 0.05；原始 log(w/h) 的容差为 0.10。超出部分用 beta 0.1 的 Smooth L1。中心与形状比重 1 和 0.25。L8 累计交叠超过自身面积 1% 的模块，改动项乘 0.25；其余为 1。按各自有效自由通道数归一。P 中心与 F/P 形状由公开规格监督。L10 只记录诊断。

固定原 36k 训练集、原 train500、原 dev500、FP32、batch64（末批32）。每组最多十轮、5630 次更新，每轮 563 批覆盖全部 36000 例。学习率按接受更新步 0..5629 从 1e-4 余弦降至 5e-5。沿用更新前有限性、Loss 与梯度检查和每模块 0.5% 位移投影。异常或 STOP 阻断后续阶段。每组固定 dev500 自身目标选唯一最佳，保留终轮等步数比较点。每组沿用两小时保护上限；不增加基于 dev 的提前停止。旧 E152 v1 结果全部作废，本轮从 E151 best45 重新载入模型并建立空 AdamW。

终末复用同一 E98.depth_budget.v1 后处理和原面积/no-MIB 评分，分别对 A、B 和同一 E151 best45 运行固定 dev500。按题核对 L8 布局哈希，记录 L8/L10/L12 重叠、位移、尺寸变化、原分组接触与贴边保留、L8 最低重叠四分位、硬合法率、Q 和完整耗时。
