## 一 继承范围和阶段安排

复用 random_mib40k_v1 的 36k 训练成员、固定 train500/dev500、增强 CPU 缓存、MIB 形状修正标签、公开输入边界和原独立硬检查。test 继续封存。不重抽样、不读取 test 标签，也不恢复旧实验。

四阶段依次为：

1. scratch L0，冻结自己的 dev best。
2. 固定 L0，scratch S0 编码器及共享双层单元，调用两次产生 L1–L4，冻结自己的 best。
3. 固定 L0/S0，scratch S1 编码器及共享双层单元，调用两次产生 L5–L8，冻结自己的 best。
4. 固定 L0/S0/S1，scratch S2 编码器及共享双层单元，调用两次产生 L9–L12，冻结自己的 best。

每阶段只训练本阶段参数，新建 AdamW；不继承 E155/E156/E157 的权重或 Adam。冻结前缀始终 eval/no-grad，跨单元只传布局。保留 width64、双层结构、S0 原组移动/成员移动分支、S1/S2 原坐标与形状残差输出头。新增内容集中在几何反馈和 Loss，不额外增加交换动作分类器或组合搜索器。

| 阶段 | 监督出口及权重 | reference 系数 | 绝对重叠 Loss | 新移动约束 |
|---|---|---:|---|---|
| L0 | L0，1.0 | 1.0 | 0 | 无 |
| S0 | L2/L4，0.2/0.8 | 各 0.75 | 0 | 无 |
| S1 | L6/L8，0.2/0.8 | 各 0.5 | 两处均保留原系数 A | 仅 L8，0.05 |
| S2 | L10/L12，0.2/0.8 | 各 0.5 | 两处均保留原系数 A | 仅 L12，0.2 |

这里“模块”按 L0/S0/S1/S2 功能单元理解，不按某个空间矩形理解。S1/S2 的双层单元承担出口重叠任务，因此其两个内部更新层都可以读取重叠反馈；未直接监督的奇数层不因此独立视作“无重叠任务模块”。

本轮先登记一套完整 E158，不自动扩展为三组训练或超参数网格。由于前端也重训，E158 对 E157 是整套方案的配对比较，不能单凭一次结果确定 reference、新反馈或移动约束各自的因果贡献。

## 二 reference 和选模分别采用什么口径

沿用现有 R 定义：各模块按自身 sqrt(area) 归一的中心 SmoothL1，加 0.25 倍 log 长宽比平方误差。监督中心沿用原 reference；形状使用当前 MIB 修正标签，直接复用已有缓存。F/P 仍全部预测，原公开尺寸和预放置位置 Loss 保留，reference 不进入模型输入或后处理。

训练目标中的 R 系数固定为 1.0/0.75/0.5/0.5，不额外按阶段数量缩小。S1 例如为 0.2*(P6+0.5R6)+0.8*(P8+0.5R8+0.05D1)。

选模建议分两部分：

- L0/S0 沿用前段 own-Loss 的做法，仍含 1.0R/0.75R。它们没有绝对重叠目标，直接拿掉 R 选模，容易偏好过度压缩、相互覆盖的初稿，不利于评估 reference 学习。
- S1/S2 按你的后段意图，训练含 0.5R，best、LR 和早停统一使用去掉 R 后的公开目标，三者严格同口径。固定 train500 和 dev500 都同时输出训练目标及这个选模目标。

这里的后段公开目标使用 E158 新 grouping 与新移动项。E157 原公开 Loss 另列为共同诊断，不把其旧移动项继续混进 E158 选模。这样可以区分“新目标改善”和“原口径改善”。这也是本稿相对所附文字中“完全照搬 E157 原选模公式”的明确调整，供审查。

本实验登记 S1/S2 的训练 Loss 与选模 Loss 存在且仅存在 R 的差别，作为用户提出的局部研究规则；不静默改写项目的通用同 Loss 约定。记录 best 更新容差 1e-5，另记录数学上的精确最小轮次，避免把容差选模误称严格全局最小值。

## 三 无绝对重叠任务时删除哪些反馈

L0 没有输入草稿，本来就不读取动态碰撞几何。S0 使用新的无碰撞反馈输入结构，物理删除并停止计算下列专用通道，而不是把它们乘零后继续计算：

| 当前反馈位置 | S0 中的处理 |
|---|---|
| 节点 overlap count/load/max 三项 | 删除 |
| 四方向脱离碰撞距离 | 删除 |
| 0.25/1.0 模块尺度平移后的碰撞负担响应 | 删除全部八项 |
| pair 中通用 signed gap 与 penetration | 删除 x/y 四个通道 |
| 四种形变探针中的碰撞负担响应 | 删除四项，其余 group contact/boundary/bbox 响应保留 |
| 组外框内异组矩形的相交面积负担与计数 | 删除；由新的接触走廊反馈替代 |
| 任何按碰撞量确定的 S0 门控、移动放宽或候选排名 | 不引入 |

保留公开位置和形状、相对位置、线网、MIB、同组联系及边界反馈。新 grouping 反馈允许读取同组模块相向边和切向投影，boundary 反馈允许读取到指定边界的通路；这些是目标关系的几何量，不保留一般矩形相交面积、penetration 或碰撞逃逸探针。位置和形状本身仍足以让网络推断部分碰撞，不能把删除专用通道说成模型完全无法感知重叠。

**S0 原相对重叠保护项单独保留。** 实现核对表明 E156 实际还有 A*relu(O4-stopgrad(O0))，不是完全没有重叠监督。本稿为遵守未指定部分沿用旧方案，保留这个原 Loss，但 S0 的专用碰撞反馈仍全部删除。这里把反馈开关明确绑定到“是否承担绝对去重叠任务”。若审查决定 S0 连相对保护也不要，应显式删去该项，不能假称原来就不存在。

S1/S2 保留 E157 完整重叠 Loss 和相应反馈。暂不取消 L6/L10 的碰撞目标；仅为“允许交换”而同时改掉这些目标，会再引入一项未指定变化。L5/L7/L9/L11 仍无直接 Loss，网络可以在这些真实中间状态中经过重叠。成功标准是阶段出口形成更好的关系，不要求连续无碰撞运动轨迹。

## 四 夹挡反馈如何同时送到 A B 和 X

### 接触走廊

对同组 i/j 分别考虑左、右、上、下四种接触方向。以 i 在 j 左侧为例：

- 法向间隙为 x_j_left-x_i_right。
- 切向区间为两模块 y 投影的交集。
- 法向间隙和切向区间都为正时，两者的乘积区域定义为接触走廊。
- X 与 i/j 不同组，且在法向穿过走廊、切向遮住其一部分时，建立 (i,j,X) 夹挡事件。

反馈使用 X 遮住的切向长度/走廊切向长度，不乘 X 的法向厚度。相向边有 10 个单位、细条遮住其中 9 个单位时，遮挡比例就是 0.9，细条宽 0.1 或 0.01 不会把这个量稀释成很小的面积。

若没有共同切向投影，走廊标为无效，contact Loss 负责引导建立接触；不填造一个走廊。同组第三个模块不当作异组挡块，可以成为合法的连接中介。

### 信息接收者

| 接收者 | 新反馈内容 |
|---|---|
| i 和 j | 接触方向、对方相对中心、法向间隙、共同切向长度、遮挡区间并集比例、主要挡块的 F/P 标志、两侧让路距离 |
| X | 自己挡住的是哪组接触或哪条 boundary 通路、方向、相对走廊中心、自己遮住多少、向两个切向方向分别移动多远能够让开、两端是否预放置 |
| 有 boundary 需求的模块 | 到每个指定外框边的通路、遮挡比例、挡块是否预放置 |
| boundary 通路中的挡块 | 自己挡住哪一侧贴边、两侧让路距离、被挡模块是否有位置约束；同组挡块也记录 |

F 只约束形状，仍可平移；P 有公开固定位置。反馈必须区分这两种情况。预测输出仍覆盖所有 F/P 模块，不把参考自由坐标或预设交换答案输入网络。

每个节点保留最严重两个“自己被挡”事件和两个“自己挡别人”事件，并附总事件数、最大严重度，防止一个模块被重复事件淹没。缺失事件用显式 valid 标志，不用零距离冒充无事件。新增 pair 关系把 i/j 与 X 联系起来，同时进入原 attention bias 和 relation value；不只在 i/j 的本地摘要中加一个障碍标记。

候选同组边采用每节点四个最近同组候选，加当前接触代价的完整同组 MST 边，取无向并集。MST 保证候选图连通；最近候选提供替代连接，不强迫所有同组成员两两相接。候选和离散排序不反传，几何数值在每层按实际当前布局重算。

所有新动态反馈只依赖公开条件与当前预测布局，并沿用原 detached 几何反馈边界。反馈本身不是执行动作的求解器。

## 五 新 grouping Loss

原 Loss 的问题是很近的同组边会得到很小的距离代价，但可能被一条异组细条完整截断。新 Loss 同时约束接触、最差连接和让路代价。

令 s_ij=(sqrt(a_i)+sqrt(a_j))/2。方向 d 的接触代价 C_ij^d 复用原接触原语：相向面距离平方/s_ij²，加切向共边长度不足的平方/s_ij²；最低共边仍为对应最小边长的 1%。它保留角点接触不是有效共边的原语义。

对一个有效夹挡事件，设走廊切向区间为 [u,v]，X 投影为 [l_X,h_X]。两个方向的完全让路距离分别为 h_X-u 和 v-l_X，加入数值间隙 1e-6*s_ij 后取较短者。定义：

    rho_X = X 遮住的切向比例
    r_X = min(h_X-u, v-l_X) + 1e-6*s_ij
    b_X = stopgrad(rho_X) * Huber_0.1(r_X/s_ij)
    B_ij^d = 最严重两个有效挡块 b_X 的均值

无挡块时 B=0；不足两个事件只对有效项平均。活动事件及较短让路分支按当前布局离散选择、反传时固定，几何距离本身可微。完全遮住时 rho 即使已饱和，r 仍有梯度，因而 X 能收到真正的让路梯度。严格等距时采用按公开模块编号定义的稳定分支破同分，并验证 x/y 互换一致性，避免两个相反分支的梯度正好抵消。

本项的分子不含 X 的法向厚度，因此薄挡块不会因为面积很小而失去训练信号。对于 P 挡块，强公开位置 Loss 与 P 角色反馈共同引导两端选择其他空间安排；不声称单独一个标量代价能保证总是选出正确动作。

对候选边选取 q_ij=min_d(C_ij^d+0.25*B_ij^d)，按 q 构建每组 MST。树与方向选择 stop-gradient，选中的接触和夹挡代价保持可微。每组分别得到：

- Gmean：树上 C 的平均。
- Gtail：树上最大的 C。
- Gblock：树上最严重两条 B 的平均，按固定树边容量归一，不按当前违规条数归一。

对至少含两个模块的有效组等权平均，最终：

    L_group158 = 2B * (Gmean + 0.25*Gtail + 0.25*Gblock)
    B = 0.3336832108335229

该项替换原 grouping 项；S0 旧的额外 0.2 瓶颈项一并被新 Gtail 替换，不重复叠加。其他 wire/compact、boundary、F/P 和 2B*MIB 系数沿用原件。boundary 新增通路反馈，但不在本轮额外增加 boundary 夹挡 Loss。

组内连接可经其他成员实现，MST 因此允许采用更好的替代边。评价时另外跟踪固定入口坏边和三元组，防止仅靠换一棵树就宣称解除夹挡。把模块挤到相互覆盖而让走廊消失，也不能计为严格修复；出口重叠及原硬检查另行报告。

系数 0.25、K=4、top2 和 Huber beta=0.1 是本稿预登记的初始常数，未根据 dev 最终 Q 调参。实施时先以合成例检查尺度和梯度；若必须改变系数或公式，更新方案再审查，不启动参数搜索。

## 六 S1 S2 如何限制无关改变而放行修复

删除 E157 仅按“入口重叠负担>面积1%”给予减免的旧 drift。新的入口基准分别为 S1 的冻结 L4 和 S2 的冻结 L8。

每次正式前向先在阶段入口建立 e_i∈[0,1]，取以下严重度的最大值：入口碰撞负担、同组接触被挡程度、自己作为挡块的程度、boundary 通路受阻程度。碰撞部分沿用公开的自身面积归一负担并截到 [0,1]；夹挡部分用切向覆盖比例。整个 e 在阶段内 detach/freeze，不使用输出端的新问题给自己解锁移动豁免。S1/S2 都有绝对重叠任务，因此这里保留入口碰撞量符合其反馈边界。

中心权重 w_i=1-0.9e_i，最低为 0.1；容差随角色变化：

| 阶段 | 中心容差 单位为 sqrt(area_i) | logratio 容差 | 阶段出口系数 |
|---|---|---|---:|
| S1 | 0.10+0.65e_i | 0.10+0.15e_i | 0.05，仅 L8 |
| S2 | 0.05+0.45e_i | 0.10+0.15e_i | 0.2，仅 L12 |

因此，不重叠但挡在 A/B 中间的 X 也能得到移动减免；无关模块仍受较紧限制。e=1 时 S1/S2 的中心容差分别为 0.75/0.50 个自身尺度，超出后仍只是软惩罚，不设硬位移上限或禁止相对顺序翻转。

定义 Dmove 为按有效模块平均的 w_i*Huber_0.1(relu(中心移动/自身尺度-容差))，加 0.25 倍对应形变项。P 中心不参与通用移动限制，F/P 形状不参与通用形变限制；它们始终接受原公开规格 Loss，仍由模型独立预测。

中心移动用实际 decode 后的几何中心相对阶段入口计算，避免原始 state 中心与非负坐标截断后的真实布局不一致；logratio 使用原始预测值，避免 clamp 掩盖形变。移动项的分母为登记有效模块数，不按加权后的权重和归一，从而使减免确实减小惩罚。

再加入 Dkeep：对阶段入口已满足、且两端 e<0.1 的同组接触和边界关系，软惩罚出口恶化。接触残差取 sqrt(min_d C+1e-12)，边界取原归一贴边距离，均用 Huber_0.1(relu(出口残差-入口残差-0.01))。入口“已满足”按公开几何容差 1e-6*相应尺度判定，关系身份固定；Dkeep 按登记的入口关系数平均，空集为0，不按输出剩余关系数重新归一。涉及夹挡修复的关系不在这个保护集合内，允许重接其他同组成员。

    D = Dmove + 0.25*Dkeep

整个阶段只在最终出口加 D；不逐层、逐小步限制累计行程，也不保护旧左右顺序。S1 的轻约束控制无关漂移，S2 的较强约束负责收尾。新 grouping Loss 提供解除夹挡的驱动力，reference 提供可学习的空间选择，移动项本身不承担创造交换方向的责任。

## 七 完整目标与训练设置

记 U 为原 wire/compact、boundary、公开 F/P 和 MIB Loss 之和，O 为原绝对重叠原语，A=0.08975162861857286，G 为上面的 L_group158：

    P_l = U_l + G_l + a_l*A*O_l
    a_l = 0 for L0/L2/L4; 1 for L6/L8/L10/L12
    H0 = A*relu(O4-stopgrad(O0))

    Train_L0 = P0 + 1.0R0
    Train_S0 = .2*(P2+.75R2)+.8*(P4+.75R4)+H0
    Train_S1 = .2*(P6+.5R6)+.8*(P8+.5R8+.05D1)
    Train_S2 = .2*(P10+.5R10)+.8*(P12+.5R12+.2D2)

L0/S0 的 best、LR、早停使用各自 Train；S1/S2 的三者统一使用各自 Train 减去 .2*.5R_aux+.8*.5R_exit。R 在固定 train/dev 两边都记录，不能把未乘系数的 R 和已乘系数贡献混写。

batch64、尾批32，seed0、FP32/确定性设置、AdamW weight_decay=0.0003、梯度裁剪和每模块0.5%参数更新投影沿用旧方案。学习率仍为 1e-3/2.5e-4/1e-4/5e-5，沿用原平台调度、保护期及早停逻辑。

每个阶段最多4小时/200轮，总训练上限16小时，不包含终末评价；累计计时与旧运行一样从本阶段准备开始，不因恢复重置。新三元关系会增加成本，同预算下完成轮数可能减少，报告接受步数、轮数和反馈计算耗时。

S0 保留原训练输入增强：75%干净、12.5%中心抖动、12.5%与最近邻交换中心；监测始终使用干净输入。S1/S2 沿用 E157，不增加布局扰动；各阶段保留原轴互换增强。所有前缀权重冻结不变，S0 的训练输入扰动不改变其 L0 原始输出；H0 的基准仍取未扰动 L0。

## 八 实施前必须通过的检查

1. 薄条合成例：A–X–B，遮挡9/10时反馈为0.9；X 法向厚度缩小十倍，遮挡量与让路代价基本不变，不能按面积缩小十倍。
2. 饱和遮挡：100%覆盖仍有有效让路梯度；仅横向压近 A/B 而不消除挡块不能被记录为严格修复。
3. 三方反馈和梯度：X 未与任何模块重叠时仍收到挡块角色；Loss 对可移动 X 的切向坐标有非零梯度，同时端点梯度有限。P/F 标志准确区分。
4. 替代连接：A–C–B 已形成无异组阻隔的同组连接时，不强迫额外 A–B 共边；固定坏边解除和替代路径修复分别记录。
5. 无专用碰撞反馈：逐名检查 S0 的输入结构、计算图和形变探针，不仅检查最后输入向量；P/F/组关系不能因删除通道错位。
6. 移动约束：入口有夹挡但无重叠的 X 获得放宽；输出新造夹挡不能改变入口豁免；无关模块移动受到惩罚；修复涉及的旧接触可以被替代。
7. padding、空组、单成员组、多组、多挡块、角点、极薄矩形、预放置挡块、同组 boundary 挡块、x/y互换，数值/有效位/梯度均正确。
8. 四阶段参数覆盖、冻结前缀、梯度、CUDA64/尾批32和序列化下一更新一致性；短检只用登记的5个 train 例，可丢弃更新后正式 scratch 重新初始化。
9. 原 dev/train 成员与缓存哈希核对；不构造新的测试视图。后处理源码/预算与 E157 逐文件核对，只允许调用接口适配新模型。
10. 最大 N=120 的显存及耗时短检。候选边分块、no-grad 计算三元组与排序代价，选定 MST、方向及有效事件后，仅对被选中的几何项重算可微 Loss；不物化 batch*N*N*N 的完整多通道张量。参数量和输入维数在实现后逐项实测、冻结；当前不编造参数总数或吞吐。

检查失败时安全保存并停止，不跳批、不放宽原数值阈值。新公式、维度或预算需要变更时先记录修改，不自动改成另一个候选继续训练。

## 九 怎样判断是否解决了观察到的问题

每轮固定 train500/dev500 分别记录训练 Loss、选模 Loss、E157 共同公开 Loss、中心/形状 R 分项、grouping mean/tail/block、重叠、贴边、MIB 和移动项。两者不能只打印一个含义不明的 total。

S1/S2 在各自冻结入口上固定受阻三元组集合，后续跟踪：

- 原同组边严格解除夹挡并达到接触，同时异组 X 不穿插且相关模块无重叠。
- 原边没有修复，但同组已通过其他成员形成有效替代路径。
- 挡块确实让开、端点改变侧向关系、或两者组合；不以换侧次数本身为奖励。
- 入口薄挡块与一般挡块分开统计，避免平均面积指标掩盖细条。
- 被保护的无关模块漂移、好接触/好边界保留率，及每阶段输入输出的 reference 中心/形状误差。

每个阶段的固定入口队列、所选 MST 和事件身份都保存，不能随模型输出换边后重新定义“最初坏边”。全链前端不同，E158 与 E157 不具有同一 L4 输入；最终质量按同一500题配对，阶段修复率必须注明各自入口事件集合。

唯一冻结 S2 best 才运行原 dev500 完整 MIB 后处理。目标仍为最终500/500硬合法、MIB500/500、grouping至少475/500，并同时报告 boundary、全部软约束满足数、外框超过reference1.2倍题数、混合Q/加权Q/平均Q、完整逐例均时/P95/最大/>250ms数。E157现有对应值为461/500、混合Q1.0146503146、外框异常2题，完整均时573.5ms；这些是本轮已存结果，不把单seed阈值当可靠泛化保证。

主要成功证据应是后处理前的夹挡修复与最终 grouping 改善相互对应，且重叠、外框、Q和耗时没有出现抵消收益的退化。若只降低 Loss，或只提高换侧次数，而最终 grouping 没改善，不宣称方案成功。

终末 dev500 评价时同时保存实际 L0–L12 全部13层，之后再导出分项诊断和统一展示；额外磁盘与绘图时间单列。默认准备同题阶段对比和最终违规例展示，用现有 visualization 滑块，不再只保存 L12。固定39道 E157 grouping 失败题作为已曝光诊断子集，最终结论仍基于完整500题。

## 十 本稿需要审查的三项具体取舍

1. L0/S0 仍按原带 reference own-Loss 选模；后段 S1/S2 才使用去 reference 的新公开目标。E157旧公开Loss作共同诊断，不让旧移动项决定新模型 best。
2. S0 删除所有专用碰撞反馈，但为沿用原方案保留已有的相对重叠保护 Loss；这与彻底删除所有 overlap Loss 是两种不同实验。
3. 保留 S1/S2 两个出口的完整碰撞任务，不在同一轮再取消 L6/L10 的重叠项；先用 reference、夹挡反馈/梯度和新移动约束检验交换能力。

其余未指定部分按上述 E157 及其前端父阶段实现继承。新反馈宽度、参数量、短检结果和实际耗时需在方案审查后实现时补齐；本稿不是已通过准备检查或已获得启动授权的记录。
