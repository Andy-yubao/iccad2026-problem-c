# E160 静态关系消息定义

目标是让公开结构关系影响传递的内容，同时保留 E159 全局 attention 的选择权重。每个块独立增加一个秩8的关系分支，模块作为接收者，全部有效模块与端口作为发送者。端口仍为固定的静态 key/value token，不增加端口更新层。

令 z 为本块原有 pre-norm 隐藏状态，e_ij 为原 pair7 加发送者类型2维。每个块定义：

```
r_i = tanh(W_receiver z_i)           # 8维
s_j = tanh(W_sender z_j)             # 8维
f_ij = tanh(W_edge e_ij + b_edge)    # 8维
psi_ij^a = U_a [r_i * (s_j + f_ij)] # 每头32维
m_i^a = sum_j alpha_ij^a (V_a z_j + psi_ij^a)
```

`*`为逐元素乘法。W_receiver、W_sender在四头之间共享，U_a逐头独立；三个块之间不共享新分支参数。alpha沿用原Q/K、pair bias和有效token遮罩。新分支经过同一个原attention输出投影和残差，再接原FFN。它不读取reference或当前布局。

e_ij的九个通道按顺序为：log(1+直接连接权重)、直接连接存在、同group、asinh(max(最短跳数,0))、可达、自身标记、同MIB、发送者为模块、发送者为端口。模块的角色、公开属性和端口坐标等依旧由z提供；没有新增按跳数分别汇总的支路。

利用U的线性和接收者r_i与j无关，可先计算 `r_i * (sum_j alpha_ij s_j + sum_j alpha_ij f_ij)`，再逐头投影。这样无需构造全宽度pair value。关系线性映射也拆为pair7和type2两部分，避免复制完整9维pair输入；这两处只是同一公式的代数实现。

每块新增参数 `2*128*8 + (9*8+8) + 4*8*32 = 3152`，三块共9456，总计677087。该计数来自源码结构，未运行模型测量。新分支的初始化使用CPU RNG隔离，原分支初始化顺序保持；U_a初始权重×0.01，保留小幅非零消息。训练随机序列可能随模型执行变化，不将共同初始化描述为全程逐步完全配对。

Loss、数据成员、MIB策略、训练计划与E159一致。有限预算内本分支可能改变每轮耗时；报告实际轮数和耗时，不以相同墙钟预算宣称相同更新数。训练后仅比较各自按相同dev总Loss选出的best；单seed结果不能单独证明普遍收益。
