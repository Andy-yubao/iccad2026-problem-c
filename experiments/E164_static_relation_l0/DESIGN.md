# E164 初稿生成器

一个从零训练的 L0 候选，seed 0，两块宽 64、四头注意力，FFN 宽 192。每块在原 E149 公共角色、端口、静态 bias 和图局部聚合基础上加入 E161 无 MIB 的秩 8 静态 value 消息。末尾一次预测所有模块的中心和 log 长宽比。登记参数数目 110955，独立随机初始化。

训练目标为 E149 原无直接重叠目标加 0.25 倍原完整重叠项。reference 权重为 1，保留原 MST 分组接触项。新增 MST 阻挡项保留为研究诊断，不进入本轮 Loss。固定 dev500 使用训练目标选 best、调 LR 和早停。输出 E149 原口径及逐题对照。

使用父集合的原始完整 train36k 及其固定 train500，并使用原 dev500。复用已登记原面积/no-MIB CPU 张量和公开角色缓存。按用户指令从 Kaggle T4 迁移至本地单 GPU，batch64／尾批32，确定性 FP32，AdamW 和原更新保护，训练累计最多 4 小时或 200 轮。
