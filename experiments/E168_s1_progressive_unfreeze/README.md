# E168 S1 分阶段训练

载入 E167 best57 的 L0、共享题目编码器和 S0，随机初始化 S1。S0、S1 各执行两次，分别输出 L4、L8。L1–L4 沿用 E167 的重叠反馈屏蔽。L5–L8 使用 E166 的完整几何反馈。

前 20 轮冻结整个 E167 前级，并保持其推理模式。第 21 轮起解冻前级，使用 S1 当前学习率的 0.1 倍。保留 S1 的 AdamW 状态和已降到的学习率档位，重新计算 plateau 计数并重捕获 CUDA Graph。L0 沿用 E166 的 dropout 设置，解冻后仍保持推理模式。

沿用 E166 的有效出口监督，目标为 0.05×L0 + 0.10×L4 + 0.10×L8。L8 的完整直接重叠项系数为 1，分组和贴边软计数项各为 0.01。保存 L4、L8 的分项，联合阶段的固定 dev500 总 loss 选 best。

固定 no-MIB train36k、train500、dev500，seed 0、batch 64、确定性 FP32 CUDA Graph。训练上限为 8 小时或 200 轮。Kaggle 使用一张 T4，只运行 S1 及前级联合微调。
