# E169 S2 分阶段训练

从 E168 第 45 轮最佳检查点载入 L0、共享题目编码器、S0 和 S1。随机初始化 S2，应用两次，读出 L9–L12。L1–L4 沿用 E167 的重叠反馈屏蔽，L5–L12 使用完整反馈。

前 20 轮冻结 L0–L8 前级并使用推理模式。第 21 轮起解冻，前级学习率为 S2 当前学习率的 0.1 倍。保留 S2 的 AdamW 状态和学习率档位，重置 plateau 计数并重捕获 CUDA Graph。L0 解冻后仍保持推理模式。

目标为 0.05×L0 + 0.10×L4 + 0.10×L8 + 0.80×L12。L12 的 reference 系数为 0.80，重叠项倍率为 1，分组与贴边保留 E166 的软计数项，各为 0.02。联合阶段按固定 dev500 的训练目标选择最佳检查点。

此版本从 E168 的最佳检查点重新初始化前级，重新随机初始化 S2 和 AdamW。在独立的 Kaggle Notebook 运行。

Prim 迭代只记录父节点，结束后一次性生成选边掩码。变形反馈复用整次前向的同组邻居表，只对同组邻居计算接触代价，用每轴前两名极值求排除当前模块的外框。

沿用 no-MIB train36k、固定 train500/dev500、seed 0、batch 64、确定性 FP32 CUDA Graph。Kaggle 单卡 T4，训练上限为 8 小时或 200 轮。
