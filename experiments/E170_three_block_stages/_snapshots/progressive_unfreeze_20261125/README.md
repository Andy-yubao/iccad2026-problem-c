# E170 五阶段布局细化

本实验在本地 Windows 上实现和训练。S0 直接使用独立预训练的 E165 L0 best67，随后按 S1、S2、S3、S4 的顺序训练四个新阶段。E169 Ref080 best33 是主要对照。

## 模型结构

- **S0 就是现有的 L0。** 原样加载三层 `RoleInitial` 的编码器和布局头。使用 `experiments/E165_joint_l0/backups/l0_pretrained_best.pt`，核对 SHA-256 `454b872665ca620994cbae0c0af0faa95cfdf71b07130f1bb681e6f97cfeb82d`。S0 原来的公开静态关系编码保留，作为可复现的初稿基线。
- **S1–S4 各执行一次，每阶段三层独立的 attention + FFN。** 首版用宽度 64、4 个头。四个新阶段之间各自使用独立参数。
- **几何只在各新阶段的第一层注入。** 用上一阶段的布局计算一次模块几何、模块对几何和变形反馈。第一层同时使用公开静态特征、布局嵌入、attention bias 和模块对消息。S1 读 S0 布局，S2 读 S1 布局，依此类推。S1 入口可以使用重叠反馈。
- **各新阶段第 2、3 层只接上一层的隐藏状态。** 使用标准 attention、FFN、残差和有效模块 mask。几何 bias、模块对消息、显式图聚合及布局嵌入都只在第一层。三层结束后用一个残差布局头更新中心与 log 宽高比。
- 阶段之间只传布局。每个新阶段从公开的单模块静态嵌入重新初始化隐藏状态，复用已有输入特征和轻量投影。布局在解冻后保留梯度。整个模型共 15 个 attention block，其中 S0 已有 3 个，新加 12 个，四个新阶段各计算一次动态几何。

## 逐阶段训练

训练 S1 时从 best67 载入 S0，训练 S2、S3、S4 时从上一个训练阶段登记的 dev500 best 载入整个前缀。每次只新建并随机初始化当前阶段，布局残差头采用 E169 的小增量初始化。每个训练阶段新建 AdamW，前缀冻结期间保持推理模式。前 20 轮冻结，第 21 轮解冻所有前层，保留当前阶段的 AdamW 状态和学习率档位，重置 plateau 计数。解冻后的前缀学习率始终取当前阶段实时学习率的 **0.20 倍**，随当前阶段一起降档。

沿用 `0.001 → 0.00025 → 0.0001 → 0.00005` 的档位和固定 dev500 的降档触发条件。S1–S3 最低训练到 `1e-4`，冻结期达到该档后继续到第 20 轮。进入联合训练后，如果当前阶段在 `1e-4` 再次满足降档条件，就正常早停，并保留联合目标选出的 dev500 best。S4 使用完整的学习率档位和原早停规则。

冻结期只优化当前出口。解冻后当前出口 **0.80**，所有已训练的前置出口合计 **0.20**，首版在前置出口间均分。每阶段按解冻后的固定 dev500 联合目标选 best，完成并保存后再进入下一阶段。

## 各出口的损失定义

| 出口 | Reference 倍率 | 直接重叠项倍率 | 分组、贴边计数代理 |
|---|---:|---:|---:|
| S0（原 L0） | 1.00 | 0.25 | 0 |
| S1 | 1.00 | 0 | 0 |
| S2 | 1.00 | 0.25 | 各 0.01 |
| S3 | 1.00 | 0.80 | 各 0.01 |
| S4 | 0.80 | 1.00 | 各 0.02 |

S0 的辅助监督取 E169 的 L0 口径。S1 的直接重叠项系数为零，保留分组距离、贴边距离、线长、外框和公开硬约束损失。S2–S4 逐步增加直接重叠惩罚，S4 沿用 E169 Ref080 的末层配方。表内各项倍率在计算出口 loss 时使用，再乘上一表的出口权重。

## 本地实施和验收

- 沿用 no-MIB train36k、固定 train500/dev500、seed 0，以及 E169 的 x/y 交换增广。复用两项计算优化。Prim 只记录父节点，最后生成边掩码。变形反馈只算同组接触，并用每轴前两名极值求排除自身后的外框。
- 短检应确认冻结时 S0 输出与原 L0 逐元素相同，新增几何反馈每阶段只调用一次，且解冻后当前出口能沿布局对前缀反传。用本地显存实测确定 batch，再登记训练参数。
- 所有版本用固定 dev2000 和同一后处理预算比较混合 Q、P95、最差 Q、硬合法及软约束。逐阶段记录原先被异组模块隔开的同组块对有多少形成有效接触，并统计这些接触能否保留到 S4。

## 本地队列

固定 seed 0、FP32 CUDA Graph、batch 64，末批 32 个真实样本。每阶段最多 8 小时或 200 轮。S1–S4 依次训练，每次核验并加载前一阶段的固定 dev500 best。S4 完成后，用加速版强化后处理自动评估同一原 no-MIB dev2000。接触追踪使用 S0 的受阻同组 MST 边，逐阶段统计有效接触和 S4 保留数。
