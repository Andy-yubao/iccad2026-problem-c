# E18：固定E17模型的快速后处理

2026-10-20用户明确授权长期自主研究、运行训练和评价，目标是在同一v5开发500例上全部硬合法、模块数加权平均Q<1.04、平均单例推理+后处理<0.25秒。优先充分研究后处理，确证仍不足后才调整模型并重训。用户授权不视作在开发期间反复读取封存测试；本轮只使用原train/dev与已有产物。

## 固定参照与测量

参照为E17 best51，SHA256 `3de22809e831edf11b56a85647a0bd9fe625e8b7617abb6eb1f4b27969cfe00a`。旧500例加权Q=1.060518、推理+后处理平均1.915333秒、500/500硬合法；原始草稿0/500硬合法。旧结果只复用，不更换checkpoint或改写终末记录。

新算法独立复制E17模型与后处理，[provenance.json](provenance.json)保存来源哈希；没有跨实验私有算法导入。输入来自冻结v5缓存的公开`case.solver_inputs`，不把参考坐标或Q分母交给优化器。旧缓存中训练graph不被索引，另存公开输入和冻结网络草稿缓存；case仅保留公开硬约束参考。网络输入特征在本实验重建，计入单例推理时间。草稿缓存固定2库线程逐例测量，以匹配E17每例资源口径、隔离特征/网络时间；此准备阶段有意串行计时，不以批量吞吐取代单例时延。

CPU候选评价统一2进程×每进程2线程，共4线程；计时为每例公开特征+CPU网络+decode的固定实测值加当前优化器墙钟，排除文件/模型加载及评分。后续验收还需完整接口直接计时，不能只依赖缓存计时。所有失败/异常计入主统计，行排列底解虽合法但Q很差，不能靠丢弃它们降低均值。Q沿用原分母，是派生任务中性时间开发诊断，非正式比赛分数。

## 阶段假设与停止条件

1. **批量稀疏建模。** 保持凸面积约束及IRLS线长主化，将按边Python建模改为NumPy/SciPy稀疏块组装；向量化拓扑与接触量化。若同预算不能增加有效迭代，或几何/硬合法明显退化，则不作为加速证据。原拓扑及量化在五例上逐值对照。
2. **少量锥迭代+精确投影。** 检验3～6次锥优化后一次固定形状、精确曼哈顿线长LP能否替代长循环；LP也批量构建并使用Clarabel。固定形状单独无法合法化时仍保留合法底解，失败计入主分。
3. **边界引导的拓扑。** 对比网络默认关系和同边界模块沿切向分离，检查软违反与尾部。若平均收益来自严重退化其他类型，则停止直接替换，研究公开输入风险门控。
4. **必要时重新设计初始种子/结构。** 只有前述机制在固定模型、相同面板上充分失败后，再依据反例调整结构预测或训练；先后处理、后模型的顺序遵从用户本次要求。

先按公开实际模块数分层选5例作机制与数值检查，再固定开发100例初筛（按模块数排序每5例取中间一例），候选冻结后开发500例确认。开发100/500都已属于适应性研究，不称独立盲测。模型保持冻结；不按参考Q选择每例候选。

## 已有证据与入口

初筛记录按运行快照区分版本：

- `20261020_screen1_*_dev100`：初版向量化，平均约0.17～0.19秒，但部分方案频繁保留Q约10的行底解；单纯缩预算失败。relaxed6加权Q约1.0619。
- `20261020_screen2_*_dev100`：硬非重叠、松弛面积锥可减少变量，但固定保守面积切线与错误拓扑叠加会大量不可行，不能直接替换。
- `20261020_screen3_*_dev100`：消除全模块对frozenset映射，向量化组内生成树及DAG约简；五例与原算法输出逐项一致。接触树临时对象曾触发约0.06～0.13秒完整GC，故速度改善并非只来自原生求解器。
- `20261020_screen4_*_dev100`：边界引导+近接触重加权改善质量；全组宏观排序会过度约束且制造不可行，已否定，不继续沿该方向调参。
- `20261020_screen5_adaptive_near_dev100`：按公开模块数分配预算，在固定100例初筛得到加权Q=1.037716、平均0.218614秒，但3例仍为低质量保底解，不能宣称完整达标。草稿自归一化目标的两个对照未胜出，不作为当前候选。

三轮完整500例已否定此前候选：

|---|---:|---:|---:|---|
| `full1_adaptive_rescue` | 1.304219 | 0.231868 | 7.511444 | 硬拓扑不可行后，短时打包救援会质量崩溃 |

两例分别为固定开发面板index164(n57)、366(n87)，原E17已分别需约11.45/15.70秒。它们仅用于解释已有开发反例，运行时不按成员ID触发或查表。救援门控使用公开输入计算的不可行状态/几何代理异常。完整而非截断的种子构造加周期接触投影，已在这两例中恢复到约2.53/1.15；仍须记录尾部退化，不能只靠加权均值隐藏。

`certify_polish.py`对已保存full3的500个输出进行低成本刚性移动，按原E14充分条件验证中性Q不退化，全部官方复评分确认无退化：13例改善、加权Q降至1.051072，额外平均0.001244秒。它是有限改善，单独不能达标，见[runs/20261020_certified_polish_saved500/results.json](runs/20261020_certified_polish_saved500/results.json)。未重跑网络推理。

当前`20261020_full4`比较`robust_fast`与`robust_aligned`：缩短普通例预算，仅对无解/严重公开几何异常构造完整种子和周期接触投影；另对照网络草稿的公开线长/面积自归一化，避免把真实参考分母输入优化器。两组都保持E17冻结权重和同一500面板。该面板已用于开发，不能称独立测试。完整验收还需要脱离缓存的直接接口计时。

[原后处理五例剖析](runs/20261020_profile5_seed0/results.json)与[热点](runs/20261020_profile5_seed0/hotspots.txt)显示，大量时间花在Python建模、重复拓扑和迭代组织，原生锥解只占部分耗时；Profiler会改变迭代次数，剖析时间不作部署成绩。首例还包含官方评分器懒加载，后续优化不得把冷启动隐藏到结果之外。

[五例机制对照](runs/20261020_vector_controls5_seed0/results.json)确认向量化拓扑与原实现一致、输出量化一致；少量迭代已出现约0.05～0.29秒的合法解，但固定形状直接投影仍会回退到Q约10，五例不能代表完整开发集。该五例对照使用第一版投影，后续版本由运行源码快照区分。
