## 假设与独立实现

E17为每个模块分别预测长宽比，部署后处理再把MIB组形状统一；这一变化会改变矩形几何，而训练没有经过同样的形状投影。E19在网络每次几何头输出后，将全自由MIB组的log长宽比按组聚合；有公开固定/预放置成员的组直接使用其公开长宽比。decode阶段统一组内宽高，公开锁定形状传播到该组自由成员，同时按预测中心构造左下角，不把MIB统一当作推理后的独立改形状步骤。

参数仍为497,299、宽96、4层attention；不恢复已退役架构，不添加新关系头、不生成教师库。输入仅公开规格，参考坐标仍只作监督。MIB聚合与解码在本实验独立维护，训练loss与推理使用同一decode。它只保证MIB形状的一致性，不保证消除重叠、满足所有软约束或最终Q改善；原MIB面积改变后的参考矩形仍未必合法。

## 控制与训练

保持v5 train16,000/dev2,000及固定train/dev_monitor各500、seed0随机初始化、E10八项geometry损失与前2轮几何项渐入、固定geometry+occupancy开发代理选模。中心/形状/相对位置/接触参考监督不衰减。batch32，AdamW，梯度裁剪1，初始学习率1e-3；四档严格为`1e-3/2.5e-4/1e-4/5e-5`，第15轮起3轮显著停滞进入下一档，8轮早停须实际下降3次且最低档完整训练验证。相对显著改善门槛0.1%、绝对1e-5；细小真实改善仍保存best。最大4小时/200轮，预算是保护而非收敛证明。

相较E17，仅模型MIB投影/解码及匹配的物理精度恢复变化；不增加参数或更换成员。E17完整原参考矩形张量缓存作为只读数据产物精确复用，不跨实验导入私有算法、不重新处理18,000例。`provenance.json`登记原准备身份，`cache.py`核验冻结registry、paths、共享datasets源码、成员和所有chunk状态；预处理内容不变。新的model/loss/decode源码及缓存兼容声明进入新运行身份和源码快照。旧checkpoint不作为续训起点。
