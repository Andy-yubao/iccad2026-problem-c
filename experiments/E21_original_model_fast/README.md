# E21：保留原E10模型的同版快速后处理对照

正式100例对照已完成，三组均硬合法100/100。lp_gate加权Q1.055165/平均0.283795秒，qp_gate为1.055603/0.254413秒，weighted为1.049960/0.335047秒；均未同时达标。同版lp/qp控制在此面板不如E19模型，停止扩大原E10权重方向。weighted缩小中小例预算使救援增多，实际平均时间反而增加，否定当前预算分配。原保留基线不修改，不据此续训或换历史checkpoint。

长期任务的备选因果对照。当前E18/E20快速后处理均先以新训练模型为输入；旧E10模型训练成员、预算和输入面积版本与E17/E19不同，不能假设新模型必然更好。E10仍是要求保留的参照，本实验仅复用其既有冻结attention best77，不恢复退役架构、教师集或旧训练。

先准备独立实现，不与E19训练及主500例争用计时资源；E20完成初筛后才决定是否评价。只读取v5开发公开输入，所有模型采用同一v5监测500、计分和同版快速后处理。原模型数据暴露与当前开发仍按原split_v1分片隔离；旧开发反馈历史不消失，不把结果称独立测试。禁止按参考Q在多个模型间逐例择优；任何组合门控须只读公开几何及计入全部推理成本。

模型实现为E17中等价的独立attention子集，参数名及计算与保留原attention相同，严格加载原E10模型配置/权重。特征源与E10保持一致；不附加E19 MIB解码，形状统一由同版后处理负责。所有算法从E20逐文件复制，来源哈希见provenance.json，不跨实验导入私有代码。

入口与E20一致，正式计时必须--direct；例如：

```powershell
& .\.conda\envs\iccad2026\python.exe -u -B -m experiments.E21_original_model_fast.run --tag 20261020_model_control --count 100 --configs lp_gate qp_gate --direct
```

未评价前不宣称此模型更好。确认面板与E20事先固定的500例保持一致，测试封存。结果、原子恢复和STOP规则同E20，输出归本实验runs。

[五例数值兼容检查](runs/20261020_compatibility5/results.json)已确认本地等价attention实现的全部输出state及物理布局与独立复制的原E10实现逐值完全一致。legacy_model.py/batches.py只作这一兼容依据，不跨实验导入运行算法。

除相同lp_gate/qp_gate控制外，预先准备weighted预算候选：普通路径按公开模块数分配0.04/0.07/0.22/0.65秒（n<60/90/110/其余），保留相同失败救援与硬合法检查。其理由是官方Q权重随n指数增加，而普通路径的CPU预算可在同一平均时间约束下重新分配；不按开发成员ID或参考Q定制预算。若小例尾部或实际总时间恶化，计入结果并否定候选，不把名义预算当实际时间或排除失败。
