接受条件只用公开面积、线长、软违反与硬合法；`max(1,A_new/A_old,W_new/W_old)*exp(2*delta_soft/N_soft)<=1`为中性Q不退化充分条件。没有逐例参考分母或Q oracle。形状变动允许范围及MIB/固定/预放置仍由硬约束保护。五例官方重评分确认接受后的Q均不增。

记录勘误：早期`stats.certificate_scope`字符串沿用“fixed shapes”，对于shape/compact两组不准确；实际是否调整软块形状以config中的shape标志及源码快照为准。证书按实际新旧面积/线长及软违反计数计算，对软块形状变化仍适用。已修正后续源码描述，原运行记录不改写。

这些检查使用已保存的E25最终布局，没有重新推理；单例附加修复约0.1～0.26秒，且E23并行训练，**不能直接加入全部样例或宣称整体提速**。当前不替换E25。后续重点应是公开风险门控、减少无效不可行尝试，或以修复替代额外救援；不能只在尾部无限追加预算。

## 下一步可能方向：仅记录，未批准启动

### 已有Loss及历史尝试

当前E17/E23训练损失并非重叠对计数。[E23 losses.py](../E23_capacity_geometry/losses.py)将模块对的最小分离穿透深度按局部模块尺度归一化，平方后对所有可变模块对求和，再除以模块数；重叠项系数为0.5，前两轮渐入。一个模块与多个模块重叠会累积多个项，但没有显式的逐模块聚合后非线性拥挤惩罚。

[occupancy.py](../E23_capacity_geometry/occupancy.py)已有交集面积、每块重叠负载平方、空白与紧凑性定义，当前仅用于固定监测/选模代理，不进入E23的geometry反向传播。不能因为日志里出现crowding，就称当前训练已优化拥挤项。

历史上有两类相关证据：

- [旧E7结论](../../history/20261018_E10_consolidation/experiments/repair_friendly_draft/conclusion.md)：曾加入重叠面积、局部拥挤等整组occupancy训练项。同10例草稿的重叠多计面积从10.0101%降至8.0571%，三重以上覆盖面积/bbox从0.4334%降至0.1436%；最终Q基本持平，没有平均耗时改善证据。该方案已经退役，不能自动恢复。这也不是重叠单一系数的消融。
- [E16 loss.py](../../history/20261020_E25_consolidation/experiments/E16_reference_curriculum/loss.py)：渐进训练采用过重叠系数1→10，但损失是按较小模块面积归一化的相交面积，同时参考监督减弱、质量权重增加。其数值不能直接与当前穿透平方的0.5比较，结果也不能单独归因于重叠权重。

已核对的训练源码与记录中，未找到保持当前其余Loss不变、只提高0.5系数的正式对照，也未找到三次方重叠训练的正式对照。

### 建议的顺序与判据

1. **先等待并分析E23容量对照。** 它保持当前Loss，约50万→137万参数。比较同版数据上的训练/开发中心误差、重叠深度与尾部，终末后处理先与E17原同版入口比较，不能直接与E25快路径混比。训练和开发中心误差都降低，可支持容量相关解释；只改善训练集应考虑泛化；草稿改善而最终Q不改善，应继续分析解码/后处理。不能仅凭一次扩大容量证明唯一原因。
2. **优先做单因素的重叠权重对照。** 若届时仍有必要，固定架构、参考中心/相对位置/接触监督、数据、LR及选模约定，先比较0.5与1.0；更高权重只作为后续候选。不同时改幂次、监督衰减和其他权重。检查梯度量级、中心偏差和布局膨胀，避免通过拉散草稿降低重叠。这里只登记候选，不实施训练或改动活跃E23。
3. **复杂堆叠用逐模块聚合量描述。** 同时报告逐对重叠面积、归一化穿透分位数、三重及以上覆盖、每块冲突度、最大冲突连通簇。训练代理可考虑`c_i=sum_j(intersection_ij / public_area_i)`，再对`c_i`作平方或只对高负载尾部惩罚。平方聚合会产生跨邻居的交叉项，比单纯对每一对独立提高幂次更直接地强调“一块同时与多块冲突”。这与旧occupancy有概念重合，应作为需要新授权的精简独立消融，不能自动恢复旧整套方案；离散度数只作诊断，不直接作为可微Loss。
4. **三次方保留为备选，不直接替换平方。** 当前深度已归一化：d=0.1时d²=0.01而d³=0.001，因此换三次方可能削弱大部分冲突的惩罚及梯度。若检验深冲突尾部，可保留平方基础项，再增加经尺度/梯度校准的阈值三次项或其他凸尾部项，而不是假设“次数更高必然更强”。指数、阈值与系数需要分开对照。

验收继续区分草稿几何与端到端价值：同一固定开发面板下比较加权Q、尾部、硬合法、救援频率与完整单例时间，中心误差/面积重叠单独改善不算最终胜出。好坏20例只用于解释，不能反复按这20例选方案；封存测试不读取。正式长任务届时另定预算和命令，不因本记录自动执行。
