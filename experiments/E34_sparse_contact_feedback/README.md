## 假设

仅研究contact_static/contact_feedback，固定E32 `replay seed0`由原始结构代理选出的best，不按E32终末Q更换模型组、checkpoint、阈值或权重。接触分数重算周期仍每三次关系调用。分离轴使用原物理启发式；不在本项实现稀疏轴反馈，以避免新不确定对的延迟预测改变dense缓存语义。
