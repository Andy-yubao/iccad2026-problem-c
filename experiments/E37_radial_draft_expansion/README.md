# E37：draft位置径向扩展5%的受控研究

用户于2026-10-22要求实施：只拉开位置，相对draft中心的距离增加约5%，宽高不变；模型调整继续挂起。随后明确授权先五例，再固定100例，必要时额外500例开发确认；CPU最多4进程，每进程1数值线程。E25/E36原件冻结，测试封存。

## 事前假设与精确操作

设每块中心为c_i，draft外包框中心为m。仅使用公开输入和模型输出，执行c'_i=m+1.05(c_i-m)，再以原宽高还原左下角。所有宽高逐位保持不变，不做2%/10%扫描，不缩放模块图形。不使用参考几何或Q选择变换。

对全部块作相同径向扩展时，中心差整体乘1.05，块对左右/上下顺序保留；在宽高固定的情况下，原shape的mode0分离轴也应保持（舍入临界点单独计数）。成对物理重叠不会新增，重叠程度应不增；但近邻接触会产生间隙，分组连通、线长和外包框可能恶化。将这两面一起观察，不能把重叠率下降直接当成质量提高。

扩展可以产生负坐标和预放置位置违反。固定形状块只要求宽高不变，其位置可以移动；预放置块的原始公开坐标则不能改写。E25首个shape子问题把seed中的预放置位置写入等式，返回时又恢复原公开规格，因此直接输入移动过的预放置块可能让首轮卡住。将该接口效应和扩展假设分开：

| 固定策略 | 操作 |
|---|---|
| reference | 原draft直接进入原E25逻辑 |
| radial5_literal | 所有模块中心径向扩展5%，直接交给原逻辑；保留初始违规作为诊断 |
| radial5_restore | 同一径向扩展后，后处理入口立即恢复预放置块的公开坐标；自由块的负坐标由原规划处理 |
| radial5_rebase_restore | 同一径向扩展后，先作使全布局非负的最小公共平移，再恢复预放置规格；这是额外入口对齐，不能称作纯径向5% |

三种展开策略的原始radial5完全相同，raw和实际送入求解器的input都保存。对reference与restore路径验证预放置入口坐标一致。原始规格、面积、引脚等输入不因展开而改写，最终输出继续硬守卫与合法保底。后处理固定为本实验独立复制的E25原逻辑（同资源1线程），不叠加E36尚未接受的方向修正，以隔离输入变换效应。

五例沿用329/496/368/127/332。通过实现检查后，冻结实现，在既有E35固定100例上比较四臂；该100不按本轮质量选样，复用同一冻结模型的原始draft。若有对齐策略在加权Q、平均耗时、CVaR95点估计上共同不劣，并检查最大Q和严重逐例回归，则只选一个固定候选进入额外500确认；不在500后继续调5%幅度或对齐方式择优复评。没有联合收益则结束，不勉强扩规模。

必要时500使用E36已保存的非monitor开发500的原始冻结draft，与本轮100不交叉；该面板已被其他开发研究使用，不能称为独立未见测试。若触发确认，保留同输入、同资源原逻辑对照，明确计时范围。模型参数、checkpoint和数据划分不变。

主指标为全部实例硬合法、加权Q、实测预处理+后处理均时、P95耗时、CVaR95、最大Q、逐例Q变化及分片配对区间。辅助观察原draft/原始展开/对齐后input的重叠图、穿透深度、负坐标与预放置偏移、分组违反、近接触保留、外包框/线长、分离关系翻转，以及最终相对原始draft的位移和形状改变、规划调用数、累计位移与救援。Q计分在求解结束后进行，非法draft的罚分不作为质量收益。

## 本轮结论（已完成）

五例检查及固定100例四臂比较已完成；400/400个正式输出硬合法，CPU实测为4个进程、各绑定单CPU槽，Torch/数值库线程均为1。累计流水线墙钟77.50秒，分析与绘图另计。模型冻结、测试未读取。

5%径向展开确实减轻了输入重叠：成对重叠面积和/总面积0.10868→0.07996（相对下降26.4%），重叠对81.69→62.02，但未形成联合性能收益。直接输入的预放置坐标与原子问题非负要求冲突，58/100例首轮PrimalInfeasible并进入救援。恢复预放置坐标后，加权Q1.024074→1.029700，均时0.200674→0.202251秒；再作公共平移后，CVaR95改善，但加权Q变为1.040439，均时0.204228秒，且例261出现明显回归。因此没有候选通过事前规则，**不扩大500例、不替换E25、不继续扫描扩展幅度**。

这轮结果区分了三件事：重叠减轻、相对次序保留、近邻组装保留。纯展开几乎保留mode0分离关系，却将原有近接触拉成间隙；按本轮较严近接触阈值，原近接触平均保留率仅0.5%。该指标是阈值敏感的几何代理，不能解释成99.5%的有用拓扑被破坏。后处理最终仍能重建多数近接触，但调整幅度没有降低。恢复预放置臂的面积/线长gap略好，分组/边界罚项变差，说明重叠量不是当前优化难度与Q的充分指标。

后续值得研究的假设是：保留组内接触与固定锚点，仅对持续冲突局部施加有方向的位移，并以可回滚的进展判断干预；本轮只提出此假设，未实现、未训练或新增求解。
