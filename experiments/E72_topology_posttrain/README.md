## 失败证据与可证伪假设

E63单纯降低中心监督权重没有形成升级；E65几何消息只有小幅收益；E68完整端口组合未改善。E70把重叠由8.426%降到3.820%，但外框广泛扩大，用户不接受；E71恢复紧凑度，却使重叠回升到4.972%，flash尾部最大Q达到3.7928。E61稳定大模型dev G较好、flash Q1.024106略优，但raw重叠仍高于E42，微小Q优势不足以升级。结论是表达、监督对齐和修复友好性仍需共同检查，不能把所有失败归为容量不足，也不能因旧大模型失败认定扩容无用。

五个固定E62训练例的冻结E42输出诊断见[runs/diagnosis/five_case.json](runs/diagnosis/five_case.json)：现有最小穿透轴与参考近邻分离方向冲突的重叠对分别为1/9/12/5/15；后三者并非按规模推断。三例还存在不再重叠、但近邻次序已反转的模块对2/3/1个，普通重叠项不能识别。新项与原重叠项梯度余弦从-0.134到0.793，说明不能视为简单增加旧重叠权重。输出空间短步也给出反例：新总Loss下降方向会在部分案例提高交面积或外框；它不是实际Adam更新，不能保证训练成功。这些证据只支持尝试，五例不承担选模或泛化证明。

组合假设：保留E42已学结构，扩大容量以容纳几何关系修正，同时加入有方向的近邻分离监督，减少碰撞的错误修复方向。若train/dev固定Loss均不改善，或方向错误改善而重叠/紧凑/Q仍恶化，组合失败；不把Loss下降自动称为更好的草稿。

## 模型、初始化与固定Loss

96×12 E42 best51扩宽为192×12。采用均匀二倍通道复制，Linear输入列权重除2，LayerNorm复制参数，q/k每头内部复制并各缩放`2^(-1/4)`以抵消注意力维数变化；v/输出、图通道与FFN同步映射。eval模式初始函数在FP32误差内保持；Dropout训练掩码独立，不能宣称训练动态相同。源码[ widen.py ](widen.py)，五例实际输出一致性为启动门槛。不是重新从头训练，也不加载曾见过64k的E61模型，源模型只见过原16k。

固定目标`L = G + 0.5 T`。G保留E42八项公式及权重，reference仅作为监督，不进入模型。对G同样的参考近邻对，选择参考有分离的轴及其方向，用`relu((w_i+w_j)/2 − sign(Δref)·Δpred)/s_ij`的平方、双向求和除有效模块数作为T；参考本身相交的对排除。具体实现[topology.py](topology.py)。该项同时处理穿透和相反次序，但它仍不是完整意图邻接、硬合法保证或可修复性证明。

训练反传、train/dev500监测、完整dev2000使用同一固定目标，无渐入。best/LR/早停只看dev500同目标均值，Q仅终末辅助。保留epoch0作为初始参照。沿用seed0、v5 train16000、固定train/dev500、batch32、FP32、四档LR与原早停规则；权重暖启，Adam/调度器重置为新后训练阶段，历史时间单独记账。沿用E61已验证的图层实际Adam位移1%保护，不改变前向图聚合，不以全局clip替代实际步长保护。

本轮优先组合，不以隔离容量因果为目标：扩大容量、新拓扑项和实际步长保护同时使用。复用已完成E63 control以及E42/E61冻结结果比较，不重复已有终末评价；胜出后再决定必要消融。当前比较只能支持组合收益，不能将全部收益独归扩宽。

## 运行与继续决策

独立环境，项目根目录执行：

```powershell
.conda/envs/iccad2026/python.exe -u -B -m experiments.E72_topology_posttrain.preflight
.conda/envs/iccad2026/python.exe -u -B -m experiments.E72_topology_posttrain.pipeline --resume
```

每组最多2小时/200轮，预计训练约1～2小时，新宽度尚未实测全程，终末评价另计；GPU单组串行，CPU终末2进程×2线程，总计四线程。输出`runs/20261029_e42_topology_seed0/`，阶段日志`runs/train.log`、`final.log`、`draft100.log`、`report.log`；best/latest保留完整恢复状态、数据顺序、RNG、调度与步长保护计数、累计预算。创建本实验`runs/STOP`安全停止，移除STOP后原命令`--resume`，不重置预算、不重新终末选checkpoint。

训练后自动完成唯一best的dev2000、一次flash500、同100例reference/current/E42无评分图及机器汇总。后续唤醒实际查看图和失败案例。train改善而dev退化时先检查泛化证据和子群，必要时使用冻结嵌套32k且保持dev不变；两者均改善但Q更差时，重点检验Loss与邻接/紧凑/修复代价的错位。不能把小train-dev间隙当作泛化充分，也不能把有限自适应dev证据称为独立盲测。

[study.json](study.json)登记6个候选/累计18小时初始研究资源上限与30分钟唤醒。达到预算是停止扩展和报告的边界，未达研究目标不得冒称成功；E42/E50基线仍保护，正式升级需证据与草稿判断。
