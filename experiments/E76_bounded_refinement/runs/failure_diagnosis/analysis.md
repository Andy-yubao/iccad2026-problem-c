# E75失败定位与E76假设

工具会话58044明确终止，状态error、step3374、epoch3、累计666.333秒。没有因观察超时重启，也未运行终末后处理。E75 own-Loss best仍是源E74的epoch0，不能把早期交面积降低但G/总Loss恶化当成训练成功。

源E74在同一个被拒批次平均L0.380677；失稳E75为16.9744，最坏例17039的L392.51，主要仍由原G的接触/位置等异常构成。所有图聚合参数保持不变，其他参数累计大幅偏移；局部attention/FFN/head恢复干预只部分改善。这说明逐模块0.5%单步投影没有阻止长期表征漂移。

据此，E76保留同一Loss，但全冻结E74 encoder，在其公开预测几何上加可训练、零初始化、有界的修正器。它直接阻止源表征被改坏，同时让模型学习局部碰撞/间隙修正。与E66当年的从头共享/增量网络不同，本方案不恢复旧控制器或权重，而是复用已证明有草稿收益的E74函数；是否足以改善Q仍待完整评价。

源主干eval、修正器训练Dropout、输出幅度界和可训练参数域在启动前固定。边界可能过紧、源模型错误可能不可达；这些都是可推翻方案的失败模式。预检不是泛化证据。
