## 先分析失败，再修改

[保存的同500例诊断](runs/diagnosis/saved_pair_analysis.json)没有支持最初的“直接加分组连通性代理与原始线长Loss”方案：E77原始分组代理比E76更低，但同例代理变化与最终分组变化相关只有0.00985。最差164的原始b2b线长/参考为1.00678，修复后变为1.65996。因此原始线长已经接近参考，继续压低它不能解释主要退化；该提案只保留诊断实现，没有正式训练。

[次序与修复记录分析](runs/diagnosis/order_certificates.json)进一步发现：最差164的29个主形状候选全部未通过合法性，固定形状projection不可行，最终调用三次packed救援并产生大幅移动。同组MIB形状在修复器准备阶段会被统一，E77有499/500例至少一个维度改变超过1%；模型的原始几何不等于修复器实际开始处理的几何。

差分约束分析发现436/500例的原次序不支持固定形状、非负坐标和预放置位置同时满足。不过极宽松的可变形状必要条件仅1例失败，所以**不能把436例说成实际SOCP都不可行，也不能据此单独归因于MIB**。这些证据只支持减少准备阶段的形状突变、降低固定模块间通道挤压这一待验证组合。

## 新组合

完整载入E77 own-Loss best38，继续训练它已经学好的最后21,860参数修正器；不叠加第三个新头、不从头训练。E76来源的5,851,799参数仍全部冻结且始终eval，E74公开预测外框及0.15局部残差界保持。

输出增加公开MIB组的协调：相同公开面积、且固定规格相容的组共享log长宽比；存在相容固定成员时服从公开固定规格。不改变面积与预放置位置；不相容或面积不同的组跳过这一硬协调，保留原监督。协调后仍投影进原E74预测框。由于这一步改变输出，**初始函数不是未投影E77**，但所有原权重完整复用。五例初始探针中MIB项归零、4例交面积增加；后训练是否能补回这一取舍必须实测。

固定Loss为`L=G+2I+5E+0.25A`。G八项原系数保留，I/E完全沿用E77。A在当前公开几何上按原mode0规则选分离轴和先后次序，做16次max-path松弛；如果这些块沿某轴排开后挤过了预放置模块的位置，就产生通道过填压力。A为归一化超量的均方加0.25倍最大平方。它是有限步固定形状代理，不是合法性证明；分离轴/次序使用普通离散选择，不做直通梯度，梯度通过已选路径的尺寸传递。

Loss从epoch0全程固定，反传、train/dev500、完整dev及best/LR/早停相同。组合同时改变输出参数化与训练目标，只能先报告组合效果。新AdamW/原四档LR、clip1、decay0.0003是新Loss阶段，来源Adam与预算不被覆盖，不冒称精确续训。
