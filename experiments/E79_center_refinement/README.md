## 组合机制

冻结完整E78的5,873,659参数，训练时始终eval。新增96维节点/32维消息的中心修正器，仅21,763参数、零输出初始化；起点物理布局等于E78，预检最大状态差在FP32容差内。每轴中心改动不超过0.15个公开面积等效边长，并夹回原E74公开预测框。尺寸、log长宽比、MIB协调结果和固定/预放置规格逐字保持，不再通过独立改形状降低重叠。

只运行一次昂贵源主干，按E78原运算顺序重建其输出与框；五例独立源模型核对通过。推理输出6通道：前三个是本轮中心/形状状态，后三个是分离梯度的公开源预测。decoder只读前三个；后三个只供Loss保护源次序使用，来自模型自身公开输入，绝不是reference或标签的新输入。

## 固定Loss

`L=G+4I+5E+0.1R`，G八项原系数完整，I为实际交面积比例，E为单侧平方log参考外框扩大。提高I的权重，以弥补E78已观察到的草稿重叠退化。

R是一侧退化保护：源几何按原mode0规则选择每对模块的分离轴与先后次序；只在新位置把这一选择的优势降到所需下限时惩罚，下限取源优势与0.1较小者，聚合为均方加0.25最大平方。源位置上R为零，沿已有健康方向继续推远也不会获得奖励，不再像旧方向Loss那样持续拟合所有非碰撞对的参考方向。源拓扑也可能错，因此这是软保护，不是禁止换序，更不保证合法。

删除E78的通道A项：尺寸固定后，它在当前离散分离选择下没有普通的中心梯度；不对离散选择做直通估计。训练/固定train-dev500/完整dev/best/LR/早停共用上述唯一固定Loss，无渐入。新增位置容量、更强I与保护共同改变，只能先报告组合收益。
