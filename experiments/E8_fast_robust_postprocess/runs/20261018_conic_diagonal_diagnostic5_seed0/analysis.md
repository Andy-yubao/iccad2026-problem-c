## 为什么改变表示

原流程用多条直线近似面积下界，求出过小面积后继续加切面。新方法直接使用等价的二阶锥：

`norm([w-h, 2*sqrt(A_lower)]) <= w+h`，其中w/h为正。

这精确表达`w*h >= A_lower`。主配置保留原方法的信赖范围与保守面积上界切面，因此不需要反复补面积下界。放弃上界切面再统一缩小形状的版本也做了对照，但本面板质量更差，未选为主配置。

曼哈顿线长需为密集连线逐项建立辅助变量；普通二次替代虽然减少变量，却造成稠密二次矩阵。最终配置先用IRLS构造平滑曼哈顿线长的二次上界，再利用`(u-v)^2 <= 2(u-m)^2+2(v-m)^2`（m取上一轮两端中点）分解成单模块项；在上一轮处函数值与梯度匹配。这是改变优化子问题的机制，不是减少评价连线或改变官方评分。

worker65的第一轮原曼哈顿锥模型有11,953个变量，完整二次/分解二次均为1,461个。完整二次的首轮原生求解约0.689秒，分解二次约0.052秒；分解版第三轮得到合法候选，并在1.3秒档完成正常质量输出。它同时保留公开软规则、兼容MIB类、固定尺寸、预放置与终末严格复核。少量位置LP用于恢复接触精度。
