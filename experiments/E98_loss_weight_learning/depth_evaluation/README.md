# E98固定计算深度评价器 v1

此版本仅供E98新研究。原E98/E101后处理不修改，原Q不与本版本直接混用。原几何实现复制来源和SHA256记录在budget.json。

主整形深度按n<60、60–89、90–109、110以上分别为4/4/7/8次，由旧基线训练100例保存轨迹的实际shape调用数75百分位定标并固定；不使用Q选择预算。主整形内Clarabel上限100迭代，投影80，容差原样。保留质量/合法性驱动的自然提前退出；无可行改善时最多2次扩展整形、一次无接触投影。备用种子固定[2,0,1]，每种最多4次主整形，必要时也允许2次扩展；精修最多接受4次、检查240候选。装箱无deadline，固定顺序和shape_trials=1。work为各次调用自身计数，备用递归计数单独保存在trace/work中，不把主调用计数冒充完整工作总量。

主路线不读时钟作分支决策，内部求解器不设time_limit；时间只作测量。达到MaxIterations时仍须通过原残差门禁和独立硬检查，不放宽容差。不同硬件/库版本仍可能有浮点差异，不声称跨平台逐位一致。

短检为五例保存的训练草稿，各复现两次，只检查确定性和硬合法；不调用网络、dev或测试。正式反馈每例一次。该检查不是质量或完整延迟结论，且执行时泛化基线可能正在训练。

depth_evaluation/solver.py是唯一新入口。repair目录复制的旧高级入口不作为本版本执行路径；新入口使用固定预算的fast_geometry/projection/packing/certify_polish组件。预算、源代码或数值环境变化后缓存失效，必须登记新身份。
