# E98 best71逐层布局观察

2026-11-07完成。结论：这五例支持“各层工作方式不均匀、后期更新较小但仍有用”，不支持“12次位置预测多数无效”，也不能证明模型失败主要由表达能力不足造成。现在没有实施或选定新结构。

## 身份与边界

增强版E98，96维、12层、best epoch71，checkpoint SHA256 `3f7ca0086af8a13bd52eedf0635117312e5c0a72e80e423e9cee3db5ca9b87ea`。只使用其原登记训练集合的5例，按元数据预选N=21/45/70/95/120，对应索引314/36/22/62/75；没有按图或结果挑例。

历史MIB平均面积变换和原关系输入保留，以观察真正训练过的模型；不计算MIB罚分或Q，不代表新无MIB协议的基线。原始reference仅在模型外用于监督张量与事后比较，网络输入由`inputs_only`白名单剥离全部自由reference字段。没有test读取、训练、修复、回退或终末评价。

CPU FP32、eval、batch1。forward不改写，通过hooks读取真实调用；同五例带钩子和不带钩子的最终输出逐位一致，模型参数与原checkpoint不变。CPU诊断不是GPU性能评测；5个训练例不支持总体泛化结论。

## 源码对原假设的修正

`generalization_baseline/model.py`中，输入产生96维h，然后调用共享head得到s0；每个块使用`h + state_embed(s * mask)`，再通过注意力/图聚合/FFN更新h，并再次调用同一head。实际是 **13次共享预测头读出**，不是12个相互独立的位置头。

96维h始终保留，不存在“每层压缩为3维坐标后丢掉隐藏特征”的硬瓶颈。位置既通过3→96的线性嵌入反馈，也进入几何注意力偏置。预测头确实只有96→96→3两层线性变换，几何偏置网络也只有19→24→4；但这些小网络嵌在12层递归组合中，不能按局部MLP深度直接断言整个模型表达浅。

训练只将最终输出送入同一Loss；没有为初始或中间读出设独立目标。因此早期图差，可能反映中间坐标只是内部计算状态或共享head尚未适配该层的表征分布，不能等同于一个充分训练的浅层模型很差。

## 观察结果

重复覆盖严格定义为(模块面积总和−占用并集)/模块面积总和，区别于会多重累计的成对交面积。中心步长为相邻解码中心的平均欧氏位移/√总有效面积；reference距离不是唯一布局质量标准。

|120|84.94%|57.91%|27.35%|18.90%|8.88%|53.0%|

五例算术平均：初始83.05%，第6层52.27%，第7层26.18%，第8层15.76%，第12层6.50%。第7层附近有明显的布局展开；第8层以后中心更新迅速变小，但仍消除约58.7%的第8层剩余重复覆盖，不能按“小位移”把后期计算视为无价值。

观察并非逐层单调：第9层在N=21/45/120例上的重复覆盖略增，同时框面积降低；这显示几何指标存在取舍，也不能据此称第9层有害——它的状态仍供后续层使用。

初始自由模块x/y解码坐标贴0比例约59%–83%，所有观察层的宽高比±5截断触发率均为0。原始中心变化与解码中心变化在早期差别明显，图中的“在原点挤成一团”部分与非负解码截断有关，不能直接归因于隐藏特征全都相同。

隐藏特征RMS由约1.1增长到约3.0，未观察到历史E95那种数量级放大。位置反馈RMS/输入h RMS前期约0.29–0.31，后期约0.12–0.14；图聚合与注意力分支仍有非零幅度。但这些分支可以相互抵消，幅度不是因果贡献率，更不能证明位置反馈必要或无用。

## 对结构问题的当前判断

有必要检查“关系推理、位置反馈、最终解码的职责分配”，尤其是浅预测头对不同层表征的适配，以及早期大量坐标截断如何影响后续关系构造。但本次证据不足以选定删除位置预测、增加预测头深度或其他结构改造。前六层可能主要准备潜在表征，也可能反复解码确有低效率；只读布局无法区分这两种因果解释。

同样，“加深加宽无法解决”仍应作为研究判断/假设，而非本次五例证明的事实。后续若讨论新方案，应分别解释信息表示、推理深度、解码能力与监督/优化，而不是把当前草稿重叠统一归为参数量不足。
