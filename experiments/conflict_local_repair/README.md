# E5：冲突驱动局部重构探针

状态：**无训练坐标重插入探针完成，当前不进入局部学习。** 未实现区域联合移除/重构或条件生成模型，不能把此探针当作完整局部生成方法的否定。

假设：在相同冻结初始化与增量时间下，冲突定位的至多 12 个自由移动块比随机同规模选区、全局可行搜索更有效。主指标为包含所有样本的官方中性时间加权 Q，越低越好；初筛 seed=0，冻结 dev5，CPU 1 线程。

[probe.py](probe.py) 使用历史 baseline search 的唯一已保存坐标作为共同起点。求解函数只接收合法输入与冻结初始坐标，不接收历史分数、参考布局或参考指标。选区来自线长热点、边界违反和 grouping 断裂；preplaced 永远不进入可动集合，fixed 可移动但尺寸锁定。每次只重插入一个块、形状不变；候选改善通过全图硬检查才接受，区域外逐坐标保持相同。全局控制从同一初始化用同样重插入算子在所有可移动块中选点，不额外调用历史 baseline 的完整构造。

[geometry.py](geometry.py) 与 [packing.py](packing.py) 从 baseline 在 2026-10-16 复制所需输入准备、代理目标、硬检查和重插入算法，独立维护，无跨实验算法导入。运行快照保留实际调用时源码；之后删去未使用的完整求解入口，未改写既有运行记录。

## 五例结果与停止判断

[唯一逐例结果/坐标](runs/20261016_coordinate_probe_dev5_seed0/results.json) · [配置与源码来源](runs/20261016_coordinate_probe_dev5_seed0/config.json)。每个控制每例 **3 秒增量预算**，共同初始化的历史构造/搜索成本在三组中都未计入，因此不是 15 秒端到端比较。

| 控制 | 硬合法 | 加权 Q↓ |
|---|---:|---:|
| 冻结初始化 | 5/5 | 1.909019 |
| 冲突选区（最多 12 块） | 5/5 | 1.905960 |
| 随机同规模选区 | 5/5 | 1.909013 |
| 全局坐标重插入 | 5/5 | 1.903646 |

冲突选区在 3/5 例优于随机，但 **0/5 例优于全局控制**；实际最多改变 5 块，区域外始终完全未动，三类全局软违反没有变化，bbox 也没有变化。当前收益主要是少量线长压缩，不支持“局部重构比全局搜索更划算”的晋级条件。暂不投入至多 1 小时的局部模型训练，也不把五例轻微收益称为普遍改善。

本次不适用性：坐标单块动作不能表达需要多个块共同腾挪的区域重构；未发现/统计一般草稿中必须改变全局 bbox 的比例。若后续 E1–E3 出现新的冻结候选，可另立明确探针检验，不自动重复当前预算。
