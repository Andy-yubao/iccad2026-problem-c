# E6 设计：让生成布局与修复过程共享可检验的关系

2026-10-17更新：模型五组训练与完整评价已完成，转入后处理研究。当前目标、职责和资源以第9节为准；第1–8节是首轮设计/运行定义，涉及有限微调、5%门槛及旧停止条件均已撤销，不再作为当前要求。修改前全文按原字节保存在history/20261017_alternating_optimization。

同日修订：**模型调整优先，后处理随后**。从模型草稿本身理解意图是默认路线，禁止任何关系头或额外关系输出。模型与后处理应相互减负，不先为修复当前误差较大的草稿开发复杂重构系统。

## 1. 目标与可证伪假设

设合法输入为 I，模型只给出三通道布局草稿 z，由 T(I,z) 从几何和公开规则推断候选关系，修复器 R(I,z,T(I,z)) 输出布局。用户明确禁止任何关系头，本实验不再保留该备选。目标是降低达到优质硬合法解所需的位移、形变和时间，同时保留好草稿的线长、紧凑性与软关系。这里“生成”指全局提议，不预设必须使用随机生成模型。

| 假设 | 为什么可能有效 | 反例与停止信号 |
|---|---|---|
| H1：局部尺度与几何/关系监督比纯绝对 MSE 更接近可修复性 | 大量远距离块对方向正确，仍掩盖局部冲突、形状与接边误差 | 同架构、同预算下，监督或关系指标改善但有限修复成功率和最终质量不改善 |
| H2：从轻微重叠等几何线索推断候选接触，优于一律推远/重排 | 修复器能保留草稿隐含的接边结构，且不要求增加模型输出 | 同一草稿下，推断接触比普通分离更差，或常误判并造成全局冲突 |
| H3：按组连通、动态边界和兼容形状建模优于逐块局部罚项 | 直接对应现后处理缺陷，而非简单放大权重 | 与冻结几何启发式关系控制相比，同预算无收益；软违反下降却面积/线长大幅损伤 |
| H4：结构化/分层解码能减少坐标与关系矛盾 | 可先形成可实现的局部骨架，再组合全局布局 | 前三项足以解决问题则不实现；若实现后骨架常与锚点或角约束冲突，停止增加层级 |

H1–H4 是机制候选，不要求全实现。优先对模型的容量/表示和目标分别做有界机制对照，不能要求先造好修复器，也不要求 Loss 探针成功才允许更改架构。随机多候选、学习修复器后置；禁止任何关系头。保留原始参考的工程价值，也承认参考有软违反及多种等价布局，不要求逐条复制参考接触图。

## 2. 模型与修复器的接口

### 2.1 三类信息分开

**公开规则由输入决定。** 面积、fixed/preplaced、MIB/group ID、指定边/角、连接与端口全部来自遮罩后的合法输入。不能让网络重新猜规则，也不能由意图输出覆盖它们。fixed 仅锁尺寸，preplaced 锁位置和尺寸；普通块面积在原容差内，不用软约束破坏硬条件。

**从几何推断的偏好允许撤回。** 例如两块轻微重叠、法向接近分离、切向覆盖明显，可能希望相切；小间隙、近边/角、近同形也能提供线索。推断必须结合归一化误差、相对方向、公开规则和邻域；不能把所有重叠都解释成接触，也不把所有候选限于 grouping，普通块也可能适合相切。只有公开 grouping 的连通才是相应软规则。模型禁止输出任何关系头。候选排序未校准前不声称是概率或可行性保证。

**修复器负责一致性。** 从偏好中选取兼容子集，记录接受、替换、撤回与原因；遇到冲突时调整离散决策，不能把不可靠偏好全当成硬等式。所有候选仅用输入和自身几何评价，禁止读取参考坐标、参考 HPWL/bbox 或测试反馈。

### 2.2 修复器内部状态，不作为模型输出

模型接口严格只返回三通道几何张量。下表除geometry外全部由修复器从草稿和公开输入计算，不是关系预测头，也不是模型辅助输出。

| 字段 | 内容/来源 | 约束处理 |
|---|---|---|
| geometry | 每块中心与 log(w/h)，由输入有效面积恢复宽高 | fixed/preplaced 在解码时锁定；输出 XYWH 与原评分接口一致 |
| separation_candidates | 从草稿冲突/近邻几何提取左、右、上、下候选与排序值；只由几何推断，不由模型输出 | 每对允许多个等价方向；选择后仍须检查全局可行性 |
| contact_candidates | 从轻微重叠/小间隙提取块对、接触侧、切向区间；grouping 边候选另标记 | 接触不只限于 grouping；组内可替换连接骨架，不把全组每对都强制接触；连线不等于必须接边 |
| boundary_state | 公开指定边/角、从草稿计算的 bbox 形状、当前边界支持块 | 指定边来自输入；草稿 bbox 只作初值/偏好，不成为新固定 outline |
| shape_preferences | 草稿宽高、MIB 兼容子组及偏好 | 成员归属来自输入；兼容性由面积和公开规格检查，冲突组可保留多种尺寸 |
| decision_trace | 关系接受/撤回、失败子问题、软残差与阶段时间 | 用于解释失败，不宣称一次子问题失败证明全局无解 |

T 完全由草稿与公开规则构造，数据字段仅为修复器内部状态，禁止模型额外输出。边界标记、group/MIB ID 本来就在输入中，重复传递它们不能当作“学习意图有效”的证据。

## 3. 全局提议：目标函数与架构候选

### 3.0 旧损失的实际实现

冻结确定性模型的正式入口为 E1 [train_supervised.py](../graph_proposal/train_supervised.py)，`components` 与 [model.py](../graph_proposal/model.py) 的确定性 `training_loss` 均采用同一 masked MSE，目标由 [data.py](../graph_proposal/data.py) 编码。

令 S=sqrt(sum_i effective_area_i)，其中普通块用输入面积，fixed/preplaced 用公开宽高乘积。每块监督状态为 z_i*=((x_i*+w_i*/2)/S,(y_i*+h_i*/2)/S,ln(w_i*/h_i*))，即两个归一化中心坐标和一个对数宽高比。每例损失为：

    L_layout = sum_i,k m_i,k (z_hat_i,k - z_i,k*)^2 / max(sum_i,k m_i,k, 1)
    L_batch  = mean_over_layouts L_layout

普通块 mask=(1,1,1)；fixed 非 preplaced 为 (1,1,0)；preplaced 为 (0,0,0)。有效标量通道等权，没有独立位置/形状权重、局部块尺寸加权、连线或大布局权重。总损失不是简单的中心 MSE 与形状 MSE 的算术平均，两项有效通道数不同；两分项仅分开记录。

训练直接比较 head 状态与标签，不经过 decode、correct 或 pack。Loss 没有重叠、接触/连通、boundary、MIB、HPWL、bbox 或修复位移项；约束虽进入模型输入，但无直接约束损失。普通块保面积和固定规格锁定是解码实现，不是这些条件已被 Loss 优化。优化器 AdamW 的 decoupled weight_decay=1e-4 另属参数正则，不能称为几何罚项。正式 best/降学习率监测也使用固定 dev_monitor500 的逐布局平均 masked MSE。

这为早期确定性/flow 对照提供了简单训练起点，但局部接边对微小误差敏感，单参考逐块误差并不直接约束关系；全局尺度归一化可能掩盖小块相对误差，中心与 log 比例的数值量级也未单独平衡。现有残差仍可能涉及架构、优化或多解监督，不能把不足全部归于 Loss。历史 flow 分支回归线性噪声路径的速度而非直接回归干净状态，当前冻结模型不使用该分支。

### 3.1 模型优先：目标与表示分别检验

G0 为 E1 的冻结确定性模型，保留原权重与哈希。为比较训练目标，另从头训练 G1（原架构/原 MSE）和 G2（同架构/新目标），统一 workset_v2、初始化种子、预算和训练策略；不能只用训练时长不匹配的 G0 证明新 Loss 有效。新目标包含下列候选项，实际权重和开关在运行前固定：

- **局部尺度监督**：中心误差除以每块 sqrt(effective_area)，形状用 log 比例及宽高相对误差；仍保留全局位置/端口锚定信息，避免局部指标丢失全局尺度。
- **局部冲突与分离余量**：重点监督冲突/近邻及锚点附近，使用四个分离间隙的平滑代理；同时监测精确穿透和无重叠。不能仅靠远距离块对的高准确率证明改善，也不能仅靠推大间距减少重叠。
- **grouping 接触**：对组内构造可替换的连通骨架；边法向间隙和正的切向接边长度共同约束，避免重叠或只碰角被代理误奖励。接触监督只从 train 标签提取；可容许多棵等价连接树，不把全部不接触对设为绝对负例。
- **boundary**：到输出自身 bbox 指定边的残差，角要求同时满足两个方向；精确计数仍按官方逐块口径。不能只靠缩小预测 bbox 让损失虚假为零。
- **MIB**：只对可兼容成员施加共享尺寸偏好；相同宽高比不等于相同尺寸。对不同面积的自由块，先判断允许面积区间有无公共交集；公开固定尺寸冲突单列。区间相交只是初筛，还要检查尺寸、几何及原计分取整条件。
- **线长和紧凑性**：输入可算的加权中心/端口 Manhattan 线长、bbox/总有效面积及形状正则联合报告；不固定芯片外框，不把扩大 bbox 当作免费修复。训练可用 train 参考作监督/归一化，推理选择不能读取实例参考基准。

规则代理是训练信号，不是官方违反数，不承诺可微惩罚严格等价于 Q。特别是 grouping 连通与 MIB 四位小数形状数属于离散量。最终硬合法性、B/G/M 和 Q 只由原官方评分与独立检查确认。

### 3.2 再检验架构

G3 是架构/表示对照，不以 G2 新 Loss 先成功为条件：类型化连接/MIB/group/boundary 信息，保留 pin 空间分布，交替使用局部消息与全局注意力；在草稿坐标上引入相对几何交互，默认只输出几何。与原架构使用相同 Loss、成员和预算比较；若最后组合架构与新 Loss，再做必要交叉归因。具体宽深先按算力试算确定，不能把“大模型”当成机制解释。

禁止增加关系头、意图头或额外关系输出。训练可从标签几何构造关系损失，但其梯度只更新三通道几何预测。MIB 共享形状只用于经过兼容检查的子组，不能强绑定整组。

G4 是备选的组级粗布局→接触骨架→块级几何的结构化解码；只有连续草稿与关系长期不一致时实现。此时可推倒重做表示，不默认继续在 64×3 上加层，也不恢复已暂停的 flow/E4 或已删除路线。

### 3.3 修复感知训练分阶段进入

模型优先阶段直接用原始几何/关系指标评价，旧修复器冻结并仅作辅助对照，不先建立复杂修复器或立即反传。后续简单修复器稳定后，再独立测量可修复性。修复含离散换向、接触选择与失败兜底，直接“端到端可微”容易产生错误梯度或把昂贵修复藏进训练预算。只有固定方向子问题的梯度与数值稳定性通过检查后，才考虑短步展开或从 train 修复轨迹提炼监督；生成这些轨迹的计算也计入预算。旧 pack 的输出不能默认充当优质教师。

## 4. 修复器：从保持合法输入到协调全局规则

本节在模型改进后实施，是候选机制清单，不是首轮必须实现的复杂模块列表。先从较好草稿做普通分离与接触候选推断的简单对照，再按剩余反例增补规则；不要求修复器先解决旧模型全部严重冲突。

### 4.1 硬条件、偏好与搜索的顺序

1. 输入/数值检查，锁定公开规格；若草稿已经硬合法，保留其原坐标作为 incumbent。单独的“仅恢复可行”模式必须原样返回；可选软优化必须经输入可算目标证实收益并通过硬检查才替换。
2. 先冻结形状，由草稿/候选意图选分离方向；求带位移信赖域的 LP/QP。对所有潜在碰撞维护分离约束，或用添加冲突对→重求的方式补齐，不能只修原始碰撞后忽略新冲突。
3. 固定方向无解时，在预设轮次和时间内撤回低可信关系、改轴、换连接树，保留已知合法候选。方向环路、锚点冲突和时间停止分别记录。
4. 只有位置修复不足时，另启面积合法的最小形变：自由块按 log 比例重算宽高，交替更新形状与位置并重新检查。宽高变化与面积乘积让联合问题一般非凸；固定形状/固定方向子问题的凸性不等于全局保证。
5. 硬可行后，在同一位移/形变预算中完善软规则和几何质量；失败时保留 incumbent。需要超预算大改动时，单列“放宽修复/兜底”，不能计为微调成功。
6. 最后用官方与独立硬检查、真实 bbox 和官方 B/G/M 复核，满足后才交付；若需最终合法构造兜底，开销与频率全部计入。

选定横向接触 i→j 时，约束 x_i+w_i=x_j，并要求切向区间有正长度交叠；固定形状与方向时可用线性约束表达。普通分离关系只需不重叠，不加统一正间隙破坏接边。数值修复应维持同一共享边，官方严格拓扑/浮点行为必须直接复核，不能放宽评分容差来通过。

### 4.2 三类软规则需要全局状态

**grouping。** 在硬合法几何上维护接边图和连通分量；候选收益按减少分量数评估，而不是仅奖励“碰到一个已放同组块”。组内边可替换，只需连通，不要求复制参考的每条边。仅有近距离、重叠或角接触不能作为满足接边的机制证明；最终以原评测器的 union 结果为准。

**boundary/角。** 把 L/R/B/T 与所有块包围关系一起维护，始终用实际输出极值核对；可探索边界支持块/外围带，但不固定任意外框。新外移的块可能使旧边界块失去资格，必须重新检查全部受影响成员。角要求同时考虑两条边及局部可容纳性；必要时撤回其他接触偏好，不能让一个软目标压倒硬规格。

**MIB。** 先按公开尺寸和自由块允许面积区间分析兼容子组，再尝试共享宽高、局部形变或拆组。自由面积区间为 [0.99 A_i,1.01 A_i]；实现时须考虑官方容差与四位小数 shape 计数，不把这个简化区间交集测试当作完整不可行证明。不得改面积、换原标签、强行旋转 fixed，或把不同真实尺寸伪装为“比例一致”。可证明的刚性冲突下界和实际剩余违反分别报告。

### 4.3 候选选择、质量和失败报告

优先硬合法；有限修复目标首先满足位移/形变预算，再比较输入可算的线长、bbox/总有效面积、精确软违反和布局关系损伤。保留多目标记录，不靠逐阶段随意加权掩盖代价。推理目标的归一化、权重及同分处理在 train/dev 固定；**不能在线用参考 HPWL/bbox 计算 Q 或挑候选**。训练代理可借鉴 log 质量分的加性软罚结构，但无参考代理不声称精确等同官方 Q。

区分数值失败、方向子问题无解、形状/规则冲突、预算停止、硬检查失败和大改动兜底。LP/QP 无解只否定该组方向/形状/预算约束；不能当成不存在任何小幅联合修复的证明。原始固定形状的必要位移下界也不能用于否定允许形变的方案。

## 5. 执行阶段与门槛

**执行顺序：G1/G2 模型机制探索与归因 → R0 简单修复校准 → R1 改善后草稿修复 → X 联合归因。** 下文保留各阶段编号便于追溯，R0/R1 不再作为模型工作的前置条件。

### R0：校准接口与“微调”

预先选择固定 5 例 train，优先从 workset_v2 的 train_monitor 中按 SHA256('intent_repair_r0_v1:<shard>:<row>')，分别在 worker0/24/49/74/99 取最小值；选样不读标签或成绩，实际成员写入 config。参考只作诊断输入，不能作为真实求解输入或另存伪训练面板。

同一五例做原样参考、位置扰动、自由形状扰动、二者联合扰动，seed=0；位置幅度为局部尺寸的 1%/5%/10%，形变按下节定义。preplaced 不动，fixed 尺寸不变。参考原样与编码解码往返分开；先解决旧诊断已暴露的浮点接边问题。

门槛：5/5 原样硬合法输入在仅恢复模式原样保留；1% 受控位置扰动在 5% 位移档 5/5 硬合法，且质量损伤低于旧 pack。其他扰动分档如实报告，若失败先检查修复算法/方向/数值，不将合成扰动失败归为模型问题。另用最多 5 个定向反例覆盖：锚点堵住首选方向、角与组接边竞争、MIB 刚性冲突、bbox 扩张使边界失效、仅角接触/重叠造成假连通；不另跑大数据测试框架。

### R1：冻结提议，对照修复器

## 6. 指标、晋级和停止条件

令 s_i=sqrt(effective_area_i)，位移 d_i=||c'_i-c_i||_2/s_i；形变 e_i=max(|log(w'_i/w_i)|,|log(h'_i/h_i)|)。普通块面积保持合法，fixed/preplaced 按公开规格锁定。tau、eta 分别取 0/1%/5%/10%，主要研究档预设为 **tau=5%、eta=5%**；同时报告 eta=0 的纯位置修复。5% log 宽高变化近似 5% 相对尺寸变化，不是 5% 宽高比变化。

“微调成功”要求实际输出证实所有可动块 d_i≤tau、所有可变形块 e_i≤eta，并通过全部硬检查；同时记录 Q、HPWL/bbox 与软违反，不能仅因微调可行就称质量优秀。联合扰动是否在预算内存在解要逐例检验，不假定受控输入必定可达。

| 层次 | 必报证据 |
|---|---|
| 原始提议 | 冲突量、固定形状位移必要下界、局部中心/形状误差、冲突/近邻方向与接触残差；train/dev 分开 |
| 有限修复 | 全部样例各档成功率；最大/P95/均值位移与形变；关系保留、撤回及失败原因；未成功仍计入分母 |
| 最终输出 | 官方与独立硬合法率，含失败的块数加权中性时间 Q，HPWL/bbox gap、B/G/M、软率、耗时/超时/兜底频率 |
| 意图机制 | 学习关系 vs 同几何启发式、屏蔽意图、可替换关系数量与不可行原因；参考关系只作标签辅助诊断，独立列出 |

固定 dev_quality100 的阶段晋级提示：全部例最终硬合法（若靠兜底仍须公开），相同总预算下加权 Q 优于匹配的最强控制，同时 5%/5% 有限修复成功率或位移/形变分布也改善；若仅其中一项改善，明确标为质量改进或可修复性线索，不宣称二者兼得。报告逐例配对变化和按规模分组，不能由一个聚合分证明因果或泛化。

先在模型阶段检查表达、优化与目标，不将修复器建设设为先决条件。后续 R0 不过先修简单算法；R0 过、R1 失败则分清模型残差与几何推断歧义，不自动增加修复复杂度；原始几何改善但旧/新后处理都无收益则检查代理与接口。每个机制允许一次有明确原因的必要修正，之后仍无信号就暂停或转结构化解码，不无限调权重/扩训练。保持固定门槛，不因结果放宽 5% 定义。

### 8.2 补充联合微调必要条件诊断

在正式dev100评价前补充一个只用于评价的乐观下界：对自由块宽、高同时允许独立缩至原值exp(-eta)，暂时舍弃面积约束；fixed/preplaced尺寸仍锁定。每对块在该乐观形状下仍需分离的最小穿透，除以两块可动sqrt(effective_area)之和，下界最大值仍是必要的中心移动预算。其乐观放松包含真实允许形变集合，所以下界超过5%可排除5%中心移动+eta形变的联合修复；下界不超过5%绝不证明可修。eta取5%和10%，额外记录固定形状结果，不能混称实际最小修复代价。

它不进入训练、监测、候选选择或超参调整，不调用新合法化器。四个合成定义检查覆盖完全重合、已接边、固定形状不可缩、双预放置冲突，均通过；不扩大数据面板。该补充使“允许小幅形变”也能获得可证伪的必要条件，而非仅凭固定形状下界推断。

### 8.3 已实现几何损失的逐项解释

实现以 [losses.py](losses.py) 为准。网络输出仍为归一化中心与 log(w/h)，面积和公开固定规格由解码器落实。旧目标是对未锁定输出维度做 masked MSE；新目标先在每个布局内求各分项，再对 batch 的布局等权平均：

\[
L=L_c+0.25L_s+0.25L_r+\alpha(t)(0.5L_o+0.5L_t+0.25L_b+0.1L_m+0.1L_a).
\]

其中局部尺度为 \(s_i=\sqrt{A_i^{\mathrm{effective}}}\)，块对尺度为 \(s_{ij}=(s_i+s_j)/2\)；尺寸锁定块使用公开宽高乘积。以下数值均在同一归一化坐标系内计算。

| 分项 | 实际定义与目的 | 边界 |
|---|---|---|
| 中心 \(L_c\) | 对中心误差除以各自 \(s_i\)，再做 β=0.1 的 SmoothL1 | 小块错位不再因全局尺度小而被忽略；不是相对误差的平方损失 |
| 形状 \(L_s\) | 自由形状的 log(w/h) MSE | fixed/preplaced 的形状不学习；不直接允许面积浮动 |
| 近邻相对位置 \(L_r\) | 参考矩形间距不超过 \(0.25s_{ij}\) 的块对，比较预测与参考中心差向量，除以 \(s_{ij}\) 后做 SmoothL1 | 约束局部邻域，不要求预测关系头；近邻标签只在训练/外部评价使用 |
| 重叠 \(L_o\) | 令 \(m_{ij,k}=|c_{i,k}-c_{j,k}|-(d_{i,k}+d_{j,k})/2\)，惩罚 \([\max(0,-\max_k m_{ij,k})/s_{ij}]^2\)，按布局块数归一化 | 是最小轴分离穿透，不是相交面积；代码对有序块对求和，两方向均计入，0.5 权重与此定义一起冻结 |
| 接边 \(L_t\) | 只对参考中已有正长度公共边的同 grouping 块对，惩罚法向间隙平方；切向重叠不足 \(0.01s_{ij}\) 时加 hinge 平方 | 防止只让中心靠近却仍重叠、分离或仅角接触；复制参考接触是监督代理，官方规则只要求整组连通 |
| 靠边/角 \(L_b\) | 对公开指定侧，计算矩形到当前预测整体 bbox 对应边的距离，除以 \(s_i\) 做 SmoothL1 | 动态 bbox，角同时约束两条边；没有固定画布 |
| 同形 \(L_m\) | 同 MIB 且有效面积 log 差小于 0.019 的块对，惩罚 log宽、log高差的均方 | 只是兼容性启发式与软偏好，不是整组可行性判断；不改变锁定规格 |
| 外框 \(L_a\) | \([\log(A_{\mathrm{bbox}}/A^{\mathrm{ref}}_{\mathrm{bbox}})]^2\) | 匹配参考尺度，同时惩罚缩小和放大；不是直接最小化面积，也没有直接 HPWL 项 |

涉及块对的规则排除自身、padding 和双方均为 preplaced 的不可学习块对。没有对应对象的分项为零。训练时 \(\alpha\) 在前两个 epoch 从0线性增至1，先建立基本几何再逐渐增加规则压力；监测始终使用完整权重，所有对照的 best、学习率和早停选择标准一致。

**科研含义。** 这些项使误差尺度与局部修复难度更相关，但不等价于可行域投影，也不保证在5%位移/形变内有解。接触、边界和同形是可调整的软监督，仍可能相互竞争；因此同时报告形状退化、重叠、必要位移下界与最终质量，不能只看总Loss下降。新增 `baseline_local` 消融检验五项显式规则在局部监督之上的整体贡献，不能据此分别归因给某一个规则项。

### 9.1 当前实现与研究记录

`global_refine.py`保留旧pack的合法候选，并从原始草稿及当前合法布局建立分离图，尝试全局LP；候选只按公开输入的几何/线长及B/G/M代理比较。合法原始输入本身也作为incumbent。`shape_lp.py`联合优化XY与WH，面积下界用双曲线支撑割平面逐步收紧；上界由局部线性约束保证（由加权AM-GM可得），每步实际面积仍检查并保持原±1%范围。锁定公开规格，已经兼容的MIB尺寸类共享宽高；不把刚性冲突硬绑定。

分离方向从当前几何重建；初期可使用弹性分离变量跨过错误拓扑，但非法中间状态从不作为结果。组内候选接边树同时要求法向靠近与正长度切向重叠，可替换、可撤回；它是接触启发式，并非精确全局连通求解。边界相对实际动态bbox建模。补充迭代重加权L1，以趋近“违反对象数量”而不只是距离和；公开输入代理仍不等同参考归一化的正式Q。

`canonical_geometry.py`把数值上已接边的关系放在一致的二进制坐标网格，并用带偏移的等式分量协调，保持公开fixed/preplaced精确值。没有更改评分器、重叠容差或面积容差；最终官方和独立硬检查一致才认可。`topology_mip.py`是可选离散方向/接触探索，初探计算重且未优于连续方案，当前不作为默认。
