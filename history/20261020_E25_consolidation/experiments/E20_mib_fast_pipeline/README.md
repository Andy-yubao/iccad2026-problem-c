# E20：MIB一致性模型与快速后处理联合流程

正式100例直接计时初筛已完成：fast加权Q1.035713/0.287869秒，lp_gate为1.036370/0.280194秒，qp_gate为1.036261/0.261333秒，均100硬合法。选择qp_gate完整500例验证，入口为`--tag 20261020_full1 --count 500 --configs qp_gate --direct`，结果尚未验收。100例不是完整目标或独立测试，不能据此宣布Q达标。

这是长期目标的联合验证入口，独立复制E19模型、E18向量化后处理及E17底层参照，不跨实验导入私有算法。[provenance.json](provenance.json)保存原文件哈希。模型仅在E19正式训练结束后冻结其唯一best，`runs/frozen_model.json`保存哈希并禁止替换候选；尚未训练结束时入口拒绝冻结，不读取进行中的权重作为正式候选。

数据继续为v5公开输入及同一开发500例，测试封存。原E17输入缓存只作为只读数据产物，训练graph/自由参考坐标不被索引或输入算法；case中的评分分母仅由外部官方评分使用。模型特征构造、CPU推理和decode计入单例时间。MIB公开固定形状在物理精度恢复后共享到自由组员，网络中心保持一致。

当前准备三项固定模型对照：`fast`为E18当前保留的快路径，`lp_gate`在无有效解且即将触发长救援时先尝试一次固定形状投影，`aligned`额外使用网络草稿的公开线长/面积作自归一化。LP前门控不读取Q或参考坐标，只根据可行性；若可行即避免昂贵延长迭代。所有额外投影、打包、救援与证书移动都计入求解墙钟。

```powershell
& .\.conda\envs\iccad2026\python.exe -u -B -m experiments.E20_mib_fast_pipeline.run --tag 20261020_initial --count 100 --configs fast lp_gate aligned
```

在E19训练和主评价结束前不运行正式时间比较，避免共享负载污染。先固定开发100例机制检查，再冻结候选完整500例，最终需直接API计时、独立硬检查及冻结后的额外开发复核；不把适应性开发成绩称独立测试或正式比赛分数。目标仍为500/500硬合法、模块数加权中性时间Q<1.04、平均单例推理+后处理<0.25秒。异常和低质量保底解计入主统计，不靠剔除尾部达标。

评价默认2进程×2库线程，共4线程；完整结果保存于`runs/<tag>_<策略>_monitor<count>/results.json`，复核时为`confirmation500`，逐例原子续写，STOP放在候选运行目录。配置、模型、数据和源码身份变化则必须新运行，不覆盖旧证据。E19训练依然只冻结一个best，不根据终末Q换checkpoint或续训；固定模型下不同后处理对照属于用户本次长期目标授权。

最终验收使用`--direct`：各计时调用实时重新构造公开特征、执行CPU模型、decode和后处理；模型加载及数据文件读取在计时外，符合常驻求解器接口。缓存只作为较早的开发诊断入口，不能代替这一验收。

训练等待期间的[五例机制诊断](runs/20261020_mechanism5_e17_diagnostic/results.json)使用旧E17公开草稿，不读取训练标签。LP入口在275/456两个困难例明显改善质量并减少救援；另三例无明显改善。精确Manhattan SOCP替代IRLS的成本过高，五例均未改善，停止扩大。此阶段与GPU训练共享负载，不作为正式速度证据，结果和源码快照保留。

后续[投影机制诊断](runs/20261020_qp_projection5_e17_diagnostic/results.json)显示，固定形状投影使用IRLS二次代理，可把大例原生求解由约0.1秒压至约0.01秒；它可能使Q退化，因此只作为`qp_gate`候选，不直接部署。`qp_gate`结合失败时二次投影与最终合法incumbent投影。提前对初始草稿投影的`qp_first`在困难例上失去后续质量，五例后不扩大。HiGHS线性投影和带阻塞传播的刚体平移均未显示优势，停止扩大；各自五例诊断保留在runs。

正式初筛比较`fast/lp_gate/qp_gate`；旧模型上已无收益的额外目标变体不重复全量比较。来源/成员/命令/平台进入运行身份。开发500验收通过后，固定方案才运行额外确认500例；[固定清单](runs/confirmation_panel.json)仅按公开模块数和哈希确定，与监测500互不重叠，仍属开发集。

`audit.py <运行目录>`独立重新评分全部保存坐标，核对硬合法性、平均/加权Q、尾部、完整计时及E17配对变化；必须完整500例且--direct才能通过验收。自助置信区间仅描述当前面板抽样不确定性，不消除适应性开发偏差。若新模型本身未改善，另有[E21原保留模型对照](../E21_original_model_fast/README.md)，避免默认新训练模型一定优于已有冻结参照。

[参考一致性离线诊断](runs/20261020_reference_consistency/diagnostic.json)发现，监测500例中485例的原log长宽比标签与严格MIB共享比值无法同时逐块匹配；解析最小shape MSE平均0.021370。它仅解释形状监督的一个不可约常数，约占当前shape MSE的一小部分，不能据此把训练误差或最终Q全部归因于数据。诊断脚本只作离线标签分析，不被任何求解器导入，不生成新教师库。全局锚定路径修复的五例也仍有失败和质量损失，未加入候选主流程。
