# E28首轮设计：先证明生成机制，再扩大规模

2026-10-21；用户批准基于上一轮可行性讨论新建研究实验。边界、命令和结果唯一入口为[README](README.md)。此文预先固定首轮假设，不按结果倒推设计。

## 问题与证据

E23将四层几何attention从约50万参数加宽到137万，训练拟合改善，开发几何/最终Q未明确改善；E27加倍重叠惩罚减少草稿冲突，也未改善同版加权Q，两组原始草稿均0/500硬合法。依据分别为[E23分析](../E23_capacity_geometry/runs/20261020_capacity160_v5_seed0/analysis.md)和[E27分析](../E27_overlap_weight/runs/20261020_overlap1_v5_seed0/analysis.md)。这些证据既不能证明任何容量扩展无效，也不能证明更低的坐标误差会自动跨越整例合法性门槛。

## 可证伪假设与首轮取舍

| 假设 | 首轮实现/对照 | 什么观察会否定继续投入 |
|---|---|---|
| H1：完整外部端点表示具有压缩中心无法提供的几何信息 | 完整端点/同编码器压缩端点，两种步数各比较一次；同时保留同中心不同L1线长的构造反例 | 反例可区分但正式开发表示收益不存在，或新增推理代价抵消可用性收益；不把表示能力反例当泛化证明 |
| H2：共享权重、多次读取当前几何比一次更新更能协调冲突 | 1/4步，参数量、初始化、数据、目标、随机键和最大累计位移相同 | 原始违反/合法率、加权尾部没有一致收益，或收益不足以抵偿实际延迟；更多步数本身不算算法进步 |
| H3：更接近公开规则的训练目标可避免只拟合过时标签 | 四组共同使用公开能量、精确加权线长和弱兼容锚点；不是独立因果对照 | 不同目标仍存在不可接受权衡，或只降低平均代理、原始Q/高权重尾部不进步；胜出后须另做Loss消融才可归因 |
| H4：随机潜变量可打破确定性对称并承载多解 | 首轮仅加入按公开数值输入哈希生成的随机节点键，所有组相同；flow/多候选分布学习留作机制不同的后续路线 | 单随机键路线仍有结构折中/无法学会选择合法拓扑；首轮不宣称已学到多模态分布或硬合法保证 |
| H5：更适当的表示与目标可能重新产生容量/数据收益 | 首轮不扩展数据、不拟合scaling law；机制有效后另冻容量×数据交叉实验 | 规模只改善训练拟合，不改善验证违反、全样例Q或相同时间预算下性能，则停止单纯扩容 |

首轮选择H1/H2的2×2矩阵为可运行主线。与E17相比，Loss及初始化策略变化是明确登记的共同背景；四组内部机制比较不改变该背景。默认先提供主候选启动入口，其余三组不是从主候选训练后继续微调，而是同seed、同基座独立初始化修正网络。

## 模型与输入

基座为冻结E25中的E17 best51，源码独立复制，权重原文件只读引用。修正网络宽96、两个GeometryBlock，最后输出头初始化为0；基座不参与梯度。每一步重新读取17维公开特征、当前中心/log比例、公开穿透/负载及尺寸反馈、两个随机节点键，逐模块聚合端点消息，再生成有限残差。每步最大中心改变量为`0.5*sqrt(area)/steps`、log比例为`0.5/steps`，用相同总位移上界控制4步组的可达范围。

完整端点分支对每个相连端点的相对坐标及其绝对值作非线性编码，再按真实连接权重聚合；压缩分支把加权中心送入同一个编码器。四组均持有同样模块和参数，不用参数量差异冒充信息保留收益；完整分支仍是聚合表示，不宣称无损或普适。基座自身仍使用原压缩特征，实验只检验修正器是否能利用新增信息。

面积按`w=sqrt(a*exp(r)), h=sqrt(a/exp(r))`解码；固定形状和预放置公开规格恢复，位置非负。**无重叠没有结构性保证**；接触、MIB与边界仍为软约束。随机节点键不编码参考坐标、分数或划分成绩，按公开数值输入哈希固定以保证恢复、各组和在线/缓存一致，不依赖数据集成员/文件标识，不用于选择最好的一次抽样。

## 固定目标和选模

按样例分别计算无量纲量，再平均：

`Lphysics = 2*penetration + 2*overlap_area + 0.25*crowding + 0.5*contact + 0.5*boundary + 0.25*mib + 0.1*wire_ratio + 0.1*bbox_ratio`

`Ltrain = Lphysics + 0.1*center_local + 0.025*compatible_shape_anchor`

穿透项是最小分离穿透/局部边长的平方，按模块数归一化；重叠面积按总模块面积归一化。拥挤按每块累计重叠面积负载计算。wire使用所有原始模块连接与端点连接、中心Manhattan距离，按冻结初稿wire归一化；bbox按公开总模块面积归一化。接触项针对初稿公开几何选出的每组MST边鼓励共享非零边段，不引用参考接触关系；该固定树可能不是最佳拓扑，不能保证可实现，是否限制收益是本轮已知反例。boundary相对实际bbox计算；MIB比较同组log宽高。

原参考仅作弱中心锚点，长宽比锚点仅用于原面积与当前面积误差不超过1%的块；**这只是必要兼容检查，不证明整组参考合法或其中心/比例联合可行**。不把参考bbox当新任务真实最优边界，不读取参考评分分母来指导网络、选择输出或修复。

选模固定为dev_monitor500的等样例平均Lphysics，不随epoch、arm或参考权重变化；同时记录按`exp(n/12)`加权的代理和硬合法率，暴露均值/尾部差异。该代理不等于Q，只用于可微训练监测；原始Q在唯一冻结best的终末阶段全部计入。若全样例Q仍为10而违反量下降，只能说明向合法性靠近，不能称为正式质量改善。

## 预算与接受标准

seed0、batch32；固定四档LR、14轮保护、3轮停滞切档、实际三次下降及最低档至少两轮。每组累计最多4小时或200轮。训练/监测不执行任何求解器、投影或合法化；训练缓存中基座草稿只由公开输入生成。终末在线推理包含实时基座计算，不用缓存草稿的批量吞吐冒充单例速度。

实现检查总共五例以内、低于20分钟。预计可能超过20分钟的正式准备、训练或评价只提供用户命令，不由助手前台/后台启动。v5测试和其他封存集均不读取。

机制初筛看违反严重度、原始硬合法率、高模块数尾部以及固定规则下的全样例Q，运行错误计入。纯模型达到加权Q<1.04需要极高加权合法率：当合法部分Q=1.02时，不合法权重须小于约0.223%；90%甚至99%合法只能作为中间机制进展。E25仍是部署参照，首轮不替换。若只有代理下降而整例可用性无进步，应报告失败并改表示/构造，不能据此无限扩模型。

单组或一个seed不足以证明机制或scaling law。矩阵若出现有用趋势，再冻结配置并扩到三个种子；若需要加入轻量精确解码，另登记为完整算法组件并同版比较，不把解码合法率归功于裸网络。数据/容量后续扩展使用原train分片池、另冻成员，不触及封存测试。

## 文献与本地推断的边界

- [Complexity Scaling Laws for Neural Models using Combinatorial Optimization，NeurIPS 2025](https://arxiv.org/html/2506.12932v2)：TSP上直接解质量随规模的实证；可行路径解码的背景不等于连续布局保证。
- [Trinity，2026预印本，附录O](https://arxiv.org/html/2610.04957v1)：FloorSet上的宽度/深度、草稿/修正/合法化分阶段对照；soft cost不是本实验Q，也不能直接移植作者算力/速度。
- [Chip Placement with Diffusion Models，ICML 2025](https://proceedings.mlr.press/v267/lee25y.html)：合成数据与跨电路迁移；不构成裸网络普遍硬合法的证明。

本实验是依据这些问题提出的独立学习式修正器，不声称已经复现上述论文，也不把局部实现检查当作论文级研究结论。
