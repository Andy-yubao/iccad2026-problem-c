# E30：两线程下的质量、速度与尾部稳定性

2026-10-22用户授权以E25为基础自由修改模型和后处理，允许启动长训练，CPU总计最多两线程；本轮总墙钟上限8小时。E25原件冻结。本实验是新研究，不恢复已经删除的原E29或暂停的E26。

**状态：已完成，未替换E25。** 普通几何三种子中2/3复现Q与均时联合改善；冻结seed0的一次额外dev500确认，Q1.051866→1.046393、平均秒0.247792→0.241181，均500/500硬合法。但CVaR95由1.435881升至1.465133，最大Q由2.614867升至3.237856，最慢秒亦恶化，配对均值差区间跨零。四次微调均已早停，测试封存，无活跃数值任务。详细证据、反例和限制见[最终研究记录](runs/20261022_research_summary/analysis.md)。下列事前方案保留作研究设计记录。

## 事前方案

1. **数值实现开销**：在相同草稿、参数、合法性及评分下减少重复拓扑和组分析。若端到端耗时不降低，停止。
2. **合法候选优先与进展停止**：尽早投影到合法布局，按公开目标改善与软违反决定后续迭代，减少墙钟截断的波动。若速度只靠质量回退获得，淘汰。
3. **关系与大模块对齐的草稿训练**：复用E25模型，显式训练参考分离关系、按模块规模加权并抑制高损失尾部；同时保留普通几何监督对照。若固定原始代理不改善或终末Q/尾部变坏，不替换基线。
4. **公开指标触发的尾部处理**：仅在合法输入和当前解显示风险时增加有限计算，保留合法incumbent。若触发过多导致均值耗时恶化，停止。

先建立一进程、两库线程、CPU亲和性限制为两个逻辑CPU的E25等价对照。所有数值任务顺序执行，不同时训练和评估；Torch interop=1、数据加载无子进程，BLAS/OpenMP/Numba/HiGHS/Clarabel均最多2线程。

数据采用冻结v5的train16000/dev2000；监测各500，测试封存。公开特征构建、CPU推理、解码、后处理、救援、最终检查均计入逐例求解；数据加载、模型加载和首次JIT单列。Q为自适应开发面板、MIB派生任务的中性时间质量指标，不是比赛成绩。

初筛seed0；开发面板后处理试验会产生自适应选择，明确披露。模型训练期间禁止后处理，每个训练组结束只评价一个由固定原始代理选定的best，不用后处理结果选择checkpoint或续训。胜出流程冻结后，在预定的额外dev确认500例上一次性比较E25与胜出流程，不据此调整。尾部同时报告P95、最差5%均值(CVaR95)、最大Q、Q>1.8/2数量及最大逐例回退；报告硬合法、各软违反、回退、HPWL/面积gap、分组和配对不确定性。

预算分配上限：诊断与后处理2小时，模型对照各最多2小时（最多2组，200轮），最终比较及整理2小时；总上限8小时优先。模型batch32，学习率1e-3→2.5e-4→1e-4→5e-5，第15轮起连续3轮无明显改善下降；最低档完成两轮且满足停滞条件才早停。提前完成或假设被推翻时不必耗尽预算。

## 运行与恢复

两组训练均从E25 best51权重开始，重新建立优化器和预算，不称旧训练续跑。选模代理固定为按`exp(n/12)`加权的E17 geometry+occupancy；两组、所有轮次完全相同，同时保留未加权原代理与分项。关系组训练增加0.25局部分离关系损失，训练样本权重为0.25均匀+0.75模块权重，并增加0.15倍batch内最差25%损失；几何组保持原几何目标作为对照。此处先验定义于两组训练启动之前。

后处理初筛固定100例（按模块数排序每五例取第三例），比较原steady、仅原生传递约简、缩短预算、预投影、提前合法化与进展停止。初筛不会打开额外确认集；胜出方案须在完整monitor500复核。原生约简保持边输出顺序、循环图回退与精度，五例及跨64节点边界作精确一致性检查。

专用环境为根目录`.conda/envs/iccad2026`。各运行保留config、源码快照、原子逐例进度、结果和分析。运行目录创建`STOP`后在当前例/批结束暂停，移除后用完全相同命令恢复。训练另显式加`--resume`，累计预算与数据游标不重置。

## 后处理阶段决策（两组训练启动前冻结）

同资源E25：Q=1.038010、平均0.251149秒、CVaR95=1.325744、max=2.525082，500/500硬合法。原生约简＋JIT：Q=1.038324、平均0.245462秒，达到旧质量/时间门槛但没有降低Q或改善极端尾部。额外公开风险修复`tail`：Q=1.037132、平均0.254446秒、P95=1.177630、CVaR95=1.323715；45例触发、16例接受，极端最差例仍未改善。差异的配对区间跨零，不能声称已确认质量提升。

快速预算、预投影及进展停止在100例中均以质量回退换速度，暂淘汰；推动修复的完整500例最差Q升至2.625380，暂淘汰。对已知最差开发例的三个机制反例（常数惩罚、边界关系、原基线快速几何）均保留退化行布局，不能依靠换这一项解决。此诊断使用开发最差Q选例，只是机制证据。

**两组模型的终末后处理固定为`tail`＋JIT**，不因终末Q换checkpoint或更换流程重评。理由是保持质量/尾部倾向，检验更好的草稿能否减少求解/风险修复开销，使速度也优于同资源E25。比较同时报告纯模型贡献（相对E25模型＋同一tail流程）及整体贡献（相对同资源E25原流程）。只有完整硬合法、Q和平均时间均下降、尾部没有明显退化的候选才考虑替换；否则保留E25。

新阶段的train seen计数只描述新阶段采样；parent best51已见过全部train16000。曲线区分当前阶段采样与继承暴露，不把旧样本标成实际未见。

若某组best仍为epoch0（父模型原权重），该组没有接受任何模型更新；终末结果的计时/墙钟截断差异不能作为模型改进。模型替换还要求确有权重更新，不能利用相同权重的再次评价择优。

在终末结果尚未知时预先规定：若seed0出现足以影响取舍的联合收益（500/500合法，Q与时间均下降，且CVaR95与最大Q改善；配对Q区间支持改善），则在8小时总预算剩余范围内追加固定seed1、2的同配置对照。只改变新阶段排列/随机状态，E25父权重仍固定，因此是微调种子复核。部署/确认候选保持seed0，不根据终末Q挑最好种子。此项使用前面阶段节省的预算，原“最多2组”为首轮规模；不会超过总时限或每组2小时/200轮。
