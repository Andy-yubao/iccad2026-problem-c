## 假设与区别

E32研究模型如何改变求解过程的离散结构；本实验研究模型如何按公开输入/初始草稿选择合适的求解策略，使有风险的快速路线只用于适合的实例。它不是增加网络参数或重训几何草稿，也不把新生成布局换成几何训练标签。训练信号是**同一训练实例在多个冻结策略下的质量/时间差**，即算法价值监督；所有计算布局无条件保存。

预定四个专家：E25原steady；同一E25草稿的原生约简＋短预算；E30已冻结seed0几何微调＋tail/JIT；E25草稿＋冻结E32 replay seed0全关系反馈。第四条在E32首组终末结果读取后、任何E33运行/标签生成之前加入：E32全反馈的加权Q/时间退化，但CVaR95及max Q改善，具有条件性互补空间；不能把其整体失败隐藏或自动升级。第四条使用原E25算子生成/复用前缀，参数与关系策略不变，微小算子舍入和墙钟预算可能使其结果不同于E32 JIT基座。短预算及E30候选此前亦未通过全局联合要求，均只作受控候选动作。所有专家源自独立复制的冻结代码，权重只读引用，不跨实验导入私有算法。

门控只能读取公开图和当前E25初始草稿的统计/嵌入；不包含参考自由几何、Q、分母、来源ID或专家求解结果。在线只运行所选专家；若选E30，额外草稿推理和门控开销均计时。保留不确定时走E25的保守策略，并用按模块数的简单选择作对照，避免把容易的规模阈值学习冒称深度学习贡献。

## 数据、监测与隔离

只为冻结v5 train16000生成四策略配对结果，SQLite原子记账并保留全部布局/命令/版本/随机顺序/预算；专家不再训练。先对预定哈希分层的1000个train成员检查理想选择器的质量/速度空间；若无空间或初始化成本吃掉收益，停止，不扩大。

为避免用开发集后处理Q选模，本实验**不生成dev策略标签供训练/选模**。在原train分片池内按完整分片再留出约20%作为门控内部监测/校准，原split_v1/v5成员不变；其中固定500个成员作每轮分类/价值代理监测，另留成员校准阈值，均不参与梯度。确切成员、实际训练数和继承的专家训练暴露单独登记。该内层角色只适用于新门控，不宣称专家未见；替代坐标模型的dev_monitor500选模，以守住“终末dev500不选checkpoint”的目的。新门控仅训练原train子集，改变数据角色的原因与数量须如实披露。

原始路线矩阵只是监督标签和内部反事实诊断，不作为新模型成果。网络best按固定内层500分类/价值代理选取，batch32、四档学习率、15轮保护、3轮停滞、三次下降及最低档两轮规则保持。校准规则必须在查看外层dev终末前冻结；外层dev_monitor500每个best仅一次联合对照，不据此续训/换checkpoint。

原专家已见过内层留出成员，因此内层留出只验证新门控，不能消除专家在原train/dev之间的性能差异。它是本方案的实际外推风险，必须用固定外层终末及冻结后确认检验；内层通过不等于整体泛化成立。完整矩阵生成后只做一次数据库哈希，并冻结size/mtime清单；训练/恢复绑定清单SHA，后续日常读取只校验增量身份，避免反复全库哈希。

## 接受与停止

至少比较四个固定专家、简单规模规则、固定神经门控；完整时间包含门控与额外草稿开销，六方法先后顺序近似平衡（500不能整除6），报告实际顺序。联合要求硬合法、加权Q和均时下降、CVaR95/max Q无明显退化；报告失败、逐例退化、救援与配对区间。若校准时只会回退E25，或所需额外推理超过收益，停止，不降低门槛凑效果。

标签准备最多6小时、门控每组最多2小时/200轮，终末及整理另预留；全部受19:39总截止。六小时保护在任何E33运行之前调整：四个冻结路径、16000实例共64000次求解，按已有每例约0.2–0.28秒及评分/记录成本估计约4.5–5.5小时。总12小时不变，实际是否扩大以1000例训练oracle诊断决定。

正式实现：约50万参数的冻结基座在同一次推理导出潜变量/草稿，门控读取潜变量均值/标准差/最大池化及公开几何/约束统计；实际特征维数、门控参数量以五例检查记录为准。不会重新运行冻结网络来获取潜变量。Gate为宽128两层MLP＋四类动作/四值质量差头，输入归一化只拟合梯度子集，目标为预定质量/时间/风险oracle动作的CE＋0.2倍对`10log(Q_a/Q_E25)`的平滑L1，直接监督相对收益。

公开状态统计包括碰撞、分组离散程度、边界距离、bbox及当前草稿的无参考Manhattan线长/归一化线长；使用真实连接和公开pins，不使用参考分母。输入的绝对质量不可直接观察，性能由外层开发评价检验。

动作oracle在任何E33运行/标签读取前固定：对动作a最小化`importance(n)*(Q_a-Q_E25)+0.05*t_a+0.2*max(Q_a-1.2,0)`，限制`Q_a≤Q_E25+0.05`。importance为`exp((n-120)/12)`除以21–120均匀支持的精确均值。这样低权重简单实例可用有限小质量代价节省时间，大实例的质量差与Q>1.2风险得到更高优先级；不把每例等权的近最优规则误当作官方加权目标。时间包含必要E25前缀与额外E30推理；实际在线完整时间重新测量。另保留“最快且Q≤每例minQ+0.002”的纯质量oracle作诊断对照，不用于训练或替换上述规则。

内部监测/校准按原train完整分片隔离：按哈希留出20%分片，再把留出分片一分为二分别供监测和校准；监测分片只取固定500，其余成员不用作梯度或校准。梯度子集另按模块数/hash固定train_monitor500。三角色完整分片不交叉；原专家已见全部train，不能称专家未见泛化。

选模代理固定为内层500监督损失的0.5模块加权均值＋0.25算术均值＋0.25最差5%均值。唯一best之后，仅在内部校准池选置信度阈值0.5/0.6/0.7/0.8/0.9/0.95，不足阈值走E25。接受阈值需校准加权Q下降>1e-4、均时下降、CVaR95不升、max Q上升≤0.05且最大逐例退化≤0.2；否则停止，不进入外层开发评价。若多项通过，先最低加权Q，再最低均时。阈值/模型/简单规模规则在外层评价前共同冻结，外层不能重新校准。

对照规模规则的档位固定为21–59/60–89/90–109/110–120，各档内部校准时选择Q不高于E25＋1e-4、CVaR不升的最快专家；在线无需门控特征，实际时间按其所需操作计算。它是学习门控的必要较简单参照，不作模型贡献证据。

规模规则也须通过相同的整体Q/时间/CVaR/max及逐例退化门槛，才能成为候选。若与神经门控同时通过，依据内部校准最低加权Q、再最低均时决定部署方法；外层评价只验证这一事前选择，不根据外层分数换回另一方法。神经阈值无一通过时用1.01表示停用，直接执行E25，不在无动作时浪费神经前缀；不能把规模规则的收益记成额外MLP的收益。

校准准入同时限制延迟尾部：P95时间不高于E25×1.05、最大时间不高于E25×1.10。它们只容许少量计时波动，避免用严重的极端延迟回退换平均数；最终仍完整报告实际分布与区间。
