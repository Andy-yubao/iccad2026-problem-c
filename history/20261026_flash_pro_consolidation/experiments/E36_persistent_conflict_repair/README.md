# E36：持续冲突的局部修复与阶段控制

2026-10-22用户要求挂起模型调整，优先降低加权Q与评价耗时并改善尾部；后处理尽量采用更简单、幅度更小的调整。用户随后明确授权同一固定100例配对对照、CPU总计两线程。E25冻结；E32/E33/E34不恢复；不训练模型或RL；测试封存。

## 首轮事前设计

基于E35已保存轨迹提出三条可证伪假设：

1. **固定形状局部平移**：同一显著重叠连续出现三轮时，至多移动四个非预放置块，逐块沿单轴寻找最近的无碰撞坐标。尺寸保持不变，不引入新碰撞；单块移动不超过0.5个公开面积平方根，单例至多两次调用。若只把冲突移向其他块、增大Q或大范围移动，就不支持该机制。
2. **及时退出**：连续冲突未得到合法最佳解时，提前转向既有打包救援，减少后续无效规划。保留原救援与合法保底，不把提前返回行布局称作加速。若只是少算而降低质量/尾部，不接受。
3. **合法后硬化**：首次获得合法形状候选后，后续shape去掉无重叠弹性松弛；此前仍用原线性增强惩罚。若限制后续关系探索或经常不可行而损害质量，则拒绝此阶段安排。

对照包括原逻辑reference、仅增加公共轨迹采集的control、hard_after_legal、local_repair、early_rescue和local_then_escape。组合臂先尝试局部平移；持续冲突达到六轮且仍未离开行保底时退出。该比较能拆分局部几何处理与提前退出的作用。初始阈值按已观察的冲突量级预设，五例只修正实现/机制，不将其成绩当作泛化证据。

五例采用已有反例index329/496/368/127/332，包含持续冲突、漂移、大幅有效调整和投影救援。随后冻结实现，仅做一次既定E35固定100例同输入比较；不按本轮Q挑成员。所有策略使用同一份已保存的冻结模型draft，计时主口径为后处理实测时间，历史draft推理时间只另列，不能与原500端到端耗时直接比较。各臂按实例平衡轮换执行；记录总预算、硬合法、加权Q、算术Q、P95/CVaR95/最大Q、HPWL/bbox与软违反、首次合法、调用数、累计/净位移和救援率。原逻辑对照用于量化采集/计时扰动。

接受条件：全体输出硬合法；加权Q和耗时在同一面板/资源口径下同时改善，并检查CVaR95、最大Q及逐例大退化。配对分片bootstrap给出不确定性，不用点估计微小收益宣布升级。位移更小属于辅助指标，不能掩盖必要修复被取消。即使100例胜出，也不自动替换E25；后续更大确认另行设计。

独立复制E35/E25私有算法，不跨实验导入算法；数据与评分复用datasets/scoring，布局图复用visualization。完整布局与轨迹留本机，紧凑证据归runs。单数值进程、CPU亲和性[0,2]，Torch/BLAS/OpenMP/Numba/Clarabel两线程，禁止并发数值任务。首轮全部数值工作累计最多20分钟，STOP可中止，恢复不重置预算或更改身份。
