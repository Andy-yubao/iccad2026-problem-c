# E38已完成容量组的阶段发现

更新于2026-10-23（北京时间）。四组训练、完整dev与唯一终末500已全部完成。按固定原始代理及draft严重度选定96×12作为下一阶段结构初筛主干，E25仍为冻结工程基线。精确结果以[配对证据](completed_comparison.json)为准；[分析入口](analyze_completed.py)仅读已有结果，无推理或测试访问。下文保留8层、12层阶段发现，并补充四组结论。

## 数据、训练与比较身份

同v5 train16k/dev2k、固定500监测、原geometry Loss及geometry+occupancy代理、batch32、四档LR和早停；seed0从头训练。控制组51轮/best51，8层43轮/best40，分别累计训练2060.44秒与2529.56秒。均因早停结束，非时间预算停止；8层最佳权重SHA256为`d41434ac1f365e625a467ac1230f51be65ad8ef1aff23f6b11b664bd05b84619`，完整dev及唯一一次终末评价均引用该冻结权重。控制组已逐张量复现E25，保留初始E25参照与新训控制两个终末对照。

在共同42轮、同样672,000训练样本呈现的检查点，深度组验证代理仍明显较低，不能简单把结果解释为12层多训练了几轮。墙钟预算上限相同，但实际每组早停时间不同；未做严格FLOPs匹配，也未做多种子确认。12层与加宽参数量仍有约7.1%差异，因此这只是当前配置家族下“加深优于单纯加宽”的初筛证据，不是所有深宽缩放的普遍定律。

下一阶段选择96×12：监测、完整dev及碰撞严重度的信号最强；大冲突簇仍然存在，正好检验E39矩形交互与E40显式约束/端点能否进一步协调。选择不依赖终末Q，未将更大CPU推理成本视作已解决。详细启动、控制复用、确定性CUDA检查和停止恢复见[后续记录](../20261023_structure_followup_r2/control_reuse.json)及所属实验README。候选验证与draft出现一致收益后再做对应消融和匹配种子确认。
