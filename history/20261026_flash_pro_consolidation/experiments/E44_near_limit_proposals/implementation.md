## 本轮交付

- [problem.py](problem.py)：严格公开输入接口；自由块按当前面积解码；兼容 MIB 共享形状；冲突组保留硬规格并记录软违反；独立加官方硬检查；简单的合法安全布局。
- [structure.py](structure.py)：每对模块恰好一个分离关系；几何拓扑及双排列两种构造；逐轴无环检查；分组接触树；相对实际 bbox 的边界附着及四个真实极值块见证。
- [geometry.py](geometry.py)：固定尺寸 HiGHS LP，完整分离、公开锚点、精确接触、正长度切向相交、实际 bbox；另有同内核软接触控制。严格记录线程与求解状态；超时只有经残差、硬规格、所选结构复核的输出才可接收。
- [solver.py](solver.py)：最多四次 LP，低置信软决定分批撤销；最多两次共享形状的受限解析更新。硬规格和完整分离不撤销，失败保留原合法安全布局。候选只按输入归一化的实际 HPWL/bbox 与离散软违反选择，不能读取参考分母。
- [gate.py](gate.py)、[evidence.py](evidence.py)：唯一五例入口、逐完成项原子保存、同身份恢复、累计预算、源码快照及环境记录。所有坐标只存一份本地 `results_local.json`。

安全布局仅用公开锚点上方的简单货架构造，**不是 E25 的竞争性替代**。本轮没有导入其他实验的私有算法。E25/E42 的既有完整评价没有重跑。

## 事前固定的五例

| 例 | 内容 | 要验证的行为 |
|---|---|---|
| 1，合成 | 四个同形方块、连通组、四角边界，安全布局有间隙 | 接触等式、正长度公共边、真实 bbox、完整分离与双排列契约 |
| 2，合成 | 两个不可移动锚点，第三块要求同时贴左右边界 | 撤销不兼容软边界；另设无环但塞不进锚点间隙的拓扑，必须原样回退 |
| 3，合成原始输入 | 同一 MIB 中存在不同固定宽高及不同面积 | 不改面积、不动硬规格、不丢实例，显式保留 MIB 软违反 |
| 4，v5 dev | `worker_17/layouts_6608.th:68`，120 块 | 最大规模的完整约束成本与锚点、接触可行性 |
| 5，v5 dev | `worker_79/layouts_5040.th:16`，57 块 | 已保存 E42 最坏 Q=1.927279 的公开开发回归例 |

后两例来自冻结 `dev_monitor500`，成员在实现求解器前固定；最后一例因已有失败记录选择，明确是自适应排错。前三例为合成约束反例，不是数据泛化证据。总共五例，不读封存测试。

真实两例各有五项，均用同一几何内核和 180 ms 设计预算：

1. `public_exact`：公开输入启发式结构＋精确接触，部署式完整入口。
2. `public_soft`：同结构和预算，仅接触改为软罚。
3. `public_sequence`：双排列构造的结构，仍检查锚点与边界的实际可行性。
4. `reference_structure_diagnostic`：明确允许本轮排错读取原参考结构，尺寸仍来自当前输入。原参考在 MIB 改面积后可能不相容，不能称其为正确结构或质量上界。
5. `feasible_structure_diagnostic`：仅读取同一开发例已保存的 E42 合法输出，固定其尺寸与完整分离，仅保留当时已真正实现且满足 1% 切向相交长度的接触和边界。这个子问题事先有可行见证，用来区分结构错误与内核兑现失败。继承的 E42 生成成本单列，绝不能当作部署候选。

合成例直接检查决定性行为；两例真实数据只作诊断，不做五例汇总 Q 排名、选模型或泛化结论。`reference_structure_diagnostic` 与 E42 见证均不进入 `StructuralSolver` 的输入。E42 结果文件哈希写入运行身份。

## 预算与解释

单进程，数值线程最多四个，Torch interop=1；HiGHS 明确 `threads=4, parallel=off`，避免多个实例或多个线程池嵌套求解。本地环境沿用 `environment.yml` 的依赖，不安装新环境。

设计完整延迟预算每项 0.18 秒；代码的时间检查和求解器 time_limit **不是实时截止保证**，特征/组装、最后检查和回退会产生超支，完整秒数及超支如实报告。数据载入、进程导入、源码快照属于冷启动/准备，单列；诊断项计入其布局准备但不伪装为公开入口。所有候选检查和失败尝试均计入对应秒数。最多两次形状更新只作为固定解析控制，不是训练后的能力。

完整检查的累计循环预算 180 秒，入口最多接受 600 秒保护。按现有规模预计数秒至数十秒，不是经测量的全量估计。预算触发保存并停止，不增候选或偷偷延长；恢复也不清零累计预算。真实的不可中断本地调用可能超过检查点预算，报告实际超时。

接受规则事前固定为：

`0.5*HPWL/(公开连接总权重*sqrt(输入总面积)) + 0.5*实际bbox面积/输入总面积 + 2*离散软违反/公开最大软违反数`。

这只是无参考选择控制，不是官方 Q。LP 用 bbox 面积的一阶近似及弱移动正则，接受时重算真实乘积与真实离散违反；不能用 LP 目标下降取代实际改善。

## 运行及恢复

在项目根目录执行，输出目录必须为 E44 的 `runs/` 子目录：

```powershell
& .\.conda\envs\iccad2026\python.exe -m experiments.E44_near_limit_proposals.gate --output experiments/E44_near_limit_proposals/runs/20261023_stageA_check5
```

中断后在原命令末尾添加 `--resume`。每完成一项写盘，最多重算中断时尚未保存的一项；已完成运行不会重评。源码、数据身份、参数或预算不符时拒绝恢复，不能清空旧结果后择优。`Ctrl+C` 可停止，不建立后台队列、定时跟进或自动续跑。
