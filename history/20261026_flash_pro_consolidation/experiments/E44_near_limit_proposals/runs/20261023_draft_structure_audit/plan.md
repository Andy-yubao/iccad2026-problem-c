# 草稿结构保留审计：事前范围

2026-10-23，用户质疑仅预测离散结构会损失完整草稿信息，要求核对现有后处理对草稿的偏好，以及保留/重建结构的条件。本轮只作源码审计和既存开发记录分析，新增训练、推理、求解及测试读取均为零；不实施新的结构模型或后处理策略。

## 样本及证据

- E39 已保存的同一 dev_monitor500：终末坐标、已保存的100+400例原草稿、原输入/碰撞及轨迹摘要CSV。重新测量结构保留，不重新运行模型或评分器。
- E42 同一面板既有500例：用已有位移、碰撞、终末分数和分支记录检查较近模型是否也有大重排。只从E39表借用经成员逐例核对一致的公开约束统计，不借用其草稿相关特征。
- E35 已有100例过程指标及逐步指标：分析原草稿→当前迭代→最终最佳布局的区别，分开看普通流程、漂移与救援。不从端点布局伪造运行中决策或未记录的对偶证据。

## 固定定义

1. 净位移按已有每块公开有效面积平方根归一化，沿用源表；新算去整体平移位移另标草稿面积归一化，仅作诊断，预放置绝不因此获得平移许可。
2. **初始已分离块对的关系保留率**：对草稿已不重叠的每对，列出当时成立的左右/上下分离关系；最终至少保留其中一个即计保留。对角分离可能有两个等价方向，不因选择轴切换直接判结构破坏。草稿本来重叠的块对不计入分母，单列比例；另报初始分离间隔≥0.05平均块尺度的稳健子集。
3. 左右/上下中心次序保留：仅统计初始中心差超过0.05平均块尺度的轴向关系。
4. 局部邻居保留：每块草稿中欧氏中心距离最近的5个邻居，在最终仍位于最近5个中的比例，再逐例平均。这是几何邻居，不是线网邻居、精确接触或公共边连通。
5. 长宽比变化使用已有平均绝对log比变化。位置、形状、邻居和全局分离须分别报告，不压成一个任意加权的“尊重度”。

源码核查须落在实际使用的steady入口：草稿尺寸/位置初始化、分离/接触提取、当前状态移动罚、当前状态与历史最佳的分工、最佳解目标以及重启条件；不用未启用的可选参数解释当前行为。

探索性条件相关在相同模块数内对秩去均值；普通/投影/救援分组只是描述，不作为因果效果。反例必须同时包含“改动大但质量好”和“改动大且质量差”。既有开发暴露、模型差异和旧预算均保留，不宣称独立泛化。

仅生成小型逐例派生表、汇总及报告，不重复保存完整坐标，不修改源记录、模型或冻结索引。本轮预计远少于20分钟，单进程、数值库上限四线程；没有新的求解实验。
