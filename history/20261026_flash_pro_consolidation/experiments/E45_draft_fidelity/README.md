## 事前假设

当前移动罚相对每轮当前状态，不能持续保护原始草稿。新方法给所有形状更新及投影增加相对**同一个原始草稿中心**的软二次锚定，以及相对公开规格/MIB一致尺寸的较弱形状锚定。原草稿只读保存，递归救援也不能把打包种子冒充原草稿。

碰撞越深，位置先验权重越低；公开预放置位置/固定尺寸始终由硬规格控制。动态版本只在同一块连续两轮仍参与实际重叠时减弱该块的锚定，未冲突块保持原权重。救援阶段以更弱权重引用同一原草稿，避免阻止必要重建。没有新的关系预测头，不改变官方打分或在线使用参考分母。

固定三臂：`control`为独立复制的steady；`anchor`为持续软锚定；`local_release`为同一锚定＋持续冲突局部释放。中心强度0.08，形状强度0.01，一次登记，不按五例扫描强度。最终合法解选择仍使用原生输入目标；锚定只影响搜索方向，不因离草稿更近而接受更差的内部目标。

## 验收与停止

硬合法必须全过。正式筛查须同时报告模块数加权Q、算术Q、CVaR95/max Q、逐例严重退化、平均/P95完整耗时、2秒超支，以及相对原始draft的中心/形状改变量。质量须有实际改善，耗时目标不增加；筛查可容忍的测量误差带事先取3%，超过即不称为联合改善。五例的好结果仅是值得扩大验证的信号，不能宣布达到加权Q≈1.01或升级E25。

若靠加大权重只减位移却增加Q，或者为了保住错误草稿增加救援/长尾，视为反例，不继续扩大强度扫描。新的后处理只保留为研究候选，未经配对验证不替换工程基线。可能超过20分钟或无法可靠排除的批量工作只交用户命令，不自动启动。
