## 事前研究边界

先复用已存draft与布局诊断bbox宽高/面积、去平移相对结构变化、线长与软违反。大位移不等于膨胀；非法draft的紧凑性不等于附近一定存在好合法解。不得以距离更近替代Q改善。

首轮使用同五个已暴露开发反例`[50,368,316,443,164]`。不按本轮结果扩大反例集，不扫描原E45强锚定的惩罚权重，不复活冲突后重置路线。先比较四个机制不同的假设：

1. **全局包络**：对子问题的bbox宽高超过原draft尺度施加可违反的全局代价，允许平移及内部重排；不固定每个块的坐标。
2. **相对结构**：在稀疏跨区域块对上保留原draft的中心相对向量，平移自由；不把“冲突深度”作为主要信任规则。
3. **全局目标尺度**：用公开draft的面积/线长提供质量尺度，修正局部perimeter/线长权重与最终选解之间的错位；与仅改变选解作消融。
4. **全局压缩精修**：合法后利用全局bbox目标或精确线长投影压缩，保留原合法incumbent，仅在公开目标改善且硬合法时接受；观察额外成本能否通过减少重复精修回收。

各假设固定一个初始实现，以机制反例淘汰无效路线；需要修改时记录原因和新版本，不按同五例做密集数值调参。所有搜索/回退/选择成本计入候选。在线仅公开输入与原draft，不使用参考位置、Q或其分母；标签仅离线诊断/评分。

## 阶段二登记（首轮100例之后，确认400例之前）

首轮100例：`native_area`加权Q1.019740→1.015643、均时+0.41%，但三例严重退化；`draft_scale`→1.016864、均时-1.67%，但两例严重退化。两者均不通过，不直接进入400例确认。原100例作为已暴露开发诊断保留，不重跑旧候选择优计时。

新增机制是**合法解上的可回滚全局刚性分量压缩**：实际相接的公开group分量一起移动，使用全局bbox与精确线网代价的分段线性位移最优点，原draft提供优先顺序及一个候选方向。每次接受都要求硬合法、面积不增、精确线长不增、离散软违反总数不增；保留原合法解。单例新增预算12毫秒，包含全部尝试，不允许以重复求解隐藏成本。

另保留一个明确标注自适应选择的规模分层候选：在原流程既有`n>=90`大规模预算档使用`native_area`，其余用原控制器。首轮严重退化均在小/中例，阈值复用原预算档，不按index设置例外；这一选择来自已暴露100例，因此不能再称100例独立验证。分别比较原规模分层、加公开早停、加全局压缩的五例机制对照。早停复用已有条件：合法、零软违反、bbox面积不超过公开总模块面积1.025倍且线长不超过原draft；并非读取真实Q后停止。

阶段二仍先五例，再冻结最多两个新组合做同100例开发筛查。最终只允许一个冻结组合进入剩余400例一次确认，确认结果不用于再选规则。

## 阶段三与计时耦合

阶段二100例中，大规模分支未启用的小例仍出现严重Q差异：两臂算法相同，但独立重复运行受墙钟预算影响、迭代数不同。旧结果不改写。新运行显式`--share-equivalent`：仅在数值配置严格相同的分支中共享一次求解输出与求解时间，另计各臂公开规模分派开销；修改算法的臂仍分别实测。原100例中的偶然小例收益/退化不归因于大规模策略，也不择优挑同一臂的时间。

在最终筛查/确认前补两种不同于绝对中心锚定的形状机制，代码固定后各用同五例：`shape_trust`使主形状迭代的宽高保持在原draft兼容尺寸的[0.75,4/3]，但所有位置自由；`shape_memory`只对宽高相对原兼容尺寸的变化添加0.02/n归一化二次项，不约束中心。救援仍使用原完整控制器，不把不合适的形状先验强加给救援。它们检验“形状漂移导致全局膨胀”，不是持续冲突触发重置。只用这两个初始配置，不扫描强度。

形状trust五例使443 Q1.764378→1.288967，耗时0.538→1.293秒，但118块例从Q1变成1.003070；软形状项没有实质改善，停止扩大。新增组合`shape_large_fast`在小/中规模使用该trust、大规模沿用`large_area_fast`，与纯`large_area_fast`一起在等价分支耦合口径下筛查100例。它们属于进一步自适应开发。另对原五例保存解试验已有认证推挤`push=True`，5例无接受移动，停止扩大该方向。
