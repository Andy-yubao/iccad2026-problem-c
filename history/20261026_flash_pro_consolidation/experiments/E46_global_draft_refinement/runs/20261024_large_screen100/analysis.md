# 规模分层100例：质量/速度信号与同配置计时混杂

300个输出全部硬合法。control/large_area/large_area_fast加权Q分别1.020579213/1.015644017/1.016109988，完整均时0.268271700/0.251838586/0.225987130秒；快速组合本轮约快15.8%，超额Q减少21.7%。

事前全指标判据仍未通过：large_area在247、large_area_fast在337有严重单例回归。两例模块数分别84、58，大规模改动均未启用，实际数值算法就是control。与此相对应，小例也出现明显偶然收益。原流程的墙钟预算/动态救援会放大机器状态、顺序及迭代数差异，不能把这些都当作条件分支的因果效果。

n>=90共31例，large_area为13胜14平4负，large_area_fast为13胜12平6负，最大退化均约0.01647，无本轮严重回归。该分层结果仍是开发诊断，不宣布达到1.01或升级。完整区间与逐例见[summary.json](summary.json)、[paired_cases.csv](paired_cases.csv)。

后续采用显式等价配置共享，消除未启用分支的第二次预算抽样；对实际不同配置仍独立计时。该比较口径改进单列，旧独立计时记录保持原样，不只替换不利案例。最终冻结组合须在统一口径下筛查，并对剩余400例确认；不会按确认结果再选规则。
