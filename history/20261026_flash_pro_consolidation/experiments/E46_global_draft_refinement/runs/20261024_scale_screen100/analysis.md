# 首轮100例：全局目标有效信号，严重单例回归阻止升级

三臂共300个输出全硬合法。加权Q：control 1.019739988、native_area 1.015643210、draft_scale 1.016864039；超额Q分别降低20.75%、14.57%。完整均时0.268225650、0.269316389、0.263740425秒，变化+0.41%、-1.67%。最差5%均值1.310799→1.275334/1.267593，最大Q1.466547→1.356206/1.344013。

但native_area有严重退化182/377/439，draft_scale有182/429。按事前规则两者都失败，不扩400确认。逐例见[paired_cases.csv](paired_cases.csv)，聚类区间与全部分项见[summary.json](summary.json)。native_area加权Q差分片95%区间[-0.009166,-0.000434]，draft_scale[-0.008018,0.001149]；只反映案例变异，不反映机器状态重复计时。

全局尺度修正改变了整条形状轨迹，并未保留未干预流程后来能找到的解，所以均值改善与单例回归可以同时发生。两候选平均面积相对draft反而从1.011312增至1.014114/1.015978；改善不是“平均更靠近原draft”，软违反总数从46降到36/39也有贡献。不能把全局目标校准的收益全部归于防膨胀。
