# E46结题：全局结构问题得到验证，当前候选未达到升级条件

2026-10-24。在用户授权的4小时上限内，完成全局几何审计、多机制五例对照、三轮自适应100例开发筛查及唯一冻结候选的400例确认。**没有得到质量、耗时、尾部共同满足要求的升级，E25保留。** 最好候选有小幅平均收益，证据不足且仍有严重单例退化；没有达到加权Q1.01或逐例2秒目标。

## 1. 对用户原意的重新验证

原draft是全局布局信息，应检查它能否抑制搜索过程的膨胀，而非仅在持续冲突后重启。已有103个不同开发布局的几何审计显示：相对draft面积中位数约0.992，但7例膨胀超过10%。这是少数显著失败，不能把所有位移都当作膨胀。

**443号例确实证明了这一问题。** 原控制器将宽度拉到draft约1.864倍、面积约1.736倍。只限制原draft兼容宽高范围、让位置自由，面积降到约1.033倍，Q从1.764378降到1.288967；完整时间0.538→1.293秒。离线原参考中心误差从原draft的0.480块尺度，经原控制器变成3.657，形状trust则为1.454。这支持“参考原始几何可以避免部分无效全局变形”的假设。

![443全局膨胀与形状信赖域](images/draft_shape_example_index443.png)

但这个初始固定形状范围只覆盖约63.9%模块的原参考宽高，不能把它当作普遍可靠的硬规则；原标签是否对MIB派生输入硬合法也未在此假定。形状trust组合扩大100例后有7例严重退化、算术Q和尾部恶化，因此按规则拒绝。单个布局的漂亮改善不能替代整体对照。

## 2. 最后保留的研究候选

`large_area_fast`在原有n>=90预算档中，使bbox代价从固定周长权重改为与原生公开输入目标一致的全局面积线性化，并复用公开早停：硬合法、零软违反、bbox面积≤1.025倍公开总模块面积，且精确线长不超过原draft。其他规模保留原steady。硬守卫、合法incumbent、原完整救援和数值认证均保留，没有外层2秒裁剪。

原draft在早停中提供全局线长参照。在线使用的面积/线长尺度、位置/形状先验或接受判据均不读取参考坐标、参考分母或真实Q。当前最好候选依靠全局目标和调度获得收益，不能声称已实现普遍的draft邻域最优搜索。

## 6. 本轮试过的机制及取舍

- 全局包络、平移不变的相对结构：五例未稳定改善典型膨胀，不扫强度、不扩面。
- 原生面积目标、draft全局尺度及仅改变选解的消融：改变子问题比仅改变选解有收益信号，但首轮100例均因严重回归未通过。
- 可回滚刚性分量压缩：五例只有很小收益，额外成本不划算，停止扩大。
- 认证推挤：原五例无接受移动，停止扩大。
- 原draft形状软记忆：收益很小，停止扩大；硬形状信赖域在443明显奏效，但100例整体退化，拒绝。
- 大例全局目标＋公开早停：100例点估计通过，冻结后400例确认未通过，不升级。

这些结果没有否定完整draft信息的价值；它们否定了本轮这些统一先验或目标替换足以稳定改善所有情形。后续研究需要能保留原轨迹质量的全局结构分支，并实际回收分支成本。此方向本轮未继续实现或调参。
