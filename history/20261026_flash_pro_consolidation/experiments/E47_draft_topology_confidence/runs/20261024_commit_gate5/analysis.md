# 第二接口：可撤销的接触承诺

六臂共30输出均硬合法。同完整draft和native预算。oracle_commit只提供接触置信度，方向仍取原draft；oracle_structured额外提供见证方向。原始输出和源码快照本地保存，summary.json和paired_cases.csv保存汇总和逐例差异。

164例有可复核的正面机制信号：control Q1.927279、完整3.125秒，oracle_commit Q1.206536、完整0.694秒，原draft相对位移指标0.822→0.174，软违反减少。oracle_structured Q1.356732，额外方向并非必要或更好。几何/打乱均未复制164收益。另一方面，443上control Q1.764378→oracle_commit1.749443，仍明显膨胀，不能认为接触结构足以恢复优质全局布局。

368轻度退化1.176090→1.182669；50和316保持。oracle_commit五例加权Q1.006579→1.002133受118块316的高权重影响，不能用这个值代表总体Q接近1.01。shuffle_commit在50、316严重退化，并在443经救援偶然达到1.288967，说明单例胜出也可能来自轨迹改变。

决定冻结接口进入固定100例，同时补齐shuffle_draft_commit和oracle_draft_priority，避免把额外方向与置信度混淆。未开始训练，五例不是泛化证据，单例2秒目标尚未普遍达到。
