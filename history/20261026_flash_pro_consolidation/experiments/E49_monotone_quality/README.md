## 初始机制

完整复制基线为受保护分支，不跨实验导入私有算法；新增搜索在基线周围优化。比较公开面积A、线长W和软违反数V。对候选c与基线b，令k=max(1,Ac/Ab,Wc/Wb)，若log(k)+2(Vc−Vb)/Nsoft≤0，则在官方α=0.5、β=2的任意正参考分母下Qc≤Qb：每项正部满足(k·r−1)+≤k(r−1)++(k−1)，两项质量权重和为1，故质量因子最多放大k。此保护不使用真实Q；真实Q只在父进程事后评价。

这个界保守，会挡住部分实际改善的面积/线长折中，因此先开发带公开面积/线长上界的精修、约束修复，保留不满足安全界的候选作诊断，不能事后用Q把它们混入部署结果。当前现场重算基线也可能因时间截断不同于历史记录，须分别检查“相对本次基线的机制保护”和“相对已存历史基线的逐例验收”，不能混淆。
