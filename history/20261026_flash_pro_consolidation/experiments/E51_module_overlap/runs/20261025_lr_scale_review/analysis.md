# 学习率数值与下降倍率审计

2026-10-25，用户澄清关注“初始学习率是否太小、每次下降倍率是否不够大”，不是patience。只读E39/E41/E42/E43完整曲线和E51运行中快照，证据见[evidence.json](evidence.json)。未调用模型、未读测试、未中断或更改当前训练。旧运行使用各自原代理，E51使用统一总Loss；下表只比较每轮运行内部，不跨运行比较绝对Loss。

现行档位：1e-3→2.5e-4→1e-4→5e-5，对应4倍、2.5倍、2倍下降。

|---|---:|---:|---:|
| E39 | 0.608686885 | 0.536449805 | 11.87% |
| E41 | 0.631705552 | 0.552504719 | 12.54% |
| E42 | 0.604967820 | 0.525967604 | 13.06% |
| E43 | 0.568051742 | 0.501104529 | 11.79% |
| E51 | 0.456558619 | 0.412631076 | 9.62% |

采用前档最佳值而非下降前反弹的最后值，避免夸大下降后的改善。全部五组在首降后首轮低于前档最佳；这些是沿同一实际轨迹的描述，不是初始学习率或下降倍率的随机对照，不能证明不同起点/提前下降会获得相同结果。

E51在1e-3阶段训练与开发监测一起反复回升，例如第20–23轮开发为0.456559/0.483450/0.466134/0.492701，训练为0.449299/0.473068/0.455357/0.478437。前期第1–6轮开发由1.060863降到0.588571，不像明显学不动；现有证据不足以支持把初始学习率升至3e-3或1e-2。更像后段高学习率下波动明显，但不能仅靠这些曲线将其确证为步长过大。

E42二降后首轮较前档最佳改善2.59%，三降改善1.19%；E43为3.28%/0.64%。后续下降仍有价值，初降收益通常更明显。当前E51快照最后完成的验证为第39轮，刚触发第二次下降，尚无其下一低档完整验证，不能评价该次下降收益。

此候选尚未训练对照，不能承诺更快或不损失质量。尤其1e-5低于既有最低档，价值未证实，只作为短收尾观察；若没有验证收益，不延长等待。加大倍率不减少每轮计算量，也不自动减少达到同等质量所需的轮数。
