## 问题与假设

E51相对E42没有明显改善用户重视的draft；已有同100例flash结果亦未改善。逐模块面积负担虽保护中小模块，但强参考锚定可能抵消几何约束，单纯增大重叠权重也可能导致空隙、改形或软约束退化。本轮检验固定Loss能否同时保留布局意图、减少冲突与后处理改动。

首轮`geometry`降低参考中心/形状/邻接位移的追随权重，提高重叠/接触/边界/MIB约束的重要程度，并加轻微紧凑约束。从头训练，不复用E42/E51参数。一个候选只在训练结束后对其唯一Loss-best做一次flash500；不按Q选择其他epoch。

其他候选是决策储备，尚未启动，不保证全部使用：

| 候选 | 要检验的原因与反例 |
|---|---|
| geometry | 更重视可修复几何；若散开或线路变差，说明减弱锚定并不足够 |
| tolerant | 中心/邻接位移允许模块边长10%的误差，形状允许log比例0.1的误差；固定容差可能减少与几何约束的冲突，也可能破坏意图 |
| clearance | 在tolerant上惩罚以双方较短边归一化的穿透深度；检验等重叠面积下修复难度的差别 |
| wire_guard | 在tolerant上惩罚相对参考的线长正向恶化；只作监督，不向模型输入参考 |
| anchor_ablation | geometry恢复原参考追随权重，核验收益是否来自减弱锚定 |
| count_ablation | tolerant去掉连续个数乘子，核验重复冲突计数是否反而妨碍训练 |

精确表达见[loss.py](loss.py)、[loss_config.py](loss_config.py)、[module_loss.py](module_loss.py)。逐模块重叠保留成对累加的重数，并非几何并集面积；连续个数因子在[1,2)内，不使用硬冲突个数。不同候选总Loss不能直接横比；比较共同分项、草稿、同面板flash和配对尾部。

## 冻结与运行口径

- 独立复制E52：矩形96×12、FFN dropout .05、1,471,539参数，模型/特征/批次语义及flash所有数值源哈希冻结，来源见[provenance.json](provenance.json)。不跨实验导入私有算法。
- v5 train16,000/dev2,000；固定train_monitor500/dev_monitor500；测试封存。FP32、确定性CUDA、batch32、AdamW decay .0003、clip1；学习率1e-3→2.5e-4→1e-4→5e-5，15轮后按原平台规则下降/早停。只改Loss项、权重或归一化，不改采样、优化器、模型、flash。
- 每轮从第一批起采用相同固定Loss；训练反传、训练/开发监测、完整开发2000一致。best/LR/早停均用固定dev500的该Loss均值，无渐入或后期降锚定。
- 沿用E52 GPU常驻输入、CUDA图、合并标量回传、周期保存。速度方法已写入[protocol](../../docs/protocol.md)。短基准2.55倍是单步结果，不冒充完整训练加速。
- 每轮训练最多2小时/200轮，并受全局截止限制；GPU阶段串行，flash2进程×2线程，绘图4进程×1线程。后台控制器记录命令、源码快照、恢复与STOP状态，训练槽位不会因重启重复计数。

## 命令、停止与恢复

本轮由助手根据用户明确授权启动，无需用户手动执行。复现首轮：

```powershell
& .\.conda\envs\iccad2026\python.exe -u -B -m experiments.E53_loss_geometry.study_runner --arm geometry --seed 0
```

控制器按顺序训练→完整开发原始诊断→一次flash500→100张三列草稿图，随后退出等待研究分析。输出`runs/20261026_geometry_seed0/`；控制日志在同名`_control/console.log`。定时唤醒后根据已保存证据决定下轮，不盲目排队。

创建`experiments/E53_loss_geometry/runs/STOP`安全停止整个实验；某轮的`STOP`仅停止该轮。明确恢复时先移除相应STOP，再运行同一命令；源码、数据、预算及设备身份必须一致。单轮已完成则不重训或重复评价。全局预算不会因恢复清零。
