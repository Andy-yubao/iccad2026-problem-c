## 假设、公式与反例

原始 overlap：每对可移动有效矩形的最小轴向穿透深度，除以平均 sqrt(公开面积)，平方、按 ordered pairs 求和，再除以有效块数；权重 .5，其余 E42 固定项不变。

候选 centerline_v1：中心差 d、半宽高和 e、r=||d||。非重叠为0；重叠且中心不重合时，沿当前中心连线继续相对移动至第一次脱离，距离 D=r*(min(e_x/|d_x|, e_y/|d_y|)-1)。轴分量为0时该轴不限制退出。中心距离小于1e-4倍局部面积长度时，明确退回原最小轴穿透，避免方向奇点；此小邻域切换不是光滑保证。其余归一化、平方及聚合与原式相同。正常分支使用实际自动微分，不暗用 detach 或自定义反向。

为避免胜出只是因为增加惩罚强度，正式训练前在同5个训练成员、冻结E42输出上一次性计算两个 overlap 对输出 state 的梯度范数。候选 overlap 乘固定 κ=原式梯度范数均值/候选梯度范数均值；记录成员、权重哈希、原始/缩放后分项与κ。此校准不读取开发结果，不训练、不扫描权重；κ随配置冻结后，训练、所有监测、选模及终末Loss完全一致。若分母为0或不有限，不能静默采用数值，先检查实现并记录处理。一个面板的梯度匹配不保证全过程同强度，结论仍仅代表该固定配置，不能声称排除了所有尺度效应。overlap.py 返回未乘κ的原始量，实际Loss入口负责固定缩放。

两个2×2矩形：差(1,1)时 D=sqrt(2)，差(0,1)时 D=1，符合用户强度排序；但这种排序与“任意向外移动都不增损失”全局不相容，因为从(0,1)到(1,1)本身就是向外移动。直接径向距离在某些非对角位置确实存在向外某一轴移动却增损失的局部反例。这是候选含义的局限，不隐瞒为梯度实现错误，也不以标量排序满足就宣布更优。

[overlap.py](overlap.py) 和 [check_overlap.py](check_overlap.py) 在正式训练前检查例子、有限位移、自动微分与有限差分、矩形交换/尺度、非重叠、包含、极端长宽比、近重合及有效掩码。方向反例单独记录，不偷偷修改测试预期；若实际梯度或数值实现不符合已登记定义，修复后才训练。若短 GPU 检查发现候选严重数值不稳，保留失败证据，先解决数值问题而非开始完整训练。

## 暂定选择规则（训练前固定）

先排除数值失稳、数据/实现检查失败或未完成共同面板评价者。共同主指标为原始草稿 overlap-area/total-public-area（均值、P95、最差5%均值），并同时报告相交对数、原最小轴穿透、径向距离、reference中心/形状、相对位置、boundary、MIB。对固定 dev2000 按相同成员配对；分模块数/约束分层。bootstrap 仅作开发集配对不确定性描述，单种子不代表训练随机性的置信度。

在无新用户评分时，centerline 只有在 overlap面积均值下降至少5%、其配对bootstrap 95%区间的上界低于0，且P95/最差5%不恶化超过2%，中心/形状/相对位置各不恶化超过2%、boundary/MIB各不恶化超过5%，flash500硬合法不少于对照且weighted Q不恶化超过1%时，才暂定胜出。分母接近0时报告绝对差并审查，不用百分比制造改善。否则沿用原始 Loss；证据冲突或近阈值标为不确定，不追加网格搜索。人工检查同批图集的3～5个典型/反例，AI观察不能冒充用户评价。允许用户后续用草稿判断推翻暂定选择。
