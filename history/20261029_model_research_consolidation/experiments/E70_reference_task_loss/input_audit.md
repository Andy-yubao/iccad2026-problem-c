# E70 v2：原始公开输入到实际网络输入的审计

2026-10-28。以datasets提供的solver_inputs、E70的features/batches/inference/model及冻结base_model的实际读入路径为准。张量出现在batch里不等于网络使用了它；下列结论区分二者。本版未正式训练。E68旧准备记录保存在其自身runs/preparation_v1/。E70仅额外在数据batch中保留原始b2b权重矩阵供Loss计算；inputs_only不把该额外矩阵送入模型，模型结构与E68 v2字节一致。

## 1. 原始公开接口

solver_inputs为(n, areas, b2b, p2b, pins, constraints, specs)。公开信息包含模块数、目标面积、模块间加权连边、端口到模块的加权连边、固定端口坐标、固定/预放置/MIB/分组/边界标志，以及依法可见的固定形状宽高或预放置XYWH。

自由模块的参考XYWH和参考评分是标签，不能进入网络。固定形状但非预放置模块也不能得到其参考XY。数据当前采用v5的MIB平均面积派生任务：组内可变块目标面积已按公开规则调整，固定/预放置规格优先；不是所有原始面积均逐字节照搬。

## 2. 实际初始节点特征：14维

| 通道 | 内容 | 表示 |
|---|---|---|
| 0 | 模块面积 | log(有效面积/平均有效面积) |
| 1–2 | 公开宽高 | 固定或预放置模块WH/尺度；其余为0 |
| 3–4 | 公开中心坐标 | 仅预放置中心/尺度；其余为0 |
| 5 | 固定形状标志 | 0/1 |
| 6 | 预放置标志 | 0/1 |
| 7–10 | 边界要求 | 左、右、上、下四个位；角点对应多个位 |
| 11 | 同MIB组其他模块数量 | 数量/N |
| 12 | 同分组其他模块数量 | 数量/N |
| 13 | 模块连线加权度 | log(1+该模块b2b权重总和) |

旧版14–16通道的端口总权重、平均x/y已从网络接口删除；Linear输入为14维，模型拒绝17维。为只读复用冻结cache，旧摘要仍可能存放在数据容器中，但训练和推理在网络边界均排除它们。

## 3. 节点特征之外，实际被网络使用的信息

| 信息 | 网络怎样使用 | 是否存在额外固定压缩 |
|---|---|---|
| b2b完整无向带权图 | 行归一化邻接矩阵用于消息和成对偏置；节点保留加权度 | 不是只有邻居均值。归一化邻接×加权度可恢复无向汇总权重，浮点误差除外 |
| MIB成员关系 | 完整同组关系矩阵及组规模，用于组消息和成对标志 | 组编号不作为数值嵌入；编号重命名不改变任务，非必要信息损失 |
| Grouping成员关系 | 完整同组关系矩阵及组规模，用于组消息和成对标志 | 同上；不是仅提供每组多少个模块 |
| p2b及端口位置 | 每个模块逐条读取所有正权连接的端口XY与权重 | 不做TopK；同端口重复边合并、零权边丢弃，对当前两端点线长等价 |
| 固定/预放置规格 | 输入特征、mask/known/specs参与状态替换和矩形解码 | 自由坐标始终不可见；硬公开规格没有遗漏 |
| 面积、有效节点 | 参与矩形解码、尺度与有效mask | N未额外作为全局标量送入；通过有效节点/张量及面积等间接体现 |
| 当前预测布局 | 每层的预测中心、宽高、间距、穿透、相对形状进入成对偏置；状态嵌入回流 | 这是模型自身预测，不是额外真实布局输入 |

坐标、WH与面积按sqrt(总有效面积)归一化；尺度用于还原输出，主干不单独读物理单位大小。对于当前主要相对质量目标，这是统一单位，不是只保留平均几何。

## 4. 本次发现并一起修正的实际缺口

旧版端口读入只让权重进入归一化注意力。如果同一模块的端口权重同时乘常数，归一化会抵消该尺度；旧总权重通道此前补足了它。直接删掉旧通道会制造新缺口。

v2让逐条log(1+weight)进入端口token，并使用门控加权求和；asinh仅用于稳定幅度，不是归一化平均。检查非零输出投影下，将同一模块所有端口权重乘2确实改变分支输出。没有再手工输入一个端口总权重或均值节点通道。

## 5. 尚存在的表示限制和有意未输入的信息

1. 所有端口token最终仍聚合到每层24维端口消息，再进入96维节点隐藏状态；模块消息也会池化。这是可学习压缩，不能声称完整原始信息在每一层无损保留。v2移除的是固定端口均值瓶颈，不是消除了神经网络的全部信息瓶颈。
2. 没有持久的独立端口隐藏token，只有当前层按模块查询的端口读入。端口之间、同一端口连接多个模块的关系通过共同坐标和模块交互间接表达；需要后续证据再决定是否显式建模。
3. 未与任何模块正权连接的端口没有进入分支。它们不影响当前p2b线长；若要把所有端口的外包络当作画布/全局上下文，这需要作为额外假设验证，不能当作已知固定外框。
4. b2b转为无向汇总矩阵。同一无向模块对的重复或反向边合并，和当前加权两端点线长等价。官方接口本就没有提供更丰富的多端超边net身份，不能把上游未给出的信息算作本模型遗漏。
5. MIB/Grouping用完整同组矩阵表达，没有持久组token。单成员组的数值ID不进入实际几何消息；在当前分组/MIB处罚下单成员组自身不构成违反。
6. 没有额外输入显式连通分量、到端口的图距离、位置可靠性、全局规模token。这些可以由公开图派生，当前模型主要自行学习；它们属于有待验证的表示增强，不等于原始连接数据缺失。
7. 自由块参考位置/长宽比、参考邻接接触、参考最优线长/面积分母不输入。它们用于监督或评价；不能补成网络输入来提高拟合。
8. 题目接口没有额外固定画布外框/自由块目标位置；边界要求是相对于输出自身包围盒。不能因为网络没有“参考外框”就说遗漏公开输入。

结论：原先确定的固定端口均值压缩和权重尺度抵消已一起处理；b2b、分组、MIB不是简单均值摘要。剩余最明确的架构限制是固定宽度消息聚合及缺少持久端口/组状态。它们可以纳入后续组合方案，但目前不据此断言增加token一定有效。
