# E70组合Loss设计：位置/形状参考监督＋公开任务优化

状态：已接入独立E70入口，按下列固定起始权重检查实现；尚未正式训练。原设计提案保存在runs/design_v1/。权重未做开发集搜索，不声称最优。提出时间2026-10-28；不修改当前运行中的E68。此文定义一个整体候选，明显进步后再做回溯消融。

## 1. 严格的数据依赖边界

唯一允许读取自由reference标签的项是L_pos与L_shape。其余项只读取预测布局以及公开面积、b2b、p2b、端口坐标、分组/MIB/边界、固定形状和预放置规格；即使完全不提供自由reference，这些项仍能独立计算。

删除旧relative_local：不再用reference几何确定近邻，也不再监督其精确相对位移。删除旧contact：不再要求复制reference的指定接触对象或方向。替换旧bbox：不再用reference bbox/面积/评分分母归一化。任务线长同样不使用reference最优线长。

公开固定WH与预放置XYWH虽然可能由数据容器的标签区提取，但属于合法公开规格，不算自由reference依赖；实现中仍必须经datasets的遮罩接口取得。

## 2. 统一符号与起始组合

预测矩形R_i=(x_i,y_i,w_i,h_i)，中心c_i，公开有效面积a_i：固定/预放置取公开WH乘积，其余取当前派生任务的目标面积。令A=sum(a_i)，S=sqrt(A)，s_i=sqrt(a_i)，t_i=max(s_i,0.5 median(s))，s_ij=(s_i+s_j)/2。所有分母只依赖公开输入；采用物理单位或先除S的归一化单位结果相同。

拟采用：

L = 0.25 L_pos + 0.25 L_shape + L_pen + L_area + 0.25 L_wire + 0.25 L_box + 0.50 L_group + 0.25 L_boundary + 0.10 L_mib + 0.10 L_domain。

每例先算上述总和，再对案例等权算术平均。没有按N、端口覆盖或难度再改案例权重。常数为新设计的起始提案，不是根据新Loss训练结果得到的最优权重；正式实施前需要相关短例的数值/梯度检查，修订必须发生在正式冻结之前并登记新版本，不能边训边改。

## 3. 仅有的两个参考项

### 3.1 位置：L_pos

自由中心参数u_i与reference中心c_i*做轴向SmoothL1(beta=0.1)，误差除t_i，然后对非预放置模块和两坐标求平均。保留解码前中心参数监督，以免非负截断导致位置纠正梯度消失；所有任务几何项则使用实际解码矩形。另报告解码后的实际中心误差，避免将参数误差混同于草稿误差。

t_i的公开尺度下限避免极小模块单独放大位置梯度。这是局部尺度正则，不是按端口少就忽略难例；没有reference对齐平移/旋转、自由模块身份匹配或精确近邻监督。

### 3.2 形状：L_shape

对可变形模块，预测log长宽比参数r_i与reference log(w_i*/h_i*)做均方差。固定/预放置模块不再接受可变形监督，其形状由公开规格直接保证。该项只约束参考形状，不把参考面积重新引入任务；实际面积由公开a_i构造。

## 4. 双重避碰：深度与真实交面积

对每个唯一模块对i<j计算，不按物理连线筛选。即使两模块完全没有连线，也必须避碰。

令半宽和H_x=(w_i+w_j)/2，H_y=(h_i+h_j)/2，中心差d=c_i-c_j。

p_ij = max(0, min(H_x-|d_x|, H_y-|d_y|))。

L_pen = (1/N) sum_{i<j} (p_ij/s_ij)^2。

p_ij是沿坐标轴将两矩形分开的最小平移深度。特别注意：在一块完全包含另一块时，不能直接拿真实交区的短边当分离深度，后者会失去正确的包含逃逸信号。

真实交面积为：

I_ij = max(0,min(x_i+w_i,x_j+w_j)-max(x_i,x_j)) × max(0,min(y_i+h_i,y_j+h_j)-max(y_i,y_j))。

L_area = 0.5 sum(I_ij)/A + 0.5 (1/N) sum(I_ij/min(a_i,a_j))。

第一部分对应全局交面积负担；第二部分防止小模块被大模块覆盖后因面积小而被忽略。唯一i<j避免双计，除N而非所有N²对数，避免大任务把少量冲突稀释。不是对重叠面积求union；同一重叠区域涉及多对时可重复计负担，主评价仍单独报告原口径指标。

两项互补：面积项接近实际覆盖量，但小块在大块内部移动时面积可能保持常数；深度项提供脱离包含的方向。完全同心处仍存在非光滑对称性，任何简单成对势都可能出现零子梯度，不能承诺Loss单独消除所有碰撞；短查必须覆盖这一情形，必要的布局对称性打破应由公开定义的模型/构造处理。

## 5. 实际线长：L_wire

严格采用当前官方的中心点加权Manhattan定义：

W = sum_{b2b边(i,j)} w_ij ||c_i-c_j||_1 + sum_{p2b边(t,i)} v_ti ||p_t-c_i||_1。

令W_tot=sum(b2b权重)+sum(p2b权重)，L_wire=W/(S W_tot)。无正权边时该项定义为0，不用极小分母人为放大。b2b和p2b共用分母，保留两种连接的相对重要性；不分别拉到相同均值，不把稀疏弱边伪造为强连接。

这仍是按例归一化：同一案例所有连线权重一同缩放不会改变L_wire，符合相对线长目标的尺度消除；某一模块或某一类边相对其他边的强弱保留。不能把它说成跨案例绝对线长和跨案例总权重也被保留。

线长含吸引作用，可能促使模块挤在一起，因此与两种避碰和紧凑项联合；单独加线长不保证草稿改善。来源定义见third_party/FloorSet/iccad2026contest/iccad2026_evaluate.py的calculate_hpwl_b2b/p2b，不调用其.item()评分函数作为可微Loss。

## 6. 无参考紧凑度：L_box

B为预测全部矩形的实际bbox面积，L_box=max(0,B/A-1)。A是公开有效面积总和，是不重叠布局的面积下界，不是已知可达最优值。

只处罚多余空间；当重叠使B小于A时，不给负Loss奖励。该hinge自身也不会继续鼓励B<A，但线长仍可能拉近模块，所以必须依赖避碰部分。预放置/分组等可能使B=A不可达，此时正残差并不等于训练故障。

## 7. 可自主选择接触拓扑的分组：L_group

这里只用公开Grouping成员，不要求组员之间存在物理b2b连接，也不对所有组员两两强行拉近。

对组内每对模块构造可共享非零边段的接触代价。令o_x、o_y为x/y投影的带符号交叠长度，例如o_y=min(y_i+h_i,y_j+h_j)-max(y_i,y_j)。rho=0.01。

C_x(i,j) = min((x_i+w_i-x_j)^2,(x_j+w_j-x_i)^2)/s_ij^2 + [max(0,rho min(h_i,h_j)-o_y)/s_ij]^2。

C_y(i,j)对调x/y及w/h，C_ij=min(C_x,C_y)。第一项选择任一左右/上下相邻方向，第二项要求横向投影有正长度重叠。仅角点接触的o_x=o_y=0，代价为正；不会被当作共享边满足。1%短边接触余量是数值代理，比官方“任意正边段”略严格，需明确保留这一差异。

对每个公开组g，在其全部成员间以C为边代价求最小生成树T_g：

L_group = sum_g sum_{(i,j) in T_g} C_ij / max(1,sum_g(|g|-1))。

只需要连成一个组，不固定成链、星形或reference的接触图；不同于reference的合法组内接触方式可以同样取得零分组Loss。不同物理连线不因此被修改。

树和方向按当前预测几何重新选择，反向只通过所选代价传播，不对离散选择本身求导。这是同一个“min over trees”固定分段可微函数，不是改变权重或阶段目标。并列时固定规则；评估和训练用同一定义。GPU实现必须避免每batch回CPU选树导致捕获失败/隐性同步；若引擎不能支持，需要在正式启动前显式解决并登记，不能静默改执行路径。MST代理不等于官方连通分量计数，最终仍需实际严格几何检查。

## 8. 公开边界与MIB

### L_boundary

用预测自身bbox确定左/右/上/下边。对每个有要求的模块，计算要求边到对应bbox边的非负距离，除t_i，做SmoothL1(beta=0.1)；先平均该模块所有要求边，再对受约束模块等权平均。角点的两条要求都必须满足。没有reference bbox，也不把固定端口包围盒当作已知外框。

### L_mib

z_i=(log w_i,log h_i)，公开同MIB组内求z均值，V_g为各成员/两轴的均方离差；L_mib=sum_g (|g|-1)V_g / max(1,sum_g(|g|-1))。单成员组不产生项。

只要求当前预测组内同形，不指定必须等于某个reference形状；reference形状偏好仅通过L_shape。若公开面积/固定规格本身与同形不兼容，应报告冲突并保持硬规格优先，不静默掩码掉MIB，也不能牺牲硬面积去凑软MIB。

## 9. 硬规格及无参考参数域保护：L_domain

公开面积、固定WH、预放置XYWH继续由解码构造保证，不用有限软Loss去替代。非负输出保留。

当前解码在未截断左下角xy=u-wh/2上使用clamp_min(0)。为使去掉reference后任务优化仍能从截断区获得纠正信号，L_domain包含非预放置模块的mean(ReLU(-(u-wh/2))/t_i)^2（两轴平均）。另对可变形模块加入mean(ReLU(|r|-5)^2)，把自由形状参数拉回现有解码的有效log长宽比范围。两者求和后乘总式的0.10，均不使用reference。

这项不处罚合法输出、也不改变原有形状范围；它补足参数域的梯度，而不是新的官方几何约束。若以后改为处处可导的合法参数化，应另登记新版本，不能与本版混报。

有限权重的穿透/面积代理仍不保证严格零重叠，不复制Q的“不可行直接10分”跳变，以免丢失优化方向。训练期间同时报告硬合法率和实际重叠，不把总Loss降低当作可行性证明。

## 10. 冻结前检查与评价

最多五例相关短查覆盖：包含重叠；仅角接触；两种不同于reference的合法组拓扑；移除/打乱reference只改变L_pos/L_shape；无边/单成员组及非有限/梯度边界。参考独立性检查必须覆盖全部非参考项及其归一化分母，不仅删除顶层reference参数名。

在训练成员上核对分项和梯度量级，避免仅凭标量占比猜测主导项；不按开发Q搜索系数。没有新目标量级检查前，0.25等只能称起始设计，不能称已校准权重。

正式训练后，反传、固定train/dev500监测、best、LR与早停统一使用此新总Loss，固定全程不渐入、不按难例改权。原G、实际线长、交面积、穿透、连通/边界/MIB违反和硬合法率作为解释指标，不能成为暗中的第二选择器。旧G与新总Loss数值不直接比较。唯一best终末flash500与同100图，低端口/稀疏子群单独报告；seed0，无多种子，测试封存。

成功应表现为同例草稿与弱覆盖几何的实质进步，同时保留可接受的位置/形状参考误差；不以任一标量或后处理Q单独宣布成功。
