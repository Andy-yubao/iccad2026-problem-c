# 工作约定

- 先读 README.md、docs/protocol.md 和 docs/workspace_structure.md；本文件只放核心边界。
- 实验代码、设计、专用入口和运行证据放在 experiments/<实验名>/，输出归其 runs/；docs/ 只留可复用核心文档。
- 当前及后续实验目录必须采用 `En_xxx` 命名，例如 `E8_fast_robust_postprocess`；历史实验不因新增命名要求自动搬迁。
- 复用 datasets/ 的数据处理、scoring/ 的官方输出评分及 visualization/ 的纯展示绘图；模型 Loss、构造、搜索、合法化等在各实验独立维护，允许复制，不跨实验导入私有算法。布局图统一调用 visualization/。
- 使用独立 conda 环境；保留官方原件，实际数据位置由 protocol/paths.json 解析。
- 固定使用 protocol/split_v1.json 的 80/10/10 划分，保持冻结文件原件；本地测试封存，公开验证只作兼容与公开对照。
- 原始 protocol/split_v1.json 与历史 workset_v2.json 保持冻结；新 MIB 派生任务及后续新训练采用 protocol/derived_workset_v3.json 的 16,000/2,000/2,000 规范，测试默认封存。固定 500 例验证监测，使用学习率下降、早停及 best/latest 保存。dev5 仅作代码排错，具体参数和评估边界见 docs/protocol.md。
- 实现训练代码前请阅读 docs/protocol.md
- 2026-10-31起，新布局训练采用前训练／后训练：沿用当前三组简化Loss表达式，仅在登记的阶段边界切换固定相对权重；阶段内训练反传、train/dev监测、best、LR及早停使用同一Loss，最终评价用后训练Loss，不另设选模代理或渐入权重。不同阶段总Loss不直接比较；测试封存、历史记录不改写。具体规范见docs/protocol.md 1.2与E92。
- 前训练保留从头训练保护期，允许学习率下降一次；第二次触发降档时不再下降，改为切换后训练Loss。后训练第0轮开发监测作新基准，第1轮起累计停滞，无保护期。阶段交接与阶段内续训分开登记，阶段内恢复保留优化器、RNG、游标、调度计数与累计预算，切阶段不清零费用。
- 默认最多 5 例轻量验证，只检查改动相关行为，不堆测试框架或重复全量检查。
- 预计可能超过 20 分钟的训练/推理，只交付命令让用户执行；不代为前台、后台启动或续跑，不拆任务规避。
- 早期发散机制与架构，允许推倒重来；后期再调参。改善必须用消融、反例或对照说明原因。
- 固定比较口径，记录命令、版本、种子与预算；区分可行性、质量、耗时和正式比赛分数。
- 每个策略阶段结束整理文件；旧的必要证据归档到 history/，重复与缓存清除，保护活跃任务、数据、环境和唯一 checkpoint。历史运行记录不因搬迁而改写。

- 日常实验区只保留 E42 共用 draft＋flash 与 E50 pro；experiments/baseline 已归档作历史参照；新实验按用户批准的计划开展，不恢复已明确删除方向的架构、权重或实验计划。
- 使用本地 Git main 与 GitHub origin 管理源码，数据、环境、缓存、checkpoint 和凭据不入库。
