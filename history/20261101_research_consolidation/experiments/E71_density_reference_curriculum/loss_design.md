# E71组合目标与研究判断

2026-10-28。一个seed0组合候选，承接E70避碰收益，针对外框外扩、内部缺少填空梯度和位置锚定减弱三项问题。常数为事前起始设计，不是开发集搜索结果，不声称最优。

## 1. 目标与日程

L(e)=λpos(e)Lpos+0.25Lshape+Lpen+Lintersection+0.25Lwire+0.5Lcompact+0.5Ldensity+0.5Lgroup+0.25Lboundary+0.1Lmib+0.1Ldomain。

除新增density、compact系数从0.25改0.5及位置日程外，公式保持E70原定义；本实验独立持有实现。位置λ第1～5轮为0.375，第6～15轮为0.25+0.0625[1+cos(π(e−5)/10)]，第15轮达到0.25，之后不变。每轮内恒定，monitor使用刚完成轮次的同一权重。旧中心系数1.0与当前位置项归一化不同；0.375只是系数更温和，实际影响还须分项梯度核对。形状仍0.25，未恢复reference近邻/接触监督。

全部任务项只使用公开信息和预测；网络输入不变。训练每例先合成总Loss，再等权案例平均；train/dev监测均eval/no_grad，使用相同当期公式。第16轮起才启用正式best、LR下降和早停。LR四档1e-3/2.5e-4/1e-4/5e-5，三轮停滞下降，三次下降且最低档完成两轮才允许早停。早期最终权重总Loss是诊断，不反向、不选早期checkpoint；旧G/Q也不选模。该局部例外来自用户本轮新要求，不追溯改写E70或通用固定Loss规则。

## 2. 内部密度：解析余弦矩与多尺度空间势

令实际预测包围盒为Ω=[x0,x0+W]×[y0,y0+H]，公开面积总和A，矩形中心在Ω内的相对坐标为u_i,v_i。对k,l∈0…K且不同时为0，定义

c_kl=Σ_i(a_i/A) cos(πku_i)sinc(k w_i/(2W)) cos(πlv_i)sinc(l h_i/(2H))，其中sinc(t)=sin(πt)/(πt)。

这是矩形内余弦函数的解析积分，再以公开面积质量归一化。均匀占据的非DC系数为零；矩形面积、mask、中心/WH均保持可微。每个尺度K=4、8分别计算Σ q_kl c_kl² / Σ q_kl，两尺度等权平均。q_kl=[(1+1{k>0})(1+1{l>0})]/(k²+l²)，使用归一化坐标下的逆谱权重，强调大尺度拥挤及空缺。它是空间势代理，不冒充物理单位下的完整泊松求解器。

全部内部模块均有参与机会，不按连线或公开分组筛选；对真实解码矩形计算，预放置与固定规格仍由原解码保证。实际bbox的min/max也反向传播，未detach外框或使用非目标函数的手工梯度。没有引入额外预测外框头、固定画布、reference bbox或参考评分分母。此实现用解析谱代替栅格采样，避免小矩形被粗网格遗漏并降低开销。

密度幅度按a_i/A而非I/B或裸平均占据归一化，因此没有简单1/B分母膨胀稀释；但改变外框仍会改变相对几何和密度，可能带来真实能量下降，不能宣称已排除所有外扩路线。固定0.5的紧凑压力共同抑制此取舍，必须实际报告B/A和同例B比，不能用密度Loss改善替代几何验收。有限频率可能看漏细孔，均匀密度也不保证合法；双避碰、公开组/MIB/边界项继续承担原职责。

## 3. 三项问题的对应与反例

- 目标偏向外扩：紧凑系数提高至0.5，保留避碰；不是整体缩放输出，不把A或带重叠的E42外框硬当作可行容量。
- 内部无方向：density对所有矩形的空间分布提供非局部信号；短查须出现内部模块非零位置梯度，并验证一步内部移动可减少能量。
- 锚定削弱：仅早期位置监督提高50%，后期回到E70水平；弱连接无分组模块也接受density信号。不能保证保留所有模块身份和reference近邻，合法的不同拓扑不自动判错。

解析短查包括无缝平铺零能量、内块错位出现信号、内部移动方向、拉开中心与外框留白反例、物理尺度一致性，以及独立数值积分核对值/梯度。五例真实训练成员短查只作实现与量级检查，不用于证明新系数或泛化最优。

## 4. 容量和数据判断

现有模型是96×12全端口结构、约153万参数，16k训练。当前缺少受控空间里的内部协调信号；同架构在不同Loss下外框与避碰取舍明显不同。因此本轮优先修复目标，保持容量和数据。训练/开发接近既可能来自规律迁移，也可能来自共同拟合限制，不能由此断言容量足够或数据无用。

凭研究判断：模型扩容的优先级略高于立即扩到64k，但两者都低于此次目标修正。若后续需要试容量，先96→128宽、深度仍12，以增加每个模块的几何消息容量；不优先加深，避免更长的聚合链。若需要试数据，先16k→32k训练成员，保持原开发与测试不变；更丰富弱端口/稀疏组合可能有益，但不改分布或按开发成绩挑训练例。旧160宽/64k经历不能当作当前新Loss的严格扩容结论，也不自动恢复其架构/权重/运行。

后续判断应看分项和同例草稿：若任务Loss及几何在训练/开发两边都停在较差水平、局部输出优化仍明显可改，容量或求解映射才更值得试；若训练显著好于开发，扩大数据更值得试。两者都只是触发下一轮的线索，不是自动因果诊断。即使差距小，扩数据仍可能改善覆盖；即使差距大，换数据也不是唯一解。本轮没有承诺或排队其他训练。
