# E80：冻结修正模型，替换布局模型

用户提出布局模型与修正模型分工的研究问题。本组只做一次事先固定的模块替换，不训练、不选择新的checkpoint：取E79best26中的完整三个修正器，保持全部65,483个参数及顺序、MIB协调和投影公式不变，将E74的192×12布局网络替换为E42best51的96×12布局网络。外框由新的E42公开预测生成，不能继续暗用E74。

已有三项比较只读复用：E74单独、E74加该修正包（E79）、E42单独。唯一新评价为E42加同一修正包，总参数1,537,022。先五例核对原E79重建、映射、冻结、公开输入/面积/规格/外框与CPU/GPU，再完整dev2000、一次flash500及固定100图。所有原终末评价不重复；测试封存。Q是后处理后的辅助指标，原始交面积、空白、外框与尾部一并报告。

本组不是正式训练候选，不生成虚构训练曲线或best轮次。二期账本记为用户新问题引导的推理诊断，旧训练费用与上限保留。评价墙钟最多1小时，STOP保留已完成记录，可按同一身份恢复。

入口：独立环境运行 `python -u -B -m experiments.E80_modular_transfer.pipeline`。输出：[runs/20261029_e42_frozen_e79_transfer](runs/20261029_e42_frozen_e79_transfer)，[预检](runs/preflight.json)，[方案](plan.json)，[来源](provenance.json)。源码首次评价前冻结，诊断放runs。

这个对照只能检验同一家族E42→E74之间的迁移。成功后才有依据讨论缩小布局网络、扩大修正网络；仍需检查质量、推理时间和不同布局来源，不能由参数更少直接断言路线更优。

已完成并复核：[结果](runs/inspection.md)。E42＋冻结F加权Q1.017329、dev交面积2.785%，500例框内；总参数153.7万。均值改善但最差Q2.200946退化，保留模块化研究方向，不升级基线；本组没有训练。
