## 网络与边界

独立修正器为192宽、12层、4头全局Transformer，参数5,831,723；加冻结E74布局器后共11,661,662参数。每层全体有效模块和完整端口token交互，完整b2b/p2b权重进入神经注意力；源草稿的矩形关系只编码一次。12层只更新隐藏特征，最后一个输出头仅调用一次，并行输出所有模块的中心/对数长宽比修正。

输出采用`draft + neural_delta`参数化，delta不设原0.15 sqrt(A)局部上限。只保留面积保持、固定形状/预放置覆盖、非负坐标和宽长比数值范围等单模块解码要求；没有继承框投影、同形组平均、梯度下降、线搜索、求解器或逐模块自回归输出。

`GlobalCorrector(public_problem, draft_state)`可独立保存和调用；E74仅是本轮冻结草稿来源，不属于修正网络内部。兼容E74注意力/FFN张量复制到独立可训练参数，不共享可变权重，零初始化最终头使初始解码结果精确等于输入草稿。这不证明模型已经学会修正。

## Loss设计正在修订

我最初把旧`G+4I+5E+.25A`作为结构研究的固定对照，但它不能未经审查直接成为新网络的主目标。当前[loss.py](loss.py)只用于历史诊断和网络接口短检，训练入口明确拒绝未登记的正式目标。下一步设计见[目标函数讨论](objective_review.md)。

新重点是每模块超过自身面积5%的严重重叠尾部及高质量draft；Q仍按固定dev500加权<1.01为后续目标。reference自由中心、形状、参考近邻/接触不默认进入主目标；公开硬规格必须保持，reference全局面积尺度只作待消融的辅助方案。
