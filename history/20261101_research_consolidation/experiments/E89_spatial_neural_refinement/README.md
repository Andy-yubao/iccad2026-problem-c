- 完整继承E90固定三类Loss：位置＋0.25×形状监督，重叠系数0.08975162861857286，公开题目项系数0.3336832108335229。无新辅助项、无重新定标、无渐入；训练反传、监测、best、LR、早停和完整开发评价使用同一函数。

- 每次前向只用公开问题在线生成冻结E90草稿，不用reference初始化，不挑优质训练draft，也不为这次训练复制整套草稿。新模块在16×16网格按矩形真实覆盖写入模块特征、动态占用、预放置障碍和过载，保留坐标、物理框尺寸及面积比。
- 三层64通道卷积（dilation1/2/4）处理空间状态；每个模块用其位置/尺寸/公开特征及公开adjacency/group/MIB消息读取。自身占用单独识别，通过减去自身贡献构造其他模块占用。
- 计算一次联合面积需求/可用容量的神经竞争信号并读回，同时输出全部模块的中心/形状残差。每坐标最大位移为一个自身面积平方根，log-aspect残差上限0.5；这不是布局合法性保证，也不硬裁在来源bbox内。
- pooled对照先将写入的空间人口/特征汇总再广播，保留坐标、模块原几何与相同参数、主要张量形状。两分支同seed/初始化/数据顺序/目标；计算量仍须记录，不能称逐指令完全相同。

这是一次并行的神经修正，没有解析消碰、梯度下降内循环、线搜索、逐模块放置或自回归。不声称已完成共享F的无监督训练或重复复用。区域软需求不等于实际矩形分配，有限网格可能漏掉细通道，仍须用开发证据检验。

新模块采用标准AdamW＋全局梯度裁剪1及有限值检查，不沿用为旧布局器设的相对参数步长投影：零初始化输出头的范数为零，直接套用旧投影会把其初始更新压到极小。两对照使用同一规则，布局器物理冻结不受影响。
