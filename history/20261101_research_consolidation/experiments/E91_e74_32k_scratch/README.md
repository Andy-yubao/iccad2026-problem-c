## 为什么此前日志只有16k

E74的实际数据和训练记录均为32,000个成员、每轮1,000个batch32更新。E87的新Loss后训练改用了原v5的16k前缀，E90为与E87作辅助权重对照也只使用16k；二者不是日志显示问题。继承的E74权重见过32k，不等于本阶段仍在训练32k。

E88/E89则有18,268个不同成员，但每轮固定抽样16,000次：12,800次来自原16k池、3,200次来自新增2,268个稀疏池，两个池各自轮转。日志的16k是本轮抽样次数；已见成员数均达到18,268。它们也不是E74原32k池加稀疏数据。数据变化虽然登记在原实验方案，但使这些结果不能视作“保持E74的32k、仅换Loss”的对照。

[数据沿革核查](runs/data_lineage_audit.json)记录实际池大小、每轮抽样数、更新数及来源。历史配置、成员和结果均保留原件。

## 本轮固定设计

- 数据：冻结`reference_workset_v6.json`前32,000成员，与E74逐项一致；每轮对全部32k无放回遍历，batch32、1,000更新。独立打乱仅改变次序，不做稀疏过采样，不加入E88侧池。原train/dev_monitor500、dev2000和封存测试不变；固定train500全部来自原16k，并非新增半数的独立监测。
- 模型：原样复制E74的192宽、12层矩形几何网络，5,829,939参数。自由reference只用于监督，完整端口只用于既定Loss的实际线长；网络仍只收公开问题信息。
- 从头训练：全部参数随机初始化，seed0；不加载E42/E74/E90权重、Net2Wider映射、Adam矩或旧随机状态。包括12层图聚合在内的全部参数可训练，不把随机图层冻结。没有E78的两个修正器、MIB形状投影或外框投影。
- 目标：完整沿用已采纳的E90固定Loss，`L = Lref + 0.08975162861857286 Loverlap + 0.3336832108335229 Ltask`。`Lref=position+0.25shape`；其余子项、归一化及聚合保持不变，不重新定标、不渐入。训练、所有监测、best、降LR、早停和后续评价共用同一函数。
- 优化：新AdamW，LR从1e-3开始、decay0.0003、全局梯度裁剪1、FP32和Dropout0.05。保留E74每模块weight/bias联合更新位移≤更新前联合范数0.5%的保护，作用于本轮全部可训练模块；随机初始化不继承旧图层冻结。普通AdamW的短检查虽通过恢复和捕获功能检查，第一步同面板Loss却从15.582升至91.799，因此没有将它作为正式入口；原证据保存在[runs/preflight_plain_adam/](runs/preflight_plain_adam/)。有限值检查、Loss<1000及裁剪前梯度范数<10000在Adam之前执行；旧后训练Loss<10阈值不适合从头训练起点。这些保护不改变Loss或选模，五例检查也不能证明完整训练稳定。
- 调度：本轮是从头训练，按项目协议保留第1～14轮保护，第15轮建立调度基准并开始观察；连续3轮无明显改善切换至下一档，四档为1e-3→2.5e-4→1e-4→5e-5。明显改善阈值为`max(1e-5, abs(best)*0.001)`；最低档至少完成两轮训练和监测后才可早停。E89的取消保护例外不自动扩展到本轮。

这是用户指定的数据/结构重训，历史E74是从E42暖启、冻结图聚合的后训练，因此与它比较同时改变了Loss、初始化和可训练域，不能宣称纯Loss因果消融。2小时资源上限也不保证从头训练充分收敛；需要结合固定train/dev曲线判断，不能直接把未学足解释成容量或新Loss失败。
