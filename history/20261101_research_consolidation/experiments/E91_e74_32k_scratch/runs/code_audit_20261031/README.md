## 1. 与新Loss后训练一致的部分

以下文件与E90逐字一致：`model.py`、`features.py`、`batches.py`、`simple_loss.py`、`group_tree.py`、`loss.py`、`ops.py`。`model.py`也与原E74逐字一致。端口提取代码仅换行格式不同，AST一致。

当前checkpoint、源码清单、固定Loss注册文件及其E90来源哈希一致。全部已完成历史train/dev500总Loss均能由保存的分项和固定系数重构，误差小于1e-6；best按同一dev总Loss选取，没有Q选模。

另已直接核对E74与E91的冻结v6清单SHA和32k数据视图：清单相同，视图代码解码文本及AST相同，仅文件换行字节不同，不存在成员版本变化。[数据与模型沿革证据](data_model_lineage_checks.json)。
