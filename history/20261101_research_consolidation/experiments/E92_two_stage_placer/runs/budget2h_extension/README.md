# 完整2h预算与条件研究授权迁移

用户明确要求“总预算至少2h”“每隔1h唤醒一次”，并要求布局达到E90后才研究复用修正网络，最终Q<1.01；未达到布局目标就终止。完整目标与资源边界在上级实验study.json，E90容差及来源哈希已在资格评价前冻结于qualification_registration.json。

初始启动受旧18h剩余预算约53分钟限制。为落实最新授权，安全暂停于P阶段711步、cursor22752、LR1e-3，累计预算355.6494秒；将本轮布局运行设为完整累计7200秒，不重置已用时间。保留全部旧研究成本；新任务布局2h、条件修正训练2h（最多两候选各1h）、准备与评价合计2h，总上限6h，限定本任务，不允许恢复旧实验。

本目录保存迁移前checkpoint、配置、源码快照及变更前文件；migrate.py逐项核对旧快照、允许的预算与记录变更，并将新身份绑定到相同训练状态。模型、Adam、RNG、样本排列／游标、调度器、历史／seen与步长保护状态的语义哈希前后严格一致；唯一时间变动是采用已有budget.json中更保守的累计值。详见[migration.json](migration.json)。当前源码五例检查重新通过，[preflight.log](preflight.log)保留；未变Loss、数据、初始化来源、batch、精度、LR或阶段日程。

后台续训准确PID及命令见上级runs/launch.json，日志为training.budget2h.stdout.log与stderr.log。训练自身只训练，每1h自动跟进负责后续冻结、同例资格评价及条件研究；测试始终封存。未来资格评价代码在qualification/单独冻结，训练不会导入它，其加入不影响训练源码身份。
