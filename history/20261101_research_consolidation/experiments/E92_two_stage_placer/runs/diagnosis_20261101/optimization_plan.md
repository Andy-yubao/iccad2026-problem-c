# E92原因排查与下一轮优化方案

2026-11-01，按用户新请求进行只读诊断与方案设计。**本次没有启动训练、恢复E92、重跑终末Q或重新开启自动唤醒。** 以下区分已证实的现象、有限反例与待验证机制，不追溯修改已冻结的Loss、门槛或结果。

## 1. 判断

目前未发现足以解释退化的训练／评估实现错误。更明确的问题是：**现有Loss的改善没有可靠转化为几何质量改善；reference监督在派生面积下并不对应无重叠布局；后训练的交接与时间分配还有优化空间，弱端口稀疏样本仍是困难子群。** 这些观察不能证明两阶段训练方向错误，也不能证明只需提高一个系数就能解决。

### 1.1 已核查的实现与比较边界

- 实际训练为完整32k，seen_count=32000，每轮1000个batch32更新，没有再次缩回16k。P/F权重实际切换；F epoch0建立基准，第3／11轮实际降档，无学习率保护。结束原因为2h资源上限，不是早停。
- E90与E92的Loss分项实现、输入特征、架构和flash算法口径已核对；同500成员、4进程×2线程，E90旧结果只读复用。冻结E90证据与E92 F best哈希相符，报告阶段未改变权重。
- 利用已保存的500例GPU批量草稿与CPU实际推理草稿比较，中心误差／模块尺度的全例均值约2.27e-6、例均值P95约3.35e-6、单模块最大约7.04e-5。没有观察到大幅尺度或推理路径错配；这不是对所有微小数值扰动下的后处理分支稳定性的证明。
- 当前adjacency、MIB、group矩阵已经行归一化，不能将本轮失败直接解释成“节点越多，未归一化消息求和越大”。五例冻结模型检查中，E92末层隐藏RMS约3.5～4.3，E90约7.8～9.0；未支持“E92激活幅度更大导致本次失败”的猜测。
- E90是既有预训练权重续训，图局部分支冻结；E92是全参数从头训练。两者还有历史训练量差别，不是仅Loss日程变化的严格消融。

### 1.2 主要证据：总Loss掩盖重叠退化

同dev500，数值都按原F表达式计算：

| 分项 | E90 | E92 | 对总Loss变化的贡献 |
|---|---:|---:|---:|
| reference | 0.228615 | 0.225156 | -0.003459 |
| overlap，系数0.0897516 | 0.447230 | 0.482949 | +0.003206 |
| task，系数0.3336832 | 0.180849 | 0.179285 | -0.000522 |
| 总Loss | 0.329100 | 0.328326 | -0.000775 |

重叠组合Loss退化约8%，被reference与task的改善抵消。最终加权Q却从1.022348退化为1.031269，最差Q从1.84197变为2.15497。这说明在当前候选之间，较低总Loss不能保证较好的草稿或最终Q。

不能把“reference标量占总Loss约68.6%”直接等同于“reference梯度始终压倒其他项”。五例共享末层读出梯度中，加权重叠／reference范数比在0.53～7.29之间；reference与overlap方向既有一致也有冲突。该诊断只覆盖选定反例的读出参数，不代表全网络Adam实际步长或全体数据统计。

进一步只用保存值，将overlap系数乘1.5／2／3后，E90/E92逐例Loss变化方向与Q变化方向的一致率约58.1%／57.8%／58.8%，原来约57.6%（排除66个Q相同例）。增权能改变两模型的汇总排序，但对案例15仍不能修正排序。因此**增权是低成本可检验候选，不是已证实的修复**；不能从这两个已知模型反推“最优”权重。

### 1.3 规模问题是放大器，但不只是平均口径问题

100～120模块样本105/500，只占21%监测例数，却占最终Q权重约82.8%；该组加权Q退化约0.01050。20～59模块组的改善几乎无法抵消它。

但有一个必须保留的反证：用相同的`exp(N/12)`权重重算原F Loss，E90为0.310551，E92仍更好，为0.306288，而Q仍更差。**所以不能把“给大N Loss加权”当作首要解决方案。** 先修复／验证几何目标的有效性，再考虑固定规模权重；目前先将N分层监测加完整，不新增选模代理。

### 1.4 稀疏问题没有解决，且不完全由N解释

保留E69原定义：端口覆盖≤30%，连接密度≤同精确N的固定开发中位数，仍为157例。

| 完整dev2000草稿 | E90交面积比例 | E92交面积比例 | 差值 |
|---|---:|---:|---:|
| 全体2000例 | 5.442% | 5.756% | +0.314个百分点 |
| 固定稀疏157例 | 8.457% | 9.419% | +0.962个百分点 |
| 其余1843例 | 5.185% | 5.444% | +0.258个百分点 |

稀疏组退化幅度约为其余组的3.7倍。按精确N标准化后，稀疏组仍有额外约0.627个百分点的交面积退化。这是子群关联证据，不是连接稀疏单独造成退化的因果证明。

已有E88数据池的2268例经成员核对，全部在当前E92的32k之外，可以重用为真正新增训练成员。不能把此前E88失败简单归结为“新样本不存在”；它也不能证明在完整32k基线和匹配优化条件下新增稀疏数据必然无效。

### 1.5 reference与当前几何确实存在冲突

同五例反例／正对照中，原始reference的模块10%覆盖违规数均为0；使用当前公开派生面积解码其原始参考中心与长宽比后，每例出现5～11个违规模块，最差模块覆盖约51.9%～77.5%。此时reference Loss恰为0，overlap Loss仍约0.454～0.717。

即“完全复现监督目标”并不是当前派生任务的无重叠解。这支持前训练主要学习reference空间组织、后训练允许较强几何修复；不支持在两个阶段都持续追求更低reference误差，也不意味着应取消前训练监督。

另发现reference位置项使用解码前中心，而重叠／task使用解码后矩形；边界clamp会造成少量语义差异。五例中相关位置Loss差值量级约1e-3，尚不足以认定是主要退化来源。**不建议直接将位置项替换为clamp后的中心**：clamp饱和处会丢失逃离边界的梯度；如未来调整，应连同平滑解码参数化一起做独立对照。

### 1.6 切换与预算分配是次级嫌疑，不是调度规则bug

P共39轮，切换回载P best36；F只获得16轮完整监测。F起点Loss0.352050，前三轮依次为0.362932、0.366211、0.366018，随后按规则降LR；最低档下仍产生best15，资源停止时停滞计数仅1，尚未满足早停。

E92中“新建Adam、起步2.5e-4”是此前助手提出的设计，不是两阶段Loss所必需。它可能增加切换冲击；但初始梯度目标改变本身也会造成短期反弹，目前不能单独归因于Adam重置。F阶段确实把自身起点的overlap从0.76750降至0.48295，约改善37%，说明后训练有作用，只是尚未追平E90的几何水平。

此前把“至少2h”实施为累计2h硬上限，导致多数更新投入P、F阶段在仍有改善时被资源截断；这属于预算分配方面的局限。不能据此宣布该训练方式已经收敛或已被否定。

## 2. 首选：固定现有架构和32k，做两个匹配的后训练分支

**不建议再从零跑一整遍。** 先利用保留的P best36作为共同起点，直接研究F阶段，节省已经完成的前训练成本。

| 配置 | 对照C：温和交接＋原F | 候选G：温和交接＋重叠增强 |
|---|---:|---:|
| reference系数 | 1 | 1 |
| overlap系数 | 0.0897516286 | 0.1795032572（×2） |
| task系数 | 0.3336832108 | 0.3336832108 |
| Loss表达式／归一化／聚合 | 原三组定义 | 完全相同，只改overlap系数 |
| 起点及Adam | P best36权重与其匹配的Adam矩 | 相同 |
| 起始LR | 1e-4 | 1e-4 |
| 调度 | epoch0基准，无保护；3轮停滞降至5e-5，最低档至少完成2轮才可早停 | 相同 |
| 数据／模型 | 原32k完整覆盖、batch32、全参数192×12、原FP32及0.005步长保护 | 相同 |
| 资源 | 最多24个完整F epoch（24000更新）／1h，早停可提前结束 | 相同 |

前训练原定义与权重不变。只提高overlap，不同步再放大task，因为task中的compactness会继续鼓励压缩外框，未必有利于缓解拥挤。原始重叠、覆盖、外框和精确空白必须分开记录，不用更小外框代替质量改善。

两分支使用同一保存的阶段末随机流／采样日程；Adam矩来自与P best36权重匹配的checkpoint，不拼接P末尾其他权重的矩。阶段交接另记父权重、Adam年龄、累计历史费用与新更新数；阶段内恢复绝不重置它们。起步1e-4不增加任何后训练保护期。

C与G是匹配的权重对照；它们共同改变的交接策略与旧E92相比属于一个优化包，不能由结果单独声称“Adam重置是唯一原因”。如值得继续，再追加保留／重置Adam的单因素短对照。旧E92的已完成终末不重跑。

每支仍用**本支固定Loss**反传、监测、best、LR与早停；不能按原F Loss、覆盖或Q另挑checkpoint。候选G总Loss的定义变大，不能直接与C/E90总Loss数值比高低。冻结唯一own-best后，才计算共同旧F诊断、完整开发几何和一次相同flash500；质量门槛事前登记，不因这轮失败而放宽。两支训练预计合计至多2h，数据重载／评价单列并记录，不强求耗满或假称收敛。

如果G相对C没有改善覆盖尾部及固定稀疏组，就停止继续机械放大权重。若草稿几何改善但Q仍退化，优先检查案例15这类Loss改善却Q恶化的拓扑／软约束反例。必要时仅在overlap组内部检验“最差一个模块”与“最差一部分模块平均”的聚合，不堆新大项；该表达式变更必须另登记，并不能视为已经验证的方案。

## 3. 第二优先：针对性使用已有稀疏新数据

在Loss／交接方案确定后才做，避免同时改变数据和目标而无法归因。

- 使用现有2268个真正超出32k的新成员，不重复大扫描；仅来自冻结train分片，参考与公开任务版本不变。训练稀疏判定用已冻结的train阈值，不拿开发157例的阈值去挑训练样本。
- 保留每轮原32k完整一次覆盖，再增加8000个稀疏回放draws，合计40000 draws／1250个batch32更新。新增2268个成员在回放池内确定性轮转；实际独立成员34268，不把重复draws称为新样本。
- 匹配对照也做40000 draws：32k完整覆盖＋8000个旧稀疏成员回放。新旧回放按实际N、端口覆盖、密度档匹配，披露没有共同支持的分层；固定相同更新预算／Loss／来源权重。这样才能区分新增覆盖、多训练与稀疏过采样。
- 主要看稀疏157组的覆盖／交面积是否改善，同时检查相同N下的非稀疏组与大布局不被牺牲。原固定监测500与完整开发2000不重切，测试封存。

## 4. 模型结构暂列最后

现有网络已经有全局attention、矩形间隙／穿透通道，以及行归一化图输入；完整端口表示和二维修正器也已有负面实验。因此不把重复添加这些机制当作首选答案。

如果目标和数据对照仍暴露无锚模块的组织短板，再比较局部分支的前归一化／状态回写增益约束，或新的纯神经空间组织机制。历史E60只能提供稳定性线索，不提供质量胜出的证明；本次E92激活并不更大，所以这些改动优先级低。仍不采用自回归。二维修正研究仍须先达到布局器门槛，不绕过已终止任务的条件。
