# 研究与执行协议

更新：2026-11-01。本文只规定当前通用边界。各实验的Loss、LR、预算、来源和执行授权以其登记计划为准；旧规范见[整理前快照](../history/20261101_research_consolidation/documents_before/docs/protocol.md)，不改写历史运行。

## 1. 数据和信息边界

原始split_v1按完整分片冻结为80/10/10；所有已冻结索引保持字节不变。路径由protocol/paths.json解析，不重切分、覆盖成员或重复解压。train用于梯度，dev用于监测和选择，测试默认封存，须用户明确发起。官方公开验证只作接口与公开对照。

新实验默认train16k/dev2k/test2k，固定train/dev各500监测；成员版本必须登记。现行reference任务用v5成员，已验证的v6前缀可读同一16k；扩展32k等须注明曝光历史，不能只报本次样本数。v2/v3/v4等版本的适用范围见[数据说明](datasets.md)。

网络与求解器只读取公开输入及允许的草稿。固定尺寸/预放置是公开规格；自由reference坐标、形状、标签和参考评分分母不作为输入。MIB平均面积规则改变任务而不改变原件，派生Q保留其反事实和自适应开发边界。

旧v2测试已暴露957例、39个worker；后续v5选择排除对应已暴露成员。既有暴露和授权不开放新的测试，也不能把适应过测试反馈的结果称为独立未见泛化。详情保留在历史索引和运行记录。

## 2. 当前研究与训练

当前采用GPU神经网络＋非神经网络混合求解，允许类似E85的多段网络、固定几何操作与有限迭代。研究重点是更好的网络草稿支持更简单、迭代更少的后处理。网络只读公开问题和允许草稿，端口采用逐模块总权重与加权中心摘要，精确线长仍用完整连接。最终硬合法、固定dev500中性时间加权Q<1.01为质量目标，质量优先；逐例完整延迟尽量<0.25秒，报告均值/P95。输入构造、传输、网络、所有几何修正与必要硬检查均纳入完整计时；模型加载/预热单列，批量摊销不能替代逐例延迟。布局器/修正器/纯几何对照与各阶段预算分别登记，历史一次纯F的限制不再自动适用。

每阶段固定Loss的项、权重、归一化和聚合。反传、固定train/dev监测、best、LR和早停共用同一总Loss；按dev500算术均值选择唯一best。终末Q、分项和尾部用于候选与机制评价，不回头按Q另选checkpoint。布局器前/后训练只在事先登记边界切换相对权重，各阶段总Loss不直接比较；修正器单独登记，不机械继承布局器的reference训练目标。

启动前登记：来源权重、初始化、数据/面板、种子、batch、精度、LR档位、保护期、min_delta、下降/早停条件、预算和引擎。当前默认batch32/FP32；从头训练保留登记的保护期，暖启动后训练epoch0建立基准且无保护。布局器现行两阶段规则保留在已登记计划中；具体数值不在本文累积历史例外。

每轮固定train/dev分开监测，eval/no_grad不更新参数；注明train监测成员曝光情况。小幅改善可保存best，但是否重置停滞由登记min_delta决定。时间/步数上限、用户停止和数值失败分别记录，不冒称收敛。

best用于选择；latest保存模型、优化器、RNG、采样排列/游标、seen、调度、早停及累计预算。阶段内恢复不清零。切换目标/引擎、回载best或重新初始化须写明继承和不继承的状态，保存原运行，不伪称普通续训。历史费用累计保留，新预算窗口单独登记。

默认最多5例做与改动相关的最小实施检查；不预先测试断点续训，不堆叠预防性或重复测试，实际出错后针对性修复。必要状态保存与数值门禁仍保留。正式训练的固定500监测和终末评价按计划执行。不能以五例表现宣称泛化，不能按dev扫描多组系数。改善机制须以控制、消融或反例论证。

## 3. 评价与人类反馈

用户同例草稿观察是重要研究依据，保留原话与评价版本，将模糊观察转成待验证假设。数值分别报告Loss、重叠/覆盖尾部、空间组织、外框/空白、线长、公开约束、意图保留与耗时；小位移不自动等于尊重输入。

默认展示固定同100例reference／L原始输出／F×1／最终后处理，统一模块ID与尺度，注明来源。没有评分控件，不自动打开页面；只有用户明确要求评分才启用。L直接研究可用reference／本轮／此前最好草稿三列。旧图和记录保持原样。

草稿硬合法与后处理合法分开，几何代理下降不保证Q改善。终末只评价冻结own-Loss best一次，支持补缺失成员；已完成的相同结果只读复用。Q调用原官方评分及独立硬检查，中性时间Q与实测耗时分列，不称正式比赛总分。开发面板已多次暴露，统计区间不消除自适应、单seed和分布限制。

## 4. 执行、工程与整理

长训练默认交用户命令；用户明确授权可在指定范围后台执行，不反复索取同一许可。不擅自添加候选、测试或自动唤醒。停止请求优先：阻止后续阶段，批次边界安全保存，核实进程退出；失败不自动无限重试。

先测量再优化，具体路径见[GPU工程](gpu_training.md)。保持数学目标、数据边界、batch和精度；只做当前改动必要的前向/梯度与实际更新短检，不专门测试恢复下一步。数值路径变化登记身份，不放宽数值门禁或隐藏失败。

源码和运行证据归实验，旧必要证据归history；保留活跃任务、唯一权重、原始数据和有效缓存。清理校验路径和引用、记录迁移，不修改历史JSON或上游原件。结构见[workspace_structure.md](workspace_structure.md)，Git范围见[git.md](git.md)。
