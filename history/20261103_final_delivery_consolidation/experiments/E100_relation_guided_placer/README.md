# E100：关系引导的同时布局网络

2026-11-03用户授权实施并后台训练。先做一个guided候选，验证端到端训练能否学出实际控制坐标的方向关系；本轮不自动追加direct/auxiliary对照、后处理评价或自动唤醒。单臂结果不能证明优于原布局器或证明机制归因，完整质量与延迟留待冻结模型后的统一评价，测试封存。

## 模型与目标

本地复制E98的96×12矩形几何编码器、公开特征和训练基础设施，全部随机初始化，不读取旧权重。模块对预测左/右/下/上四方向，交换模块严格反向；方向读取全局模块表示和初始草稿。4层固定几何更新实际使用这些方向：熵置信度降低不确定关系，四次幂强化方向，按违反量推动模块分离；同时施加弱公开连接吸引和边界方向引导。预放置不可移动，固定形状按公开规格解码；形状只由初始形状头预测，几何层保持不变。更新有界，所有模块同时更新，不保证草稿硬合法。

端口继续完全压缩为每模块总权重和加权中心，完整公开连接只用于Loss。reference自由坐标、形状和方向标签只在Loss中使用，不作为网络输入。方向监督允许reference的多个有效方向，重叠且无有效方向的reference模块对忽略关系标签；独立几何Loss不会因此关闭。

固定Loss为E98十项原系数加方向集合NLL×0.2，阶段内不变，不扫dev权重。反传、固定train/dev500、best、LR与早停共用同一总Loss。数据为冻结v5原16k，公开MIB平均面积变换，复用核验过的v6前缀缓存，不扩成员。

## 本轮运行

batch32、FP32、seed0、AdamW，从头训练；最多4小时或200轮，平台调度保护期14轮，第15轮建立基准，随后按登记阈值与耐心降LR/早停。具体配置见plan.json和loss_config.py。best/latest分开，状态保存继续保留优化器、RNG、排列游标、调度、累计预算。用户明确要求不测试断点续训，本轮不验证恢复功能。

实施短检仅5个训练成员组成batch32，确认Loss和一次真实CUDA图参数更新、关系头有有限非零梯度。无恢复测试、求解器测试或反复预防性检查；实际错误保留证据后针对性修复。

训练入口：`python -u -B -m experiments.E100_relation_guided_placer.train`；后台入口launch.ps1。日志为runs/train.stdout.log、runs/train.stderr.log；100步追加steps.jsonl；每轮保存固定面板详细分项、关系指标、每模块重叠低于10%达成率、最坏模块负荷及成员。训练末尾只保存结果，不自动后处理。

运行目录runs/20261103_relation_guided_seed0；heartbeat.json用于当前步骤和累计时间，progress.json用于每轮完整监测，checkpoints/best.pt和latest.pt分别保存。创建runs/STOP可在批次边界安全停止。所有复制源码归本实验独立维护，来源与哈希见provenance.json。
