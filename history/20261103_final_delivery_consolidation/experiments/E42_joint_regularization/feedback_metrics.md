# 人工反馈的几何量化 v1

2026-10-24。范围是首轮已记录的22张评分及另1张仅标签，共23例；100图准备完成不等于100张都已评分。源草稿和评分不修改。用户口述保存在分析运行的反馈快照中，原始评分/标签及修改事件同时保留。指标在看到本轮反馈后提出，属于探索性定义，不是独立验证后的训练目标。

## 1. 局部复杂重叠

设矩形面积为`a_i`，交叠面积为`I_ij`。保留三种不同的量：

- `r_ij = I_ij / a_i`：i被j覆盖的比例，方向不可互换。每块总覆盖负荷`l_i = Σ_j r_ij`可超过1，表示同一位置被重复覆盖。
- `m_ij = min(r_ij,r_ji) = I_ij / max(a_i,a_j)`：两端各自面积都被占用多少。强重叠图用`m_ij ≥ τ`连边，避免一个小块被大块吞没时误称双方都大比例重叠。小块被吞没仍由单块负荷报告。
- 在强图的每个至少3块的连通分量C内，`l_i(C)=Σ_{j∈C} I_ij/a_i`，定义`E_C = Σ_{i∈C} l_i(C)^2 / N`，取最大者为局部复杂堆积能量`E_complex`。同时报告分量块数占比、面积占比、每块覆盖负荷和强边数，不能只报一个合成数。

平方负荷对多重覆盖更敏感；除以整例模块数N，使大范围堆积承担更多权重。分量内部覆盖负荷包含C内全部实际交叠，不仅强边。主展示τ=10%，并固定提供2%、5%、10%、20%曲线，不用22张分数挑选阈值。该能量没有上限，也不是概率或百分比。

独立报告普通交叠对数、最大任意重叠连通块、总交叠面积/总模块面积、覆盖负荷最坏10%均值。单独两块严重重叠也很差，但不称为“一大片复杂堆积”。合成反例检查：浅重叠长链和深重叠大团可有相同连通块大小，新指标应区分二者；缩放/平移不改变量纲无关指标。

## 2. 无效留白：受限改动下可消除的部分

原包围盒面积B，真实矩形并集面积U，空白E=B−U。`E/B`只描述现象，不能说明能否廉价消除。尤其草稿有重叠，不能用`B−Σa_i`代替真实空白。

我们希望测的是：在给定中心位移预算δ、形状预算η、线长代价预算ε及约束保护条件下，最多能收缩多少包围盒，同时占用并集不减少。理想函数为

`R*(δ,η,ε) = max_{允许改动} (B−B')/B`，并报告`(B−B')/E`（原留白可消除的比例）。

这不是直接计算空白面积，而是寻找一份真实可执行的“小改动→可观收缩”证据。原布局本身总是零收益候选。任何大于零的合格候选都证明至少这一部分留白可以在该预算内消除。

初版预算事前固定如下，不用人工分数拟合：

| 项目 | 定义 |
|---|---|
| 移动 | 每块中心L1位移除以自身`sqrt(a_i)`；最大≤δ，平均（包括所有块）≤δ/4 |
| δ曲线 | 0、0.02、0.05、0.10、0.20；δ=.05表示每块最多移动自身面积等效边长的5%，全例平均≤1.25% |
| 形状 | 宽`w'=w exp(z)`，高`h'=h exp(−z)`，面积逐块精确保留；η=0或`abs(z)≤.05`，即宽最多增加5.13%/缩小4.88%，长宽比最多变化约10.5% |
| 固定/预放置 | 固定尺寸不变，预放置位置和尺寸不变；其他公开输入不变 |
| 线长 | 使用原版官方中心到中心/引脚Manhattan线长，最多相对增加0.1%；不使用自由参考位置或参考分母 |
| 重叠保护 | 每一对模块的交叠面积不得增加，不产生新交叠；真实占用并集不得减少 |
| 其他代价 | 官方边界/分组/MIB违反数分别不增，面积/尺寸违反数不增；不增加负坐标问题 |
| 保守边界保护 | 原本完整满足边界要求的块保持原尺寸及贴边关系；这会漏掉一些通过改这些块形状取得的收益 |

另报相对于芯片对角线的实际最大位移，方便判断视觉上的“小”。η=0表示仅位置可改；δ=0、η=.05表示仅形状可改；两者均非零是共同改动。比较这三条曲线有助于检查“形状与位置共同作用”的猜想，但探测不是全局最优，差值不能解释成精确因果贡献。

**区分包围盒收缩和重叠释放**：把堆积模块在原包围盒中摊开，可以增加U、减少E，却没有让布局范围变小。因此主指标只计算经保护的`B−B'`，另外报告`U'−U`及完整`E−E'`。不能把单纯解重叠填空白也算作整体压紧。

## 3. 如何找到证据，以及不能推出什么

[feedback_geometry.py](feedback_geometry.py)用独立的诊断探测，不调用生产后处理器：每个预算分别最小化归一化宽高之和、仅宽、仅高，最多三个凸锥候选。指数锥给出`w≥w0 exp(z)`和`h≥h0 exp(−z)`，求解后恢复精确等面积尺寸。对每对矩形选用原端点构造交叠上界，原来不交叠的保留一条分离方向，原来交叠的两个方向都不加深。固定方位和端点是一项保守限制，允许原来的空隙闭合。

每个候选恢复真实几何后再逐项复核官方软约束计数、逐对交叠、精确并集、面积、锚点、位移、形状及线长。任何保护条件失败都不能进入主指标。保留几何/线长合格但软约束退化的候选，明确标成“有代价的收缩”，用于解释为什么不能算无效留白。更小预算的合格候选和仅移动候选一直保留，因此最终报告的证据曲线单调不减。

这里得到的是**已找到的收益下界**。凸子问题不等于全局布局问题；三种宽高方向没有穷尽面积最小解，固定分离关系、贴边保护及数值精度都会漏解。值大证明存在容易消除的留白；值小或零不能证明其不可消除，也不能把当前探测器的盲区当成模型优点。该量不作为正式Q，也不代表修复后全硬合法。没有把新指标接入Loss或训练。

## 4. 与人工评价核对

只在22张实际评分上计算分档分布、秩相关及控制模块数后的描述；仅标签那张参与几何诊断，不补分。少量主动标签不是完整二分类标注，“没标留白”不能当作“留白正常”。仅1张留白标签不能验证留白指标，也不能仅据总体等级的相关性否定该维度。

结果须展示支持例与反例，记录定义是在本轮反馈后提出；没有留出验证、没有拟合分数权重、没有尝试宣称统计因果。后续如要将其用于模型调整，应先在开发数据确认指标能重复对应可见现象，再提出明确的对照实验。
