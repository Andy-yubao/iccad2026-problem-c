# “整齐且容易微调合法”四项顺序诊断

2026-10-24，用户明确授权依次检验此前讨论的四个角度。所有结果属于诊断，不训练、不改变原E42模型/Loss/生产后处理，不恢复旧方向。仅使用已有22评分＋1标签的公开输入/已存草稿；梯度与层内轨迹另外使用事前按模块数选择的5个开发监测成员，不读未暴露测试。

1. **小改动可合法化。** 联合优化全部可动模块。固定形状先作原方位线性规划，再作允许四方向选择的混合整数规划；报告最大/平均/最坏10%归一化位移、移动模块比例。主移动上限为自身等效边长的0.5，评估2%/5%/10%/20%/50%预算。线长最多增加1%，宽/高各最多增加sqrt(1.01)−1，外框面积最多增加1%；原本完整满足的边界要求保护。允许小幅改形的固定方位指数锥另作条件见证（log宽变化≤5%），不能把固定方位不可行称为全局不可行。逐例原版官方硬约束及软约束独立复核。把找到合格见证、有硬合法但软代价、已证明受限问题不可行、限时未知分开。混合整数求解每例2秒，四进程各1线程；诊断墙钟保护8分钟。
2. **相近重叠量的反例。** 在同一22例上匹配：总两两交叠面积比例差≤0.01、模块数差≤20、预放置占比差≤0.05；跨评分匹配不放宽阈值凑例。报告匹配数量/缺口、修复证据、强冲突团及原关系下不可满足约束。旧结果只作关联，不能当因果；没有足够自然配对时明确说明，第四步以同例微扰补足。
3. **训练目标及12轮更新。** 按冻结dev_monitor500的公开模块数元数据，选择最接近25/45/70/95/115块的5例（重复时取下一成员，不参考成绩）。冻结best51，eval模式，保存初始head＋12层head状态。核对最后状态与正常forward一致。分析真实几何训练Loss各项：输出state梯度与参数梯度分别测余弦、范数和抵消；占用项只作选模诊断，不混入实际训练梯度。原参考理想state在新面积下解码另作监督冲突诊断，不作为模型输入或合法标签。记录LayerNorm/解码clamp影响、输出表示与几何的差别。最多5例，不更新任何参数，保护8分钟。
4. **人工反事实对照。** 前三项完成后，优先用真实小修见证及同例可控微扰生成少量盲置左右对照；原布局/变体来源与左右随机化事前冻结。共享visualization绘图/前端，另建新评分会话，1=A更整齐/2=差不多/3=B更整齐，可选评价哪边更易微调合法及哪边留白更合理。原22评分不重解释、不覆盖。准备好前端后由用户评分，人工反馈未到时该阶段标为待评价。

所有方向都保存失败和未知。不得把求解器未找到解记成“草稿本质难修”，不按Q选图，不用这轮测试评分直接训练。计算预计数分钟，训练/推理累计保护仍小于20分钟；源码快照、实际命令、成员、哈希、线程、预算和停止事实保存在本目录。
