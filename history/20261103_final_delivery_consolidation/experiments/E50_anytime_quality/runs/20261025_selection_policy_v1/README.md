# 公开输入选解规则：先冻结，再检查剩余候选库

当前100运行仍使用v1的保守证书，不修改进行中的搜索或结果。其21例候选库已经找到Q约1.038的解，但保守证书拒绝了它。这说明“任意未知参考分母都保证不退化”的要求强于用户的“固定100例实际不退化”，会阻止实质改进。

新规则只使用公开面积、实际线长、软违反、原draft线长、公开模块总面积和距离D：用截断后的面积/线长超额及exp软违反构成估计Q，再加0.01D。它模仿官方质量因子的正部结构，避免给已经低于分母估计值的量继续奖励；这只是公开代理，不能冒充真实Q或数学不退化保证。真实Q仍仅事后验收。

仅用当前100运行的前43例候选库选择全局规则，未按案例ID设分支。尝试原draft线长倍率0.98/1/1.01/1.02/1.04和D权重0/0.002/0.005/0.01后，冻结倍率1、权重0.01；这43例事后模拟加权Q约1.012289，零历史基线退化。后57例只用于冻结规则的候选库确认，不能据其结果回改本规则或覆盖旧100在线成绩。全部100候选生成过程不读取真实Q，选解规则不影响本轮生成；候选库复选仍需另一次端到端验证，不能替代实际运行耗时证据。

唯一规则见[policy.py](policy.py)。当前这份规则不得在“确认”过程中静默修改；若失败使用新版本和独立证据记录。首轮源码快照、逐例候选及旧在线选择保持原样。
