# E74：真实碰撞门控Loss＋冻结嵌套32k后训练

2026-10-29，按用户“兼容思路优先组合”的要求，将目标修正与数据扩充合为一组，继续优秀E42模型后训练。原E73完成但未胜出；本组不改变其稳定化宽模型结构及优化限制，测试封存。

## 证据与假设

[E73复核](../E73_wide_robust_posttrain/runs/inspection.md)显示：best固定train/dev Loss分别下降13.75%/2.04%，差距扩大至46.15%；后期train仍降而dev回升，存在泛化不足信号。与此同时，同dev500旧G增加0.022990，却被新增T加权下降0.038338覆盖，导致总Loss下降而flash加权Q从E42的1.025860退到1.033736。同100图真实交面积、外框和精确空白均退化。

[已有100例坐标审计](runs/objective_audit/saved100.json)没有模型推理或求解，发现E42/E73的T中分别62.39%/55.19%来自当前已不相交的模块对。T的非相交贡献由0.480481降至0.384555，相交贡献反而0.289682升至0.312236。它主要奖励了非碰撞处的参考方向对齐，不能把这种改善解释为避碰提升。拟议门控C在同坐标上0.055059→0.076842，与实际交面积退化方向一致，但这只是事后设计依据，不是训练收益。

组合假设：把新增方向监督限制到真实碰撞处，同时用冻结32k降低新增关系监督的过拟合，在保住E42已有宏观拓扑和紧凑性的前提下改善草稿。该假设可被train/dev曲线和同例几何/Q推翻；两个改动一起实施，不单独归因。

## 唯一固定Loss

`L = G + 0.5 C`。G保留E42八项公式、权重与归一化，不降低中心/相对位置监督。沿用E72/E73相同参考近邻集合和参考分离轴，令每对的有向缺口平方为`t_ij`，实际矩形交面积为`I_ij`，公开面积为`a_i/a_j`：

`C = sum_ij [t_ij * I_ij/min(a_i,a_j)] / n`。

新项对所有不相交模块对严格为零，并随交面积趋零连续趋零；不使用碰撞布尔开关造成有限跳变。参考方向只在真实相交时指导分离，原G仍锚定位置和近邻。它仍不是硬合法保证、完整意图邻接或修复可行性证明。旧无门控T仅作诊断，不参与选模。

反传、train/dev500、完整dev2000及未来获授权测试均调用同一固定Loss；best/LR/早停仅用该Loss的dev500均值，epoch0合格。不同总Loss不能与E73总值直接比较；共同G、物理交面积、外框/空白和固定flash结果提供解释。
