# 下一阶段研究提案：优先清除严重重叠模块

2026-10-30。用户确认Q目标为固定dev500的加权Q<1.01；随后明确“Q只是一个指标，我们更关注于产出质量更高的draft，因此处理严重重叠模块的优先级更高”。本文件据此调整优先级，属于研究提案；没有启动训练、模型推理、后处理求解或自动跟进。

## 1. 目标与评价位置

首要研究目标是质量更高的修正草稿。新增主指标暂按自然面积定义为：

`r_i = area(R_i ∩ union_{j≠i} R_j) / area(R_i)`

`N_5 = sum_i 1[r_i > 0.05]`。

每个有效模块均计入，包括预放置模块；被多个邻块覆盖的同一区域只算一次。阈值严格为>5%，不引入有利于达标的宽容区。用户尚未单独回复并集/逐对累加口径问题，本提案建议采用并集；保留历史逐对累加口径对照，不追溯改写。

N5在“修正阶段输出、最终后处理之前”评价。目标是完整dev2000每例N5=0，即最大值和全部案例总数均为0；不能用平均数接近0代替。报告均值、中位数、P95、最大值、零严重重叠案例率，以及最大r_i和超过阈值的面积余量。N5=0也不等于完全无重叠，原硬合法性仍单列。

Q沿用当前同一固定dev500、相同flash配置/预算及中性时间评分定义，作为后续最终质量目标。单例、尾部、救援和新增修正耗时继续报告。Q与N5位于不同阶段，不把最终合法化结果计作网络草稿已达标。测试继续封存。

E85总交面积下降，但约96%的最终两组平均差在冻结算子直接对照中已存在；无端口模块相对位置/次序改变很少。平均交面积下降没有解决高重叠模块尾部，尤其可能忽视面积小但自身被覆盖比例高的模块。

Q的保存结果精确分解：超额Q约0.014672，其中线长0.002305、外框0.002686、软约束0.009680。软约束约占66%，其中边界/分组的对称分摊分别0.004412/0.005268。该分解只说明评价结果构成，不是可直接获得的因果收益。研究优先级仍是严重重叠草稿；组/边界结构作为重要质量保护条件。

## 3. 第一阶段：先验证动作空间，不训练

冻结E74与当前F85最佳权重，将E85完整修正输出作为共同起点。只用最多5个训练成员作机制检查；样本按公开端口覆盖、连接稀疏性、模块大小/锚点结构选取并事前固定，不挑开发终末Q。

对照A：保留现有有限步连续位移和尺寸，针对每模块相对重叠尾部施压。可微的逐对累加上界 `ell_i=sum_j I_ij/A_i` 满足 `r_i<=ell_i`；若所有ell_i<=.05，则并集指标也达标。它提供可验证的保守约束，不作为新指标替换并集，不通过搜索Loss权重实现。

对照B：同一输入、同框、同尺寸与预算，允许冲突簇局部重排。以严重重叠模块为种子，纳入会被推挤的邻块、相关分组成员及锚点障碍；候选让位区域由矩形边、公开空白和锚点通道决定，允许少量分离轴/相对次序改变与簇级平移，再联合求位置。冻结尺寸，先分辨连续移动受限与次序错误；如果必须改形状，另立必要对照，不混在首轮。

比较N5、阈值以上余量、最大相对重叠、受影响模块数、原框/面积/固定规格、组连通/边界和实际线长变化。允许中间步骤临时增加局部碰撞，但完整候选必须检查外部邻块，不能把冲突推到未计入的模块；不能靠排成一行或任意放大外框达标。

可证伪条件：若A已经稳定消除严重重叠，优先保留更简单的连续机制；若A停滞而B改善，支持局部次序/空间分配是下一项模型表示。若两者都找不到满足约束的结果，先区分搜索预算不足、锚点拥塞、形状和来源框可装性；求解超时不等于证明不可行。机制不成立时不启动长训练。

## 4. 第二阶段：只学习经验证有效的局部修正决策

若B有明确价值，候选采用“冲突簇级空间分配/次序头＋可检查的坐标解码”，优先让模型学习移动哪些块、放到哪个可用区域、沿哪条方向让位。训练监督来自当前派生任务公开约束下的局部修正动作，避免要求网络精确复制与当前面积/同形条件不相容的旧参考局部坐标。reference外框尺度和已有宏观结构继续保留为先验/对照。

先冻结E74主干，复用当前F权重后训练。一个候选加一个必要对照为上限；两组采用同一起点、同成员/数据规模、同预算、相近可训练参数，以及从一开始取消后训练学习率保护的相同规则。新增动作监督/训练目标在训练侧先定义与定标，然后登记唯一固定Loss，训练、监测、best/LR/早停完全一致；不边看开发结果边试多组系数。阶段验收以草稿N5及用户同例观感优先，checkpoint仍按该固定Loss选择，不根据终末Q或临时几何结果重选权重。

只有后训练在困难例、反例和整体草稿上都有实质价值，才考虑从头训练检验架构本身。从头训练仍保留原保护期；不把一次开发改善直接宣布为泛化突破。

## 5. 阶段验收、预算与停止

主验收：完整dev2000每例N5=0；同时保存原始交面积、形状/硬规格/外框/分组/边界、无端口近邻次序及同100例四阶段图供用户判断。前期未达零时如实报告零严重重叠案例率和最坏案例，不把平均N5下降称作达标。
