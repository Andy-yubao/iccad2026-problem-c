# E96 权重修订提案：先明确消碰与外扩的交换代价

日期：2026-11-01。按用户最新结论，E95 已失败，E96 尚未启动。本方案已由用户“好的，现在启动后台训练”采纳并授权执行。现行配置为外框 0.5、仅完全压缩；旧准备源码与登记已保存于 runs/20261101_bbox05_registration/before_revision.zip。新源码须通过原五例预检后才启动。

## 建议

F 后续固定使用完全压缩：保留每模块端口总连接权重和加权中心，不使用独立端口 token；不安排 regional32 后续阶段。完整原始端口及连接只继续供精确 Loss、评分和后处理使用。冻结 L 及其输入不因 F 压缩而改变。

建议固定目标：

`Loss = 1.0*overlap + 0.5*(B/A) + 0.05*wirelength + 0.2*soft + 0.1*intent`

保持现有各项定义与归一化。B 是实际草稿外接矩形面积，A 是公开有效模块总面积；不使用 reference 的位置或面积分母。

`intent = direction + neighbour_expansion + 0.01*(movement + 0.25*shape_change)`

因此实际方向/邻居扩张/移动/形状权重依次为 0.1、0.1、0.001、0.00025。这里的相对位置来自输入 L 草稿，不来自自由 reference 坐标。邻居扩张项确实限制外扩，不能将全部外扩阻力归于 B/A。

## 为什么不沿用初始梯度等范数

E95 用原五个 train 例在 L 初始草稿上的 overlap 与 B/A 自由状态梯度范数比中位数，确定了 8.46。该方法只匹配初始局部梯度的总范数：没有决定实际消碰收益与外扩代价的交换率；B/A 的极值边缘梯度与 overlap 的局部作用也不同。在初始草稿处 intent 的值和梯度均为零，这次匹配未衡量修正后出现的意图阻力。

8.46 是旧有效外框系数 0.05 的 169.2 倍。不能因初始等范数便认为这是合理的任务偏好。

## 使用已有五例做有限变化的代价核算

只复用 `../E95_single_pass_corrector/runs/20261101_bbox_preparation/calibration.json` 的五个 train 例，不做新网络推理或参数更新，不加载 dev/test 数据。

比较相同 L 草稿与此前 normalized-local E95 best 的单次修正。记：

- `C = overlap + 0.05*wirelength + 0.2*soft + 0.1*intent`
- `benefit = C(L) - C(F)`，已经扣除线长、公开约束及意图变化的代价。
- `delta_b = (B/A)(F) - (B/A)(L)`。
- 修正比原草稿更受目标欢迎的条件是 `lambda_box < benefit/delta_b`。

表中 delta Loss 为修正减原草稿，负值表示修正更优。

|train ID|delta B/A|非外框净收益|外框临界权重|lambda=0.5 的 delta Loss|
|---|---:|---:|---:|---:|
|1683|0.146089|0.158952|1.088048|-0.085908|
|10027|0.226590|0.274045|1.209428|-0.160750|
|5474|0.219298|0.345876|1.577195|-0.236227|
|10140|0.122427|0.238164|1.945360|-0.176951|
|15001|0.277625|0.630121|2.269687|-0.491309|

五例的上限最小值为 1.088。采用其一半作为保守余量，再向下取一位小数，得到 0.5。这个“一半”是明确的设计选择，不是统计推导的最优值，也不是根据多组训练结果挑出的系数。0.5 在这五例最多消耗约 46% 的非外框净收益；8.46 会让五例的已有消碰修正全部比原草稿更差。

0.5 仍是旧 0.05 的十倍，每增加 0.1 的 B/A，需至少获得 0.05 的非外框收益才能抵偿。重叠损失下降 0.1 时，可抵偿的 B/A 增量上限为 0.2，且其他项的恶化还会消耗这份收益。

## 相对位置权重为什么暂时保持

临界权重的计算已经包含现有 0.1*intent。先只修订外框权重，可以保留更清楚的解释边界；同时降低相对位置系数缺乏本次五例的独立依据。相对位置项可能在个别局部修正或训练后期造成约束，需要通过同例分项与方向代价进一步检验，不能用平均 Loss 大小推断梯度影响。

## 证据边界及后续登记

这些是已曝光五个训练例、单个历史修正器两端几何的解析比较，不能证明所有中间移动均获鼓励、不能证明收敛，也不能保证 N5=0。完全压缩后的 F 尚未训练，不能将这些数据当作 E96 性能证据。也尚未证明该目标适合强化学习。
