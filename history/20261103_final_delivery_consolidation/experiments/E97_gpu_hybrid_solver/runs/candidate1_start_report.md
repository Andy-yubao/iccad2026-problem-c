# 候选1：公共求解器蒸馏小修正网络

16,000个冻结train成员与原dev500的监督已全部生成，16,500个目标均通过公开硬检查，没有row回退标签；生成墙钟839.68秒，计入本轮12小时。成员/数据分片/manifest及每个chunk哈希已核验；网络输入仍只有公开问题与冻结L草稿，不输入目标位置或reference分母。目标来自较强公开输入求解器，离线成本不计作推理免费收益。

## 开始训练前发现并处理的动作空间问题

原计划v1保持E85的固定L来源框和每段0.15局部尺度限制。监督核查表明：11372/16000个train与364/500个dev目标超出这个固定框，几乎每个案例至少有模块的目标长宽比变化超过两次形状修正的0.30上限。因此，原先的受限网络无法完整表示teacher，不能将拟合失败简单归为优化器或Loss。

v1在正式训练前终止，没有消耗正式候选。原方案、源码和已通过的数值检查保存在`20261102_candidate1_v1_reachability_rejected/`。当前v2保留相同三个小消息网络和241547个F参数，但前两段采用无tanh硬限幅的线性残差提议，不再投影回冻结L框；公共非负位置/固定和预放置规格、MIB协调保留，最后局部修正与8步真实交面积下降使用当前提议的外框。

初始化复制E85兼容隐藏/消息权重，三个最终读出层清零，冻结E74布局器；初始函数是零学习残差加固定几何协调，不能冒称与原F85初始函数相同。0.5只定义残差参数单位，不是可移动距离硬上限。仍保留log-aspect[-5,5]数值范围，9个train目标超出此范围，dev目标均在范围内；nominal-area解码与teacher允许的面积误差也会使精确模仿不可能。这些案例不删除、不修改冻结面板。

## 固定目标与运行

固定Loss为`teacher_center_local + 0.25*teacher_shape_logratio_mse + 0.25*teacher_near_relative_local`，全部乘固定teacher_usable标志；本次16,500例均可用。中心和近邻误差采用beta0.1的SmoothL1，以公开模块尺度归一化，形状为log(w/h)平方误差。邻近判定通过公开nominal-area及目标长宽比恢复的尺寸计算，原CPU面积容差不作为额外隐含网络通道。

这是一项公共求解任务的蒸馏控制，目标是让同一个弱修复器获得更好的输入并减少灾难性回退；不是自由reference模仿，也不保证超过teacher或达到Q<1.01。

seed0、batch32、FP32/无AMP/TF32，fresh AdamW，weight_decay0.0003、裁剪1，原四档LR和3轮停滞下降，无保护期，最低档等待2轮。最多100轮或3600秒，受原12小时总截止共同限制；不继承E96的9872步上限。反传、train/dev固定500、best、LR和早停使用同一个函数。best/latest分存，latest保存模型、Adam、RNG、顺序/游标、seen、调度及累计费用。

五train当前源码预检通过：同形状普通执行与CUDA图真实Adam更新、动量差均为0；捕获预热不更新参数或Adam；重建图并恢复后的下一步模型/Adam/RNG逐位一致；非有限目标在Adam前被拒绝；冻结L保持逐字不变。最初一次检查误让训练态诊断前向消耗Dropout RNG，导致对照不同，已修正为eval诊断并保留失败原件；没有放宽容差。

正式训练已在后台启动，计数1/8。日志已确认实际超过750步，epoch0 dev蒸馏Loss0.263111，第1轮0.189851；这仅说明蒸馏目标开始改善，不能解释为Q或最终解质量已经改善。

结束后流水线只评价唯一own-Loss best：保持完全相同slim3修复、逐例完整dev500计时/评分、dev2000原始几何诊断与同100例四阶段图。所有回退计入Q，不能用增加CPU步骤掩盖网络不足，不按Q回选checkpoint；测试封存。阶段结束后由自动跟进检查证据再决定下一候选。
