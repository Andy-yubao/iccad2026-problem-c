# 三步简化后处理：五train机制检查

同五个公开train成员、零训练；相同冻结E74与来源框/MIB/8步几何操作。`ops_only`不执行已学残差网络，仍包含冻结布局器及相同几何协调，不能称为完全无神经网络求解。

简化器最多3次形状SOCP＋1次固定形状位置投影，设置seconds=0.18，不启用adaptive扩大预算、延长、救援、多种子或最终确定性刚性优化。保留原始硬合法回退并全部计时。这仍是CPU凸求解简化原型，尚未将主要后处理改成GPU并行算子。

端到端时间包含每次公开特征构建、120槽padding、CPU→GPU、常驻图、decode/返回、完整修复、公开硬检查；模型/数据加载、初始图准备、native预热单列。每个实例/方法一次求解，不能据此得出稳健P95。

结论：简化具有速度与硬合法可行性，质量存在损失，旧F85也没有在这五例稳定优于无学习残差控制。例如5474的E85简化结果出现边界1＋分组2项违规，而几何协调控制仅分组1项；1683则学习修正略好。该反例支持针对简化器重新学习更有用的输入，而非假定低重叠的旧F适配任何弱修复器。

这是机制检查，尚未证明最终Q<1.01或完整面板0.25秒目标。训练仍0/8，后续训练应针对这个弱修复器的可行性与质量瓶颈，不能用增强CPU求解预算掩盖网络不足。
