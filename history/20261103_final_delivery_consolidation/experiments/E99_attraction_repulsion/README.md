## 相互作用

令两模块中心连线方向为u、中心距离为d，半尺寸之和为a=(wi+wj)/2、b=(hi+hj)/2。沿该方向的接触距离为min(a/|ux|,b/|uy|)，零分母视为无穷大；有符号间隙g为d减接触距离。

- g<0：沿中心连线排斥，强度为ell·tanh(-g/ell)，ell取两模块短边的较小值；深重叠不会产生无界作用。
- 0<g<R：沿中心连线吸引，强度为0.25·g·(1-g/R)²，其中R=0.5·ell。
- 刚好接触或g≥R：作用为零。仅接触容差使用float64机器精度量级。

每对力等大反向，先汇总整张草稿，再以全图最大活跃邻居数作统一阻尼；过阻尼步长为0.5。**v2质量取初始面积/草稿中位面积，位移响应为合力除以质量。** 在受力相同且未触发坐标域保护时，面积越大位移越小；不同模块真实合力不同，不能据此保证所有大模块的实际位移都小于所有小模块。

安全限幅采用全图统一缩放：选择同一个不超过1的倍率，使每个模块都满足单轮/累计路程上限。这样不会因分别截断步长而抹掉逆质量响应。再施加非负坐标保护。中心完全重合时，用模块ID确定可重复的破缺方向。未加入惯性、能量搜索、group、贴边、MIB、线长、端口或外框目标；公开约束只用于固定预放置和保持坐标域有效。

旧v1没有面积质量，且逐模块限幅；仅作为历史或显式`Config(mass_weighted=False)`对照保留，当前默认开启面积质量。解析检查验证面积4:1的两个模块在等大反向力下产生1:4的单步位移，强排斥限幅时仍保持该比例。

这是矩形方向接触距离控制的中心力启发式，不宣称是某个矩形势能的梯度，不保证交面积单调下降。多个模块共同作用时可能产生新的小重叠；大空洞超过相互作用范围也不会主动被填满。第一版不含形变，方向性应力需以后单独定义。

## 接入

直接处理CPU草稿及预放置掩码：

```python
from experiments.E99_attraction_repulsion import Config, relax

revised, diagnostics = relax(draft_xywh, preplaced_mask, config=Config())
```

有完整公开输入时，推荐使用`pipeline.preprocess(draft, inputs)`，它会先检查尺寸和预放置是否与公开规格一致。`pipeline.solve`可把该步骤与调用者给定的规划器组合：

```python
import json
from pathlib import Path
from experiments.E99_attraction_repulsion.pipeline import solve
from experiments.E99_attraction_repulsion.planner.solver import optimize

options = json.loads(Path(
    "experiments/E99_attraction_repulsion/planner_config.json"
).read_text(encoding="utf-8"))
final, trace = solve(draft, inputs, optimize, planner_options=options)
```

`planner/`是旧E97单线程后处理器的独立逐字复制，24个源码文件哈希见[来源清单](planner_provenance.json)，没有跨实验导入私有算法。该规划器原有其他目标均属于后半部分，不进入吸引—排斥步骤。原E97/E98源码、已存结果、权重及运行未改动。

本地文件入口使用独立环境，在项目根目录执行：

```powershell
& .conda/envs/iccad2026/python.exe -B -m experiments.E99_attraction_repulsion --input input.npz --output revised.npz
```

输入NPZ必须含`positions`（N×4 XYWH）和`preplaced`（N布尔值）；输出包含修改后草稿、逐轮轨迹及参数/诊断。已有输出会拒绝覆盖。文件入口只执行前置操作。
