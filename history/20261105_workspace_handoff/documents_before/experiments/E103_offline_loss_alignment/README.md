用户已认可五个模型并授权自主推进、后台运行长任务和4路并行。当前新登记为数据库1000×5 → 离线权重拟合 → 局部下降方向检查 → 报告。神经网络长训练须根据该证据先登记固定目标与有限对照，当前流水线不盲目自动训练。E98调权搜索已按用户要求安全停止并放弃，不自动恢复。

研究目标：使训练Loss能够引导模型输出在固定后处理器下具有更低混合Q的草稿。路线为同题多模型草稿数据库 → 同题排序/受约束权重拟合 → 局部下降方向检查 → 少量同父模型真实训练验证。离线排序好不自动等于训练有效。

## 数据库规格

原固定train16k中统一抽1000题，每题分别由5个充分训练且权重不同的模型各生成1份原始草稿，共5000份。同1000题已按seed2026110431冻结在panel.json，600拟合/200调参/200内部最终检查；检查按题目隔离。禁止用同一模型5个早期checkpoint或4份扰动凑数量。小幅扰动仅可作为后续另登记的辅助检查，保留固定位置、固定形状、面积与公开约束。

本次冻结CPU FP32单线程原模型推理和E98当前固定计算深度版后处理（源码与预算未改）。四个进程按题目并行，每个题目顺序执行五个模型，最多4个计算任务；数值路径与原GPU运行不同，原数学输入/解码及权重保持，不冒称历史草稿逐位复现。所有草稿在同一公开MIB平均面积任务、ID与尺度下比较；后处理Q标签将由同一独立冻结计算深度评价器重新生成，不拼接历史不同后处理器/时钟预算的Q。各Loss项按同一函数重新计算，保留reference监督但不将reference喂给网络。拟合与检查按题目分隔，并检查留出模型来源，测试封存。

## 已登记的离线分析与方向检查

600题拟合十项非负权重，量纲按拟合题内差异的75%分位数固定；4个正则强度(.0001/.01/1/10)并行，200题只用于调参，选定后冻结提案，另外200题仅终末检查。原系数作为先验与对照。按一半题目等权、一半官方exp(n/12)规模权重拟合同题排序。五种留出来源检查不参与重选超参或系数。

十项值在各模型原始网络state上用同一函数计算，实际解码草稿决定Q；保存原state及草稿，明确解码截断可能使不同state对应相同几何。随后在调参区预先固定40题的E98泛化草稿上，新/旧Loss各作.002/.01两个步长的RMS归一化梯度更新，共160次额外后处理。固定位置/形状通道不变，原解码保持面积。若两个步长均改善且优于原Loss，才建议登记下一步神经训练对照；否则先诊断表示不足或梯度错位。

所有1000题都在原训练分片及源模型的训练历史中，内部检查200只对系数拟合未见，不是网络未见验证集。四路并发耗时不作为部署逐例延迟。五例实施短检生成的25份正式面板草稿直接保留，不重复求解。无验证后处理Q调权，无测试访问，无额外模型。
