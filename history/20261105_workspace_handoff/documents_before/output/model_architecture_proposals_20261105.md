# 当前布局模型结构修改方案

日期：2026-11-05。状态：设计提案，尚未实施或启动训练。目标是在当前公开MIB平均面积派生任务上，改善模型对布局关系的表达，同时降低深层前向放大和训练失败风险。提出三个方案，建议先做方案一，再考虑二或三；不同时扩数据、改Loss或改后处理。

## 现有证据与结构边界

当前基线为E104修复后的128宽、16层结构，参数3,463,747。其训练中途从原未归一化局部路径迁移到local-prenorm.v2；best81的固定train/dev500 Loss为0.337633/0.337808，终末dev500加权Q为1.032266，最终500/500硬合法、草稿0/500硬合法。它可作现有成果对照，但由于前20余轮使用旧路径，不能替代新结构从头训练的严格控制组。

已观察到的失败是前向放大和单例Loss越界：失败后保存的RNG重放中，单例Loss约1914、裁剪前梯度范数4678，数值仍有限；单题eval隐藏状态最大幅度从约9逐层增至996。把局部消息改用已有LayerNorm后，同批次最大Loss约2.90、梯度范数11.77，修复后完成正式训练。这支持局部路径存在放大问题，不证明所有宽/深模型都会梯度爆炸。

代码中的具体设计点：

- 注意力和FFN已有前置归一化，局部消息近期补入归一化；局部与注意力目前共用norm1，且两个输出相加后统一残差注入。
- 每层都执行`h + state_embed(state * mask)`，没有独立归一化或更新门，形成另一个几何状态反馈路径。它是待验证的风险点，不是已经单独证实的本次根因。
- 电连接/MIB/分组矩阵已经按行归一化，不能把当前问题解释成完全没有处理邻居数量。
- 每层的19维模块对描述已包含相对坐标、尺寸、间隙、重叠和公开约束，主要进入注意力的加性bias；不能把再次加入相对坐标称为全新能力。注意力传递的value主要仍是模块自身隐藏特征。
- MIB与分组目前主要通过模块间关系和均值聚合表达，没有独立的组级状态。几何读出head在层间共享，直接预测归一化中心和log宽高比。

这些表达能力瓶颈是代码支持的研究假设，尚无消融结果证明它们限制了当前最优质量。尤其草稿不合法还可能来自目标与后处理的配合，不能只归因于结构。

## 方案一：完整前置归一化、残差门控和门控FFN（优先）

目的：先建立能稳定从头训练的主干，并在近似相同参数量下增强单模块非线性变换能力。

具体改动：

1. 保留128宽、16层和当前矩形几何attention bias。注意力、三关系局部消息、FFN、几何反馈分别使用独立的前置LayerNorm，不共用注意力与局部分支的归一化仿射参数。
2. 注意力与局部消息分别投影、分别通过残差门注入；FFN也有独立门。每层每分支使用一个可学习sigmoid标量门，取值0到1、初值0.1，预先固定，不按dev扫描。它控制更新幅度，不替代数值门禁。
3. 保留几何反馈，但改成`LayerNorm(MLP(masked_state))`后通过独立门注入，移除原来的无归一化直接加法。反馈MLP取3→128→128并层间共享，每层的反馈LayerNorm与门独立；只用本模型当前预测和公开已知量，不引入reference位置。
4. 几何读出前增加独立LayerNorm，保持原三维state和公开规格decoder接口，不对最终坐标或Loss做人为截断。
5. 普通SiLU FFN改为SwiGLU。当前FFN中间宽度为3w；SwiGLU中间宽度取2w，三组权重的主项仍约为6w²，与原两层FFN接近。总参数需实现后精确核算，额外归一化/门参数单列，不能声称逐参数完全相等。

核心形式：每种消息都从归一化输入计算，以独立受控残差更新进入隐藏状态；几何读出与反馈也有自己的尺度控制。残差主状态不被每层强制归零，因此仍保留累积信息。

预期收益：减少各分支互相放大的机会；让模型学会何时依赖连接、几何和非线性变换。SwiGLU在近似相同参数预算下提供乘性特征选择。均为待检验假设。

主要风险：门初值较小可能使有效深度建立较慢；新增归一化可能削弱有用的幅度信息。LayerNorm仿射参数和门仍会学习，不能据此宣称有严格的全局稳定性保证。

工程代价：参数增量较小，但归一化、门控和额外FFN投影会增加运算；FP32吞吐、完整epoch和逐例网络延迟必须实测。这个方案同时改变几个相关组件，若成功只能先归因为整体设计，不单独声称某个组件贡献已被证明。

## 方案二：在方案一上增加携带几何内容的模块对消息

目的：让网络不仅学“关注谁”，也能传递“两个模块目前是什么几何关系”。

具体改动：

1. 保留方案一主干，另设小型边编码器。输入沿用已有公开关系及当前预测产生的几何量：归一化相对中心、宽高、间隙/穿透、电连接强度、MIB/分组标记和固定/预放置状态。距离用公开模块尺度归一化，对大幅几何描述采用预先固定的有符号log1p变换，保留正负与大小顺序，不用reference决定尺度或剪裁阈值。
2. 边编码宽度固定32。消息在原节点value外增加边内容，形式为`sum_j a_ij V(z_j) + U(sum_j a_ij e_ij)`。先加权汇总32维边特征，再升到128维；不构造batch×N×N×128的完整pair-value张量。
3. 电连接、MIB、分组的局部消息保留类型区分，使用各自投影和门；无邻居时该类型消息严格为零。全局attention仍保留，能够处理没有显式连接但可能碰撞的模块对。
4. 消息只更新隐藏特征，最终仍由同一三维state接口输出；不添加外部几何更新层、方向分类监督或新的Loss项。

预期收益：关系与几何内容更直接地影响隐藏表示，例如同一“相连模块”在远离、接触和穿透时传递不同消息。它针对的是已有bias与消息内容之间的差别，不是简单重复添加几何bias。

主要风险：模型可能过早依赖尚不准确的自身草稿几何，形成错误反馈；pair计算可能增加显存和推理时间。继承方案一的归一化和门控，但不保证这种表示必然改善最终Q。

历史约束：E100曾用方向分类加固定几何更新，降低了自身重叠却未改善最终Q。因此这里不把方向准确率作为成功标准，不照搬其几何更新路线；仍要看固定Loss、草稿几何及冻结后的同配置完整后处理结果。

## 方案三：在方案一上增加分组、MIB和全局层级表示

目的：让网络显式保存“一组模块作为一个整体”的信息，补充纯模块对消息。

具体改动：

1. 为每个非平凡公开分组建立一个组token，为每个非平凡MIB集合建立一个MIB token，另加一个全局token。token身份由公开成员关系决定，不使用任意整数ID的专属可学习向量，保持模块和组的排列等变性。
2. 组token以成员隐藏特征的可学习加权汇总，以及公开统计量初始化：成员数、总面积、固定/预放置信息等。端口仍由每模块总权重和加权中心表达，不展开端口token或额外端口分布。
3. 在第4、8、12、16层进行“成员→所属组/MIB→成员”的双向更新；组token只从成员收集，只向成员返回。全局token从所有有效模块汇总后广播。各路径前置归一化并独立门控，保留原模块attention。
4. 实现为带成员mask的两部交互，不把所有模块、组、MIB及全局token拼起来做一次更大的全连接attention，以控制额外开销。空组和padding不得参与softmax或统计。
5. 最终中心与形状使用分开的输出分支；MIB token提供共享形状上下文，再结合模块特征预测log宽高比。首版不强制共享宽高或中心，不用硬绑定覆盖公开固定/预放置规格。

预期收益：让分组的整体组织、MIB内形状协调和全局空间分配有独立状态，而不只依靠成对平均消息。它能表达这些关系，不意味着自动满足连通、同形或无重叠。

主要风险：组级广播可能抹平组内差异；多个约束角色可能冲突；若当前主要误差来自局部碰撞，这个方案未必有效。实现和归因复杂度最高，优先级低于前两项。

## 建议比较方式与实施顺序

只做一个方案时，选择方案一；若继续第二个结构方向，优先比较方案二与方案一。方案三作为侧重组级组织的独立备选，不与方案二未经验证地堆叠。当前仅提出方案，不授权实施或训练。

将来获得实施授权后，使用以下共同边界：

1. 严格结构对照需有“E104修复结构从头训练”的控制组，不能把E104中途迁移后的best81直接当成全部同条件的结构归因证据。已有E104结果只读保留作历史成果对照。控制组不是第四种设计方案。
2. 首轮固定v6前32k、128宽×16层、seed0、batch32/FP32、原十项固定Loss、原增强/Dropout与登记的LR/正常早停，不同时改变训练数据、Loss权重或后处理。参数数目和实际训练量分别报告，不把不同早停步数称等算力。
3. 不暖启动不同结构做首轮能力比较；各结构随机初始化。训练全过程模型/Loss身份固定，保留best/latest、Adam、RNG、排列/游标、调度和累计耗时，不进行中途结构切换。若发生真实错误，单独登记修复及证据。
4. 只用最多5个相关训练实例做必要实现短检，其中包含E104失败题、固定/预放置模块及MIB/分组样例，不专门搭建恢复测试。正式训练按既定监测面板进行。短检不能证明稳定泛化。
5. 稳定性诊断：记录训练批次最大Loss、裁剪前梯度范数和门禁触发；在固定训练小面板低频采样各层隐藏范数、分支更新/残差比、attention logits与门值。关注随深度的幅度增长及门是否饱和；指标不进入dev权重搜索。
6. 表达能力诊断：同时看固定train/dev Loss及分项、间隙，区分train拟合改善与泛化；草稿看精确重叠覆盖、外框、线长与公开约束，并分别观察有无MIB/分组的训练诊断结果。分层观察用于解释，不能代替全体结果。
7. 固定dev500 Loss负责best/LR/早停；终末冻结唯一Loss-best后，每个已登记候选仅一次同dev500、同E98固定计算深度后处理评价，分别报告三Q、草稿/最终硬合法、回退及完整均值/P95/最大延迟与250ms超限。Q不反馈重选checkpoint、改系数或再训练；不读取封存test。
8. 吞吐、完整epoch时间、显存和单例网络时间单列，批量吞吐不替代完整延迟；任何“更稳定/更快/质量更好”的结论都需要对应实测。先进行单seed机制筛查，有正向结果后再讨论独立种子复核，不自动增加运行。

不预报具体Loss或Q收益。新的结构需要同时交代拟合、稳定性、泛化、草稿几何与最终质量，单一指标改善不足以证明整体升级。
