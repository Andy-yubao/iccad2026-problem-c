## 0. 结论摘要（先看这九条）

1. **1x 面板** mean Q = **1.021867**、官方加权 Q = **1.021268**，Σ(Q−1) = 10.934。可约部分 **70.7% 来自 soft 违反**，29.3% 来自 quality gap。
2. 只有 **119/500 例**有 soft 违反，却占**加权超额的 93.1%**；若全部 V=0，uniform 1.0064 / weighted 1.0071。
3. 分族（互斥）：grouping-only 60 例（超额 43.3%）、boundary-only 46 例（25.0%）、both 13 例（19.7%）、无违反 381 例（12.0%）。
4. **reference 的 soft 违反是格式性的**：boundary 985/985 都有空带可外推（中位 1.0 单位）；grouping 45/45 的两片最近距离恰为 **0**（角接触），不是散架。按用户对 boundary 的同口径处理，reference 有效 Q ≈ **1.000**，我们 1.0219 是**真实差距**。
5. **草稿在 soft 结构上已接近参考解**：组内配对 24.6% 重叠、0% 共边、75.4% 分离（连续坐标几乎不可能共边）；贴边余量中位 **0.043** 单位。
6. **共边是 H 造的**：最终解组内配对 **42.9% 共边**，与 reference 的 42.9% 相同；boundary 99.5% 恰好贴边。
7. **H 动得越多 Q 越差**：草稿→最终位移均值 0.0444·L，`corr(位移, Q)=0.49`（对比 `corr(草稿覆盖率, Q)=0.18`、`corr(N, Q)=0.03`）。
8. **Loss 与 Q 严重错位**：boundary+grouping 只占训练 Loss 的 **1.3%**，却对应 **70.7%** 的可约 Q；position 一项占 58.8%。
9. **H 已接近局部最优，0.25s/例与 Q 直接冲突**：同预算把 H 再跑一遍只值 ≈0.003；3× 深度只值 ≈0.0135 且 105/119 仍违反；步数降到 2 直接崩（子集 1.05→1.46）；放宽容差、硬边、去保守锥都更差。注册版 N=111–120 平均 **0.427s**，而 >0.25s 的 137 例承担了 51.9s/91.6s 的修复时间。

## 1. Q 的构成（1x 面板，500 例）

```
Cost = (1 + 0.5·(max(0,hpwl_gap) + max(0,area_gap))) · exp(2V) · runtime
```
本地研究 Q 把 runtime 置 1；gap 从下方截断为 0（官方 `compute_cost`，`third_party/FloorSet/iccad2026contest/iccad2026_evaluate.py:334`）。

| 项 | 数值 | 占 Σ(Q−1) |
|---|---:|---:|
| quality（clamp 后） | 3.201 | 29.3% |
| soft violation `exp(2V)−1` | 7.733 | **70.7%** |

- 有违反 119/500，占权重 25.0%、占加权超额 **93.1%**。
- 原始 gap 均值为负（HPWL −0.58%、bbox −0.29%），159/153 例为正。
- 分族超额占比（uniform / 官方加权）：grouping-only 43.3% / 46.2%；boundary-only 25.0% / 23.3%；both 19.7% / 23.6%；无违反 12.0% / 6.9%。
- **V 的口径**：官方公式 (4)，`V=(grouping+boundary+MIB)/N_soft`；新研究口径 MIB=0。`N_soft` 平均 42.3，因此 1 个违反 ≈ V 0.022 ≈ ×1.045；V 只有 0 与非 0，没有"轻微"。

## 2. reference 审计：它的 soft 违反是格式性的

把每例 `supervision.reference_xywh` 直接送官方评分：

| | hpwl_gap | area_gap | boundary | grouping | V>0 例 | mean Q |
|---|---:|---:|---:|---:|---:|---:|
| reference | 0（≤5e-8） | 0 | 985（433/500） | 46（43/500） | 437/500 | **1.1058** |
| E119 最终 | −0.58% | −0.29% | 66 | 88（按 violation 计数） | 119/500 | **1.0219** |

**boundary**：985/985 违反都有空带（外推不穿越任何模块），外推距离中位 **1.0**、最大 **10.0** 单位 → 与用户判断一致，可视为不违反。

**grouping**（45 个打散组，43 例）：

- **45/45 最近两块距离恰为 0**（角/点接触），没有一个是真间隙；
- 单块 0.5 单位微调可合并：**14/45**；其余 **31/45 被邻块钉死**（挪 0.5 会与邻居重叠或断开自身原有边接触），需要 2–3 块协同重排；整组件刚性平移能修的也要 44–103 单位（中位 62），不属于微调；
- 例：case0 group3 的 blk24 与 blk62 在 (86,90) 点接触，整组是一个 L 形连通块。

**结论**：reference 的 0.106 超额几乎全部来自"角接触不算共边 / 未贴边"的格式性违反；扣掉后 reference 有效 Q ≈ **1.000**。因此不能再说"我们比 reference 好 8 个点"——正确表述是：官方口径下我们 1.0219、reference 1.1058；有效质量口径下 reference ≈1.000，**我们的 1.0219 是真实差距**，且集中在同样 119 个 bad case 上。

## 3. 谁的错：草稿还是 H

### 3.1 组内配对关系（抽样 100 例、4757 个组内配对）

| | 重叠 | 共边 | 角接触 | 分离 |
|---|---:|---:|---:|---:|
| 草稿 | **24.6%** | 0.0% | 0.0% | 75.4% |
| 我们最终解 | 0.0% | **42.9%** | 0.1% | 57.0% |
| reference | 0.0% | **42.9%** | 0.7% | 56.4% |

草稿**没有任何精确共边**；共边全部由 H 合法化时产生，比例与 reference 一致。草稿的组是"近但分离"（24.6% 甚至重叠）。

### 3.2 贴边（13235 个"模块×边集"实例）

- 草稿：5879 个恰好贴边，余量四分位 **[0.043, 0.494, 1.051]** 单位——**几乎全部已经贴死**。
- 最终：13169/13235 恰好贴边，失败 66 个，其草稿余量中位 0.42。
- **66 个失败里 57 个是"预放置"模块**（不能移动）；剩余 9 个是自由块。有自由块伸到它外侧的实例 59+18 个——即理论上可通过"把别的块拉回它内侧"解决，但布局密集、条带被挡，强行拉会崩（见 5.2）。

### 3.3 组打散（1746 个组实例）

- 最终打散 80 个；其中 **78/80 是真间隙**（中位 **7.84** 单位），78/80 走廊里坐着外来模块，只有 2/80 可 0.5 单位微修。
- 草稿侧的机制指标（组级，非因果）：组 bbox 内**无**外来模块中心 → 最终打散率 **0.5%**（1/210）；有 ≥1 个 → 5.1%；≥3 个 → 7.0%。组 `bbox/面积 ≤1.18` → 0.5%；`≥1.80` → 7.0%。即 10–14× 的风险梯度。

### 3.4 位移是当前最强的单变量

- 草稿→最终平均位移 **0.0444·L**（中位 0.0380）；`corr(位移,Q)=0.49`、`corr(位移,V)=0.26`、`corr(位移,草稿覆盖率)=0.27`。
- 分族：grouping 0.0569、both 0.0620、boundary 0.0347、干净 0.0430。

**解读**：草稿并不"不会分组/贴边"，它已接近参考解；H 在合法化时把结构打散，动得越多 Q 越差。因此网络侧最值得做的是"让 H 少动"，而不是"更准的 reference 坐标"。
